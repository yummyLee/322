# 法术视觉与贴图替换约定

本文约定**所有法术**在实现时如何预留「后续换成美术贴图 / 序列帧」的路径，避免逻辑与临时几何绘制绑死。

---

## 1. 分层原则

| 层级 | 职责 | 贴图化方式 |
|------|------|------------|
| **战斗 / 逻辑** | 冷却、命中、Buff、位移、计时器 | **不**持有 Texture；只收数值与可选 `Texture2D` 参数 |
| **场地控制器** | `SpellSystem` 在 `current_scene` 下 `add_child` 的 `Node2D` 等 | 用 **`setup(..., p_field_texture: Texture2D = null)`** 或 `@export` 注入贴图 |
| **表现** | 预警圈、持续场、弹道外观 | **有贴图**：子节点 `Sprite2D` / `AnimatedSprite2D` + `modulate`；**无贴图**：`_draw()` 占位色，并注释「替换点」 |

逻辑代码里**禁止**把多边形的顶点算死成「唯一真相」后又无处接贴图；应保留「贴图优先、draw 兜底」的分支（与 `GravityWellController._apply_optional_field_sprite()` 相同思路）。

---

## 2. 推荐 API 形态

1. **`SpellCasterComponent`**（或数据 `Resource`）上为每个法术增加可选 `@export var <spell_id>_<role>_texture: Texture2D`，由策划在 Inspector 拖拽；`null` 表示使用程序绘制。`<role>` 按视觉含义命名，**禁止**统一叫 `field_texture`。当前已落地的字段：
   - `gravity_well_field_texture`（重力阱场地外圈）
   - `terracotta_rush_stripe_texture`（兵俑犁阵冲刺段条纹）
   - `phase_tick_disc_texture`（时针错位回溯盘面）
2. **`SpellSystem.cast_xxx(..., texture: Texture2D = null)`** 作为命名参数传入控制器；该参数名与控制器局部变量保持一致（`field_texture` / `stripe_texture` / `disc_texture`）。
3. **控制器 `_ready` / `setup` 末尾**：若 `texture != null`，则创建 `Sprite2D`（`centered = true`，按 `outer_radius` 或 `region` 算 `scale`）；并在 `_draw` 开头用 `if _sprite != null: return`（或 `if _stripe_sprite != null: return`）跳过占位绘制。

---

## 3. 与旧法术的衔接

- **纯 `_draw` 预警**：`SpellGroundMarker` 等可在后续改为「子节点 Sprite2D + 可选 shader」，接口上增加 `texture: Texture2D` 即可，不必改 `SpellSystem` 命中逻辑。
- **已有控制器**（引魂灯、冰轨段等）：新法术优先遵守本节；旧法术逐步加 `Texture2D` 可选参数即可，**不必一次性改完**。
