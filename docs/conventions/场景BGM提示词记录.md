### 场景

| 项 | 说明 |
|---|---|
| **用途** | 第一章开场，沈寂房间室内自由探索 |
| **时段地点** | 盛夏清晨，北窗暖黄晨光，极小猎户土屋 |
| **气质** | 关上门后的静；刚醒的空茫；克制、稀疏、可长时间循环 |
| **游戏场景** | `scenes/chapter1/phase1_room.tscn` |
| **已落地** | `resources/audio/ch1_沈寂房间_清晨_v1.mp3` |

### 提示词

```
【场景】沈寂房间，第一章开场，室内自由探索

【风格】古风轻音乐，纯器乐；绝对无人声（无歌词、无哼唱、无 chant、无 vocal pad、无口哨、无诵经、无合唱、无拟词人声）

【时段地点】盛夏清晨辰时，北窗暖黄晨光斜入；极小猎户土屋，关上门后与门外隔绝

【情绪】关上门后的静；刚醒的空茫；温吞、克制；不悲、不紧张、不史诗

【编制】箫或笛主奏（比室外更 sparse、更暗）+ 古琴散音 continuous drone 铺底；无鼓、无琵琶；中高频留空

【循环要求】30 秒 seamless loop。0:00 与 0:30 同一主音/和弦根音，起止配器密度一致，古琴散音全程 continuous drone，no fade out，no strong ending，首尾同音无跳变。
```
