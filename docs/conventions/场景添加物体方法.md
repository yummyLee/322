---

## 推荐做法：不用先导出很多小 PNG

1. **在场景里**  
   - 选中 `Props` → 右键 **复制节点** `ExampleFromTestObj`，或新建 **Sprite2D**。  
   - 在检查器里把 **Texture** 设成 **AtlasTexture**（点 `Sprite2D` → Texture → 新建 **AtlasTexture**）。  
   - **Atlas** 选 `res://resources/world/test_obj.png`。  
   - **Region** 里填矩形：`x, y` 为这一块在整图上的像素位置，`w, h` 为宽高（示例用 **64×64**；若你的格子不是 64，就改成你的格子大小）。

2. **算格子（整图 2752×1536，64×64 可整除）**  
   - 第 `col` 列、第 `row` 行（从 0 开始）：  
   - `Rect2(col * 64, row * 64, 64, 64)`  
   - 例如在编辑器里 Region 填：`256, 128, 64, 64`。

3. **摆放**  
   - 用 **position**（必要时 **scale**）对齐背景和摄像机；需要遮挡关系时，可开 **Y Sort** 或调整节点顺序（下面的节点后画，会盖在上面）。

4. **要挡路**  
   - 在该物体下加 **StaticBody2D + CollisionShape2D**，形状对准贴图（你场景里 `Walls` 那套就是同样思路）。

---

## 什么时候才要“真的切文件”

只有当你要**很多关共用同一批独立小图**、或给非 Godot 工具用时，才用外部工具批量导出切片；在 Godot 里用 **AtlasTexture.region** 一般就够了。
