# 场景 BGM 音乐生成 Agent 使用说明

用途：记录**音乐生成 Agent** 的职责、系统提示词，以及你每次向 Agent **发送场景提示词** 的格式。

- **音乐 Agent**：直接生成约 30 秒 MP3，古风 + 轻音乐、无人声、可无缝循环
- **你**：按本文档第三节写好提示词，发给 Agent
- **落地**：MP3 放入 `resources/audio/`，场景挂载 `SceneBgmPlayer`（`loop = true`）

---

## 一、音乐 Agent 做什么

| 输入 | 输出 |
|------|------|
| 你写的**场景音乐提示词**（见第三节模板） | **约 30 秒 MP3 音频文件** |

Agent **不负责**帮你写提示词；提示词由你根据场景需求自行撰写（可参考本文档示例）。

**Agent 必须遵守的生成约束：**

- 风格：**古风 + 轻音乐**，克制、留白
- **无人声**：无歌词、无哼唱、无 chant、无 vocal pad、无口哨、无诵经、无合唱、无拟词人声；**纯器乐轻音乐**
- 时长：**约 30 秒**
- **首尾无缝循环**：起止同音/同和弦、无 fade out、无强终止
- 默认非战斗、非史诗；蝉鸣/鸡鸣/劈柴等优先由游戏 SFX 承担

---

## 二、音乐 Agent 系统提示词（复制整段给 Agent）

将下面 ``` 内的全文设为 Agent 的**系统指令 / Custom Instructions**：

```
# 角色

你是《天命之玉》Godot 游戏的**场景背景音乐生成 Agent**。
用户会直接发送音乐提示词；你的任务是**生成约 30 秒的 MP3 音频**，供游戏内无缝循环播放。

你不负责帮用户写提示词。用户发来什么描述，你就按描述生成，同时必须满足下方硬性约束。

# 硬性约束（每次生成都必须满足）

## 风格
- **古风 + 轻音乐**：东方气质、克制、留白，适合长时间循环
- **无人声**：禁止歌词、哼唱、chant、vocal pad、口哨、诵经、合唱、拟词人声；**只能是纯器乐轻音乐**
- 默认：探索 / 日常 / 氛围；仅当用户明确要求时才做战斗 / 紧张曲
- 禁止：摇滚、EDM、西方史诗管弦、现代流行、电子 drop

## 编制（按用户提示选用，勿堆满）
- 主奏：箫、笛、古琴、琵琶轻拨、阮
- 铺底：古琴散音、极轻 pad
- 节奏：默认无或极弱；户外村景可极轻手鼓 / 竹板
- 中高频留空（给游戏蝉鸣等 SFX），低频克制

## 时长与循环（最重要）
- 只能生成 **约 30 秒**
- 游戏会 **loop = true** 循环播放，因此必须 **首尾无缝衔接**：
  - 0:00 与 0:30 同一主音或同一和弦根音
  - 起止配器密度相近
  - 结尾禁止强终止感（complete cadence）
  - 禁止 fade out 到静音
  - 结尾应像「还没说完就接回开头」

## 推荐 BPM（4/4，保证 30 秒为整小节）
优先选用下列 BPM 之一：

| BPM | 30 秒小节数 |
|-----|-------------|
| 48  | 6           |
| 56  | 7           |
| 64  | 8           |
| 72  | 9           |
| 80  | 10          |
| 88  | 11          |
| 96  | 12          |

公式：小节数 = BPM ÷ 8

## 循环结构（作曲时按其一执行）
- **A–A'**：前 15 秒动机 A，后 15 秒略变化，末音 = 首音
- **AB–AB**：偶数小节重复，第二段结尾回到起始音
- **Drone Loop**：全程固定散音铺底 + 旋律简化重复，首尾同音

## 默认动态与调性（用户未指定时）
- 动态：pp ~ mp，不超过 mf
- 调性：五声调式，D 或 G 调
- 室内 / 清晨：56 或 64 BPM
- 户外村庄：72 或 80 BPM

```

## 三、你发给音乐 Agent 的提示词格式

每次需要新 BGM 时，按下面模板写提示词发给 Agent。**可直接复制填空，或参考第四节完整示例。**

```
【场景】（必填）场景名 + 用途，如：沈寂房间 / 赤水村日常

【风格】（必填）古风轻音乐，纯器乐；绝对无人声（无歌词、无哼唱、无 chant、无 vocal pad、无口哨、无诵经、无合唱、无拟词人声）

【时段地点】（必填）如：盛夏清晨，室内小猎户土屋

【情绪】（必填）2～5 个关键词，如：安静、温吞、略空茫

【编制】（可选）如：箫 + 古琴散音，无鼓

【BPM / 调性】（可选）如：64 BPM，G 五声；不填则由 Agent 按默认

【衔接】（可选）如：与 ch1_沈寂房间_清晨_v1 同调，略更开阔

【禁止】（必填）绝对不要任何人声（含哼唱、chant、vocal pad 等）；另列场景禁止项，如：不要蝉鸣、不要史诗弦乐

【循环要求】（建议每次都写，强化 Agent 行为）
30 秒无缝循环。首尾同一主音/和弦，无 fade out，无强终止，起止配器密度一致。
```

### 最短版（熟悉后可一句话）

```
赤水村日常 BGM：【风格】古风轻音乐纯器乐绝对无人声。盛夏上午户外穷村，笛+古琴+轻琵琶，普通 lazy 村日、底层淡忧，72 BPM G 五声，30 秒 seamless loop，首尾同音无 fade out。【禁止】绝对不要任何人声；不要蝉鸣。
```

## 四、完整提示词示例（复制改场景即用）

### 示例 A — 沈寂房间

```
【场景】沈寂房间，第一章开场，室内自由探索

【风格】古风轻音乐，纯器乐；绝对无人声（无歌词、无哼唱、无 chant、无 vocal pad、无口哨、无诵经、无合唱、无拟词人声）

【时段地点】盛夏清晨辰时，北窗暖黄晨光斜入；极小猎户土屋，关上门后与门外隔绝

【情绪】关上门后的静；刚醒的空茫；温吞、克制；不悲、不紧张、不史诗

【编制】箫或笛主奏（比室外更 sparse、更暗）+ 古琴散音 continuous drone 铺底；无鼓、无琵琶；中高频留空

【BPM / 调性】64 BPM，G 五声

【衔接】与 ch1_赤水村日常_上午_v1~v4 同章同调；动机可相近，但编配更室内、更空、更静；出门进村子后应能自然过渡

【禁止】绝对不要任何人声（含哼唱、chant、vocal pad、口哨、诵经、合唱、拟词）；不要蝉鸣、鸡鸣、劈柴、风声（游戏 SFX 单独播）；不要史诗管弦、欢快田园、现代流行、战斗感

【循环要求】30 秒 seamless loop。0:00 与 0:30 同一主音/和弦根音，起止配器密度一致，古琴散音全程 continuous drone，no fade out，no strong ending，首尾同音无跳变。
```

### 示例 B — 赤水村日常

```
【场景】赤水村室外开放地图，NPC 对话与追鸡
【风格】古风轻音乐，纯器乐；绝对无人声（无歌词、无哼唱、无 chant、无 vocal pad、无口哨、无诵经、无合唱、无拟词人声）
【时段地点】上午至正午，土路、老槐树、井、晾衣竿
【情绪】晒白土路的 lazy 村日；表面平静，底层极淡不安
【编制】笛 + 古琴散音 + 极轻琵琶拨弦；极弱手鼓可选
【BPM / 调性】72 BPM，G 五声
【衔接】与 ch1_沈寂房间_清晨_v1 同章同调，编配略丰满
【禁止】绝对不要任何人声；不要欢快田园舞曲；不要史诗管弦；不要蝉鸣
【循环要求】30 秒 seamless loop，same note at start and end，no fade out，instrumentation density matched at start and end。
```

【场景】周伯院子夜袭，第一次战斗

## 五、循环验收清单（生成后人工试听）

听 3～5 遍循环，逐项确认：

- [ ] 0:00 与 0:30 为同一主音或和弦根音
- [ ] 结尾无渐弱至静音、无强收束
- [ ] 起止配器层数接近
- [ ] **绝对无人声**（纯器乐轻音乐；无哼唱、chant、vocal pad 等）
- [ ] 切回开头无跳变感
- [ ] 中高频未塞满（给蝉鸣等 SFX 留空间）

**仍有接缝时**，在原提示词末尾追加一句重生成：

```
exact same chord and texture at 0:00 and 0:30, continuous guqin drone throughout entire 30 seconds
```

游戏内 `SceneBgmPlayer` 的 `fade_in_duration` 可作 2 秒 crossfade 兜底，但优先靠音频本身无缝。

## 七、落地到游戏

### 文件命名（强制）

所有放入 `resources/audio/` 的 BGM **必须**按下列格式命名，Agent 落盘时直接采用规范名，不得保留临时英文名：

```
ch{章节}_{场景}_{时间}_v{版本}.mp3
```

| 段 | 说明 | 示例 |
|---|---|---|
| 章节 | `ch` + 数字 | `ch1` |
| 场景 | 简短中文，对齐 `场景BGM提示词记录.md` | `沈寂房间`、`夜袭战斗` |
| 时间 | 时段 | `清晨`、`上午`、`午后`、`深夜`、`凌晨`、`黎明` |
| 版本 | 同曲迭代 | `v1`、`v2` |

示例：`ch1_沈寂房间_清晨_v1.mp3`

重命名后须同步：`.import` 文件、场景 `ext_resource` 路径、本文第八节登记、`场景BGM提示词记录.md` 中的「已落地」字段。

### 挂载步骤

1. Agent 生成 MP3 → **以规范名**保存到 `resources/audio/`
2. 场景挂载 `SceneBgmPlayer`，设置 `stream` 或 `streams`、`volume`（通常 0.3～0.6）
3. 单轨 `stream` 会 `loop = true`；多轨 `streams` 按序交替（每曲播完切下一首）
