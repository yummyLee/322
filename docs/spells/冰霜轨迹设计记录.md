# 冰霜轨迹（Frost Trail）代码设计记录

## 1. 目标与当前行为

- **自身指向法术**：无需鼠标落点；施法后在一段时间内，施术者**移动时在身后铺设冰带**。
- **敌对踩冰**：对每个仍存活的冰带段做周期性形状查询，命中的敌对单位通过 **`SlowBuff`** 施加减速；同源（`source_tag = frost_trail`）重复命中为**刷新持续时间与等级**，不叠多条同源减速。
- **与玩家解耦**：施法参数与入口在 **`SpellCasterComponent`**，统一经 **`SpellSystem.cast_frost_trail`** 落地；NPC 挂载同一组件即可复用。

---

## 2. 调用链（自顶向下）

1. **输入 / UI**：技能栏绑定 `spell_id = "frost_trail"`；`player.gd` 将 `Callable(spell_caster, "cast_frost_trail")` 注册到内部施法表（玩家不持有法术数值常量）。
2. **`SpellCasterComponent.cast_frost_trail()`**（`scripts/magic/spell_caster_component.gd`）  
   - 校验冷却、组装导出参数，调用 `SpellSystem.cast_frost_trail(...)`。
3. **`SpellSystem.cast_frost_trail(...)`**（`scripts/magic/spell_system.gd`）  
   - `SPELL_ID_FROST_TRAIL := "frost_trail"`；`_can_cast_spell` → 可选 `cast_delay` → 实例化控制器并 `add_child` 到 **`current_scene`** → `_begin_spell_cooldown`。
4. **`FrostTrailController`**（`scripts/magic/effects/frost_trail_controller.gd`）  
   - `_process`：在 `trail_duration` 内按位移阈值铺段；按 `tick_interval` 对所有存活段做命中检测，对敌对调用 `SlowBuff.apply(..., SLOW_SOURCE)`；施术者失效则自清理。
5. **`FrostTrailSegment`**（`scripts/magic/effects/frost_trail_segment.gd`）  
   - 仅负责**视觉**（尺寸、生命周期、淡入淡出）与**几何信息**（供控制器查询）；不直接改战斗状态。

---

## 3. 减速与 `SlowBuff` 约定

- 实现：`scripts/core/combat/buffs/slow_buff.gd`（`class_name SlowBuff`）。
- 冰霜轨迹使用的来源标识：控制器内常量 **`SLOW_SOURCE = &"frost_trail"`**（与 `SlowBuff` 文档示例一致）。
- **等级 → 移速减免比例**见 `SlowBuffDef.LEVEL_TO_PCT`（1~10 档，每级 +10%；等级 3 为 **−30% 移速**）。`SlowBuff` 只是对外 apply/remove 的兼容入口；数据表统一存在 `SlowBuffDef`。  
- **不同 `source_tag`** 在目标上各占一条 modifier，按 **`PERCENT_ADD`** 合并；便于与其他减速来源共存。
- **`slow_duration` 建议 ≥ `tick_interval`**：踩在冰上时每次 tick 刷新，离开冰后 buff 自然过期。

---

## 4. 渲染层级（Z 顺序）

- 冰带与控制器均设置：**`z_as_relative = false`**、**`z_index = -10`**。
- **约定**：地面类场景约 **`z_index = -100`**；角色/怪物默认 **`0`**。  
  绝对 `z_index` 避免父节点层级把冰面抬到实体之上。

---

## 5. 可调参数（`SpellCasterComponent` 导出）

| 导出变量 | 含义（摘要） |
|----------|----------------|
| `frost_trail_duration` | 持续铺冰时间（秒） |
| `frost_trail_segment_lifetime` | 单段存在时间（秒） |
| `frost_trail_segment_spacing` | 再铺新段所需位移（像素） |
| `frost_trail_segment_length` / `width` | 单段碰撞与绘制尺寸 |
| `frost_trail_tick_interval` | 对冰上单位施加/刷新减速的周期 |
| `frost_trail_slow_level` | `SlowBuff` 等级（1~10，默认 3） |
| `frost_trail_slow_duration` | 每次 tick 刷新的 buff 持续时间 |
| `frost_trail_cast_delay` | 施法后延迟再生成控制器 |
| `frost_trail_cooldown_seconds` | 法术冷却 |
| `frost_trail_collision_mask` | 段形状查询用的物理层掩码 |

`SpellSystem.cast_frost_trail` 的形参与上述一一对应，便于脚本或调试直接调用。

---

## 6. UI 与目录

- 技能面板 / 技能栏目录项：`spell_id` **`frost_trail`**，展示名「冰霜轨迹」（`skill_panel.gd`、`spell_hotbar.gd`）。

---

## 7. 扩展注意点

- **换强度**：改 `frost_trail_slow_level` 或 `SlowBuffDef.LEVEL_TO_PCT` 表即可，无需复制控制器逻辑。
- **新法术共用减速**：新来源使用**新的 `source_tag`**，避免与 `frost_trail` 互相覆盖刷新策略。
- **更复杂地面交互**：可在控制器 tick 内追加效果，或让段携带自定义 metadata；保持「段只负责视觉 + 几何、控制器负责查询与战斗」的分工即可。
