# 兵俑犁阵（Terracotta Rush）实现原理

策划条目：`../planning/技能设计.md` —— 沿施法方向连续 3 段矩形预警，短暂延迟后犁过：小额**物理**伤害 + 强击退，同一目标击退递减。

---

## 1. 调用链

1. **UI**：`spell_id = terracotta_rush`，技能栏默认 **H**（`spell_hotbar.gd`）。
2. **`player.gd`**：`SpellCasterComponent.cast_terracotta_rush` → `_wrap_component_cast_at_mouse`（与引魂灯、重力阱相同）。
3. **`SpellCasterComponent.cast_terracotta_rush(aim_world_point)`**  
   读取 `@export_group("Terracotta Rush")` 与可选 **`terracotta_rush_stripe_texture`**，调用 `SpellSystem.cast_terracotta_rush`。
4. **`SpellSystem.cast_terracotta_rush`**  
   冷却 id `terracotta_rush` → `cast_delay` → 在 `current_scene` 下添加 **`TerracottaRushController`**。
5. **`TerracottaRushController`**（`scripts/magic/effects/terracotta_rush_controller.gd`）  
   在施法者**按下施法瞬间**的位置取 `rush_origin`，方向为 **`normalize(aim - rush_origin)`**；节点 `global_position = rush_origin`、`global_rotation = 方向角`。顺序：第 *i* 段预警 `warn_seconds` → `intersect_shape` 矩形结算 →间隔 `pause_between_segments` →下一段。

---

## 2. 几何与命中

- 每段为 **`RectangleShape2D`**，`size = (segment_length, segment_width)`，中心在冲锋轴上：  
  `x = start_offset + L/2 + i * (L + gap)`（控制器局部 **+X** 即冲锋方向）。
- **`PhysicsShapeQueryParameters2D.transform = Transform2D(global_rotation, center_world)`**，与 `spell_system` 中线段查询思路一致。
- 命中去重后仅 **`FactionUtils.is_hostile(caster, target)`** 的目标结算。

---

## 3. 伤害与击退

- **伤害**：`DamageCalculator.compute_outgoing_physical(attributes, base_damage)`，走 `receive_hit` / `on_hit`，`source_tag = spell:terracotta_rush`。
- **击退方向**：与 `rush_dir` 相同（向前犁出）。
- **递减**：字典 `_knock_counts[target]` 记录**之前已经被犁过的次数 `n`**（首次命中时 `n = 0`，乘子 `pow(decay, 0) = 1` 即全额；第二次 `n = 1`，乘子 `decay`；依此类推）。默认 `decay = 0.72`。
- **位移通道**：与夹击术相同，优先 **`ChaseController.add_external_control_velocity`**；否则 **`CharacterBody2D.global_position`** 微移兜底。

---

## 4. 视觉与贴图

- 遵守 **`../conventions/法术视觉与贴图替换约定.md`**。
- **`stripe_texture != null`**：单个子节点 `Sprite2D` 跟随当前预警段中心拉伸；无贴图时用 `_draw` 画土黄色矩形框。

---

## 5. 可调参数（SpellCasterComponent）

| 导出变量 | 含义 |
|----------|------|
| `terracotta_rush_segment_count` | 段数（默认 3） |
| `terracotta_rush_segment_length` / `width` / `gap` | 每段长、宽、段间距 |
| `terracotta_rush_start_offset` | 起点距施法者原点（避免贴身自撞） |
| `terracotta_rush_warn_seconds` | 每段预警时长 |
| `terracotta_rush_pause_between` | 段与段之间停顿 |
| `terracotta_rush_base_damage` | 物伤基数（与物攻公式合并） |
| `terracotta_rush_knockback_base` | 击退标量 |
| `terracotta_rush_knockback_repeat_decay` | 同一目标重复命中击退衰减系数 |
| `terracotta_rush_cast_delay` / `cooldown_seconds` | 施法延迟与冷却 |
| `terracotta_rush_collision_mask` | 查询掩码 |
| `terracotta_rush_stripe_texture` | 可选预警条纹贴图 |
