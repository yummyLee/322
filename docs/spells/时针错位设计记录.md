# 时针错位（Phase Tick）实现原理

技能效果：发射缓慢前进的“时针盘”；敌对单位穿过盘面时记录其当下坐标；**`rewind_delay`（默认 1.2s）后强制回到记录点并受一次伤害**。

---

## 1. 调用链

1. `spell_id = "phase_tick"`。**默认不占快捷槽**，仅出现在技能面板目录（`spell_hotbar.gd.spell_catalog`）中，玩家需要时可拖到任意槽位；若要默认绑定某键，需手动在 `slot_configs` 里追加。
2. `player.gd` 通过 `_wrap_component_cast_at_mouse("phase_tick", ..., "cast_phase_tick")` 走鼠标落点施法。
3. `SpellCasterComponent.cast_phase_tick(target_point)` 读取导出参数，调用 `SpellSystem.cast_phase_tick(...)`。
4. `SpellSystem` 校验冷却后实例化 `PhaseTickController`。

---

## 2. 控制器行为

脚本：`scripts/magic/effects/phase_tick_controller.gd`

- 盘体以 `direction * move_speed` 前进，累计 `travel_duration` 秒后**停止前进**但**保持存在**，直到所有已记录目标都完成回溯。
- 每帧对盘体半径做 `intersect_shape` 查询；`exclude = [caster]`，仅对**每个敌对目标记录一次**：
  - 字典条目使用 `"pos"` 键保存命中瞬间位置，`"left"` 键保存回拉剩余时间（初始化为 `rewind_delay`）。
- 计时到 0 后执行：
  1. 目标 `global_position = pos`（若目标有 `velocity` 字段，也清零避免继续滑行）
  2. 结算一次伤害（`source_tag = spell:phase_tick`）

这样避免了“持续控制”，更像时间回溯。盘面本身在 `_finished_travel and _recorded.is_empty()` 时 `queue_free`。

---

## 3. 伤害与类型

- 默认伤害类型：`MAGICAL`（可在 `SpellSystem.cast_phase_tick` 调参覆盖）。
- 出手伤害在控制器 `setup` 时缓存一次（法强/暴击沿用现有 `DamageCalculator.compute_outgoing_magical`）。

---

## 4. 贴图替换预留

- 控制器支持可选 `disc_texture`。
- 非空时挂 `Sprite2D` 并按盘体半径缩放，`_physics_process` 会每帧给 Sprite 叠 `rotation`，做出「指针走动」的自转效果；为空时走 `_draw` 的程序占位绘制（外圈 + 时针线，线段角度每帧自增 `_visual_spin`）。
- 符合 `../conventions/法术视觉与贴图替换约定.md`。

---
