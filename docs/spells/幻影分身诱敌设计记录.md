# 幻影分身诱敌（Mirror Decoy）实现原理

与策划条目 `../planning/技能设计.md` 第 5 条一致：**下一次冲刺**在冲刺**起点**生成分身约 4s；施法者获得约 **1.5s 隐身**（受击框关闭 + 精灵半透明）；带 `ChaseController` 的敌人追逐目标临时改为分身；分身消失时在落点周围施加 **0.5s 强减速**（`SlowBuff` 满级，作眩晕占位）。

---

## 1. 调用链

1. **UI**：`spell_id = mirror_decoy`，技能栏默认 **Y**（`spell_hotbar.gd`）。
2. **`SpellCasterComponent.cast_mirror_decoy()`** → **`SpellSystem.cast_mirror_decoy_arm`**（冷却 `SPELL_ID_MIRROR_DECOY`）。
3. **`cast_mirror_decoy_arm`** 在 `cast_delay` 后调用施术者 **`arm_mirror_decoy_spell(...)`**（仅 **`Player`** 实现该方法）。
4. **`Player.arm_mirror_decoy_spell`**：设置 `_mirror_decoy_armed` 与 `_mirror_pending`（分身寿命、隐身时长、眩晕半径/时长等），并记录 **`arm_window`** 超时时间。
5. **`PlayerDashAbility.dash_started(start_position, direction)`**（信号在**首帧冲刺位移前**记录起点）→ **`Player._on_mirror_decoy_dash`**：若已武装则在 `start_position` 生成 **`MirrorDecoy`**，并 **`_begin_mirror_invisibility`**。

---

## 2. 追逐目标切换

- **`MirrorDecoy`** 在 `_ready` 中遍历 **`group "enemy"`**，对每个子节点 **`ChaseController`**：  
  `Dictionary[chase] = chase.chase_target` 备份后 **`chase.chase_target = self`**（分身 `Node2D` 世界坐标供 `ChaseTowardInRangeBehavior` 使用）。
- 分身 **`queue_free()`** 前 **`_restore_chases()`**，把各 `chase_target` 还原为备份值（多为 `null`，继续走默认 `target_group` 找玩家）。

---

## 3. 隐身与「不可被看见」

- **表现**：`AnimatedSprite2D.modulate.a ≈ 0.15`。
- **受击**：`CombatHurtbox.collision_layer = 0`，近战形状查询默认打 hurtbox **层**时无法命中玩家（与怪物攻击配置一致）。
- **计时**：`_mirror_invis_time_left` 在 `Player._physics_process` 首段递减；到期 **`_end_mirror_invisibility`** 还原 layer（若备份为 0 则回退 **16**）与 modulate。

---

## 4. 分身本体

- 脚本 **`MirrorDecoy`**（`CharacterBody2D`）：**`collision_layer/mask = 0`**（本体不参与移动碰撞）；动态挂载 **`CombatantComponent` + `CombatHurtbox`（layer 16）**，**可被怪物/法术命中**。
- **属性快照**：`_ready` 时从施法者 **`Player`** 复制五维、等级、`move_speed`、全部 **`StatModifier`**，以及**当前 HP/MP**（释放瞬间数值）。
- **死亡**：`CombatantComponent.died` → **`_destroy_on_death()`**（还原追逐、**不**触发到期眩晕）；自然到期仍走 **`_expire()`** 范围减速。
- **非玩家**：仅加入 **`mirror_decoy`** 组，**不在 `player` 组**、非 **`Player` 类**；`WorldItem` / `WorldGoldPickup` 等用 **`MirrorDecoy.is_mirror_decoy_node()`** 排除，不触发拾取、任务、采集等 **`body is Player`** 逻辑。
- **`get_faction_tag`** 与施法者一致；实现 **`on_hit` / `receive_hit`** 转发至 `CombatantComponent`。
- **`attach_visual_from_player`**：复制玩家 `AnimatedSprite2D`（共享 `SpriteFrames` 资源，略偏蓝 `modulate`）；绘制简易 HP 条；后续可改为独立预制体 + 贴图（见 `../conventions/法术视觉与贴图替换约定.md`）。

---

## 5. 消失时「眩晕」占位

- 以分身位置为圆心 **`intersect_shape` 圆**，对敌对调用 **`SlowBuff.apply(..., level=10, duration=0.5, source=&"mirror_decoy_expire")`**（满级减速 ≈ 定身）。

---

## 6. 冲刺信号变更

- **`PlayerDashAbility`**：`dash_started` 现为 **`(start_position: Vector2, direction: Vector2)`**，便于在**几何冲刺起点**落分身。  
- **`PlayerDashHitAbility`** 仍连接该信号，参数兼容。

---

## 7. 可调参数（`SpellCasterComponent`）

| 导出变量 | 含义 |
|----------|------|
| `mirror_decoy_arm_window_seconds` | 武装后未冲刺则失效的等待窗口 |
| `mirror_decoy_lifetime` | 分身持续时间 |
| `mirror_decoy_invisibility_seconds` | 隐身时长 |
| `mirror_decoy_stun_radius` / `stun_duration` / `stun_slow_level` | 消失时范围与强减速 |
| `mirror_decoy_cast_delay` / `cooldown_seconds` | 施法延迟与冷却 |
| `mirror_decoy_collision_mask` | 消失结算形状查询掩码 |
