# 重力阱（Gravity Well）实现原理

对应策划条目：`../planning/技能设计.md` —— 在一点生成吸引场，敌对被拉向中心；内圈周期性叠「重压」减速；结束时对范围内敌对施加短时眩晕并结算小额收束伤害（**无向外爆发击退**，早期策划里的「外爆」已改为眩晕）。

---

## 1. 调用链

1. **输入 / UI**：`spell_id = "gravity_well"`；技能栏默认绑定 **G**（`spell_hotbar.gd`）；技能面板可拖拽绑定。
2. **`player.gd`**：若存在 `SpellCasterComponent.cast_gravity_well`，注册  
   `_wrap_component_cast_at_mouse("gravity_well", spell_caster, "cast_gravity_well")`。
3. **`SpellCasterComponent.cast_gravity_well(target_point)`**  
   读取本组件 `@export_group("Gravity Well")` 下的数值与可选 **`gravity_well_field_texture`**，调用 `SpellSystem.cast_gravity_well(...)`。
4. **`SpellSystem.cast_gravity_well`**（`scripts/magic/spell_system.gd`）  
   `SPELL_ID_GRAVITY_WELL` 冷却 → `cast_delay` → 实例化 **`GravityWellController`** 并 `add_child` 到 **`current_scene`**，`global_position = target_point`。
5. **`GravityWellController`**（`scripts/magic/effects/gravity_well_controller.gd`）  
   `_physics_process` 内完成脉冲吸引、内圈叠减速；寿命耗尽时结算眩晕与小额伤害。

---

## 2. 吸引（与 AI 的协作）

- **脉冲式拉取**：控制器用固定间隔 `_PULL_TICK_INTERVAL = 0.5s` 触发一次 `_apply_pull_once`，而非每帧推送，手感更像「一抽一抽」把目标拖向中心。
- **中心停止圈**：距阱心 `_CENTER_STOP_RADIUS = 10px` 内不再继续施加拉力，改为反向刹车外力，避免穿心来回抖动。
- **优先**：与夹击术（`pincer_clamp_controller.gd`）相同，对目标解析 **`ChaseController.add_external_control_velocity`**（或目标自身若实现该方法），把每次脉冲写成**速度增量**，避免与追逐 AI 抢写 `velocity` 覆盖。
- **兜底**：无外力通道的 `CharacterBody2D`（如测试假人）退化为 **`global_position += step`** 微移，保证仍能被拉动。

**拉力方向**：指向阱心；**强度**：随距边缘越近越大（`falloff`），并限制脉冲速度不得超过「距停止圈剩余距离 / 脉冲间隔」，避免单次脉冲穿过中心。`gravity_well_knockback_strength` 在当前实现中并不负责「结束击退」，而是作为**拉力强度下限**（`max(pull_strength, knockback_strength * 3.0)`）保证拉感不丢；命名为历史遗留。

---

## 3. 「重压」与 SlowBuff

- 内圈半径 `inner_radius` 内，对每个敌对目标累计时间；每满 **`heavy_interval` 秒**（默认 1s）叠一层。
- 使用全局 **`SlowBuff.apply(target, level, slow_refresh_duration, HEAVY_SLOW_SOURCE)`**，其中  
  `HEAVY_SLOW_SOURCE = &"gravity_well_heavy"`，`level` 为当前层数（上限 10），与现有 `SlowBuff` 的 `PerSourceSkill` 语义一致：同源刷新、等级随 `stacks_override` 提升。
- 离开**外圈**后清除该目标在控制器内的累计状态；离开**内圈**仅清除「距下次叠层」的计时，已施加的减速仍按 Buff 自身时间衰减。

---

## 4. 结束效果

- 寿命结束时，对**外圈**内敌对：
  - 施加 **1.5s 眩晕**（`StunBuff.apply(..., &"gravity_well_finish_stun")`）。
  - 并结算一次小额魔法伤害（`source_tag = &"spell:gravity_well_burst"`）。

眩晕 Buff 的独立实现见：`../systems/眩晕Buff实现记录.md`。

---

## 5. 视觉与贴图替换

- 详见 **`../conventions/法术视觉与贴图替换约定.md`**。
- 本法术：`setup(..., field_texture)` 非空时挂 **`Sprite2D`** 作为场地贴图并跳过 `_draw` 场地环；无贴图时用紫色环 + 中心旋转方块（程序占位）。

---

## 6. 可调参数（SpellCasterComponent）

| 导出变量 | 含义 |
|----------|------|
| `gravity_well_duration` | 吸引场持续秒数 |
| `gravity_well_outer_radius` / `inner_radius` | 外圈吸引 / 内圈叠层 |
| `gravity_well_pull_strength` | 吸引强度缩放 |
| `gravity_well_heavy_interval` | 叠一层重压的间隔 |
| `gravity_well_slow_refresh_duration` | 每次施加 SlowBuff 的持续时间 |
| `gravity_well_knockback_strength` | 拉力强度下限（命名历史遗留；不再做结束击退） |
| `gravity_well_end_damage` | 结束时小额魔法伤害基数 |
| `gravity_well_cast_delay` / `cooldown_seconds` | 施法延迟与冷却 |
| `gravity_well_collision_mask` | 形状查询掩码 |
| `gravity_well_field_texture` | 可选场地贴图 |
