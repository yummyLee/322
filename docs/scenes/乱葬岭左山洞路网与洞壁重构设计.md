# 乱葬岭左山洞：路网、洞壁与地面重构设计

版本：1.0（2026-09-20）  
适用场景：`burial_left_cave/world.tscn`

## 1. 本轮目标

把左山洞从“多个区域面片加道路贴片”整理成一座可以探索的连续天然石灰岩洞穴。J0～J13 的区域语义、墙体围合关系、入口方向和连接账本继续保留；重做区域之间的通路、区域边缘、洞壁层次和地面材质。场景必须在 Godot 编辑器里直接可选、可移动、可调整，运行时不生成或覆盖地形。

## 2. 已有要求与本轮新增要求梳理

### 2.1 需要继续满足的要求

- 保留 J0～J13 的区块与连接账本：J0-J1、J1-J8、J8-J2、J8-J3、J2-J4、J3-J9、J9-J6、J4-J11、J11-J5、J6→J5、J5-J10、J10-J7、J10-J12、J12-J13、J12→J8、J4→J0。
- 区域地面必须是保存到 `.tscn` 的连续细分网格，带真实高度变化、连续法线和低饱和材质过渡。
- 重要物体使用独立可编辑资产组；碰撞、入口标记、相机、灯光和场景层次一起落盘。
- 以玩家可见身高为尺度，地面和道路细分单元最长边不超过 `0.5H`；不能以长方形、单个扇形、大平面或重复规则拼块代表地形。
- 洞口保留净空，坡脚、路肩、台阶和入口前后要能从正面、侧面、俯视和旋转视角读懂。
- 保留 `burial_left_cave/main.tscn` 运行入口，不改动 `village/main.tscn`。

### 2.2 本轮反馈对应的修复

- 路面与区域面片重叠：删除旧的重叠路段，按入口到入口建立唯一的曲线中心线；路面只覆盖连接段，不伸进区域内部；两端用低矮路肩和坡脚收口。
- 区域墙体缺失、直线多边形暴露：每个区域恢复不规则圆润的岩脊边缘，并增加分层岩墙、岩板、塌落块和湿痕；墙体在入口处主动留出缺口。
- 左上三条直线、最左侧怪路、无意义木板路：移除直线/重复/无语义路径；木桥只保留在 J11 悬骨桥这一处，并明确与裂谷两端连接。
- 地图出现简单多边形：区域轮廓改为至少 9 个不等长控制点的天然曲线，边界以连续网格和岩石轮廓包住，不留下孤立的几何占位形状。
- 纯色地面过多：加入共享调色范围内的湿干变化、冲刷沟、碎石簇、落叶/骨屑、脚印和车辙；细节为独立节点，疏密不均，不铺满。
- 需要探索欲：保留三层高差、三条回路、两处捷径和多个视觉遮挡点，让玩家通过曲线、岩柱和坡台逐步发现下一块区域。

## 3. 空间与路线设计

### 3.1 主干路线

| 编号 | 起点 → 终点 | 路线形态 | 处理 |
|---|---|---|---|
| R01 | J0 → J1 → J8 | 南北 S 弯 | 唯一入洞主路，宽度 4.0～4.6，入口处缓坡 |
| R02 | J8 → J2 | 东侧上抬弯 | 三个以上控制点，踏石与碎石路肩 |
| R03 | J2 → J4 | 东北折返爬坡 | 避免门对门，保留上层视线遮挡 |
| R04 | J4 → J11 → J5 | 高层沿裂谷弧线 | J11 只在裂谷处使用一段木桥，其余为岩台 |
| R05 | J8 → J3 → J9 → J6 | 西侧湿层回路 | 顺水流下降，曲线遮挡井厅 |
| R06 | J6 → J5 | 单向塌方落台 | 只允许向上回到 J5，加入残阶与坡脚 |
| R07 | J5 → J10 → J12 → J13 | 深层采石回路 | 灰瀑阶地、采石廊和记名室逐级收窄 |
| R08 | J12 → J8 | 永久捷径 | 只在塌口打开后可见，不能与 J10→J12 共面 |
| R09 | J4 → J0 | 单向高层落台 | 窄坡/残阶，通向洞口侧壁，不作直线滑道 |

### 3.2 道路几何规则

- 每条路由至少 4 个控制点，使用平滑重采样；控制点的转角半径大于玩家宽度的 1.5 倍。
- 道路使用一张连续带状网格，沿中心线宽度轻微变化并跟随标高；路肩是断续小岩块、湿边和裸土的混合带。
- 每条路只创建一个 `RoadSurface` 与一个 `GroundCollision`。禁止再叠加第二张同范围路面。
- 每个连接端保存 `RegionEntrances/<连接编号>` 标记，入口两侧墙体缺口与碰撞净空一致。
- 路面细节按语义分配：R01/R02 为车辙和脚印，R05 为湿痕和浅排水沟，R07 为拖槽和石灰粉，R08 为塌方碎石。

## 4. 洞壁与区域边缘

- 每个 J 区有独立 `RegionRockRim_<J>` 父节点，至少包含连续低岩脊、2～3 个较高岩壁段、塌落块和湿痕层；不要用一圈同高石柱。
- 岩壁采用不等长、轻微倾斜、上下错层的岩板与圆润岩块组合。外轮廓至少 9 个控制点，避免可读的直线和长矩形。
- 入口处用“豁口 + 两侧低肩 + 后退高壁”形成峡湾式咽喉；不得用高石柱堵住入口。
- 外围洞壳与区域岩脊分层：外围负责洞顶和侧壁，区域岩脊负责空间分隔；两者不共面、不互相穿插。
- 岩石材质共享冷灰、蓝灰、湿青灰范围，通过顶点高度和小幅色差表达裂隙、湿润和沉积，不用纯黑矩形遮洞。

## 5. 地面材质与细节

- 母岩地面使用连续细分网格，顶点起伏幅度约 0.04～0.12H；区域连接处共享高度趋势。
- 颜色在相邻区域之间逐步过渡：干岩灰 → 压实土褐 → 湿青灰 → 石灰浅灰，避免硬色块。
- 每个区至少有三种尺度的纹理节点：中尺度湿干/冲刷带、半埋碎石簇、少量脚印/骨屑/落叶/石灰粉。细节留白，不能均匀散点。
- 水面只出现在 J3 和 J10 的浅层沟洼，低于可走地面并留出可见岩缘，不能覆盖道路或区域面。

## 6. 实现顺序

1. 在当前提交上建立回滚点，写入本设计文档。
2. 重写一次性烘焙脚本中的路网与岩壁构件，并运行 `--overwrite` 生成落盘场景。
3. 静态检查：区域数量、连续地面/道路数量、入口标记、墙体碰撞、禁止遗留名和细分尺寸。
4. GPU 运行检查：普通/像素画面、俯视、正面、侧面、旋转和玩家尺度同框；确认无重叠、共面、悬空、闪烁和封闭入口。
5. 对失败项回到脚本修改后重新烘焙、重新验证，直到所有检查通过。

## 7. 验收阈值

- `validate_scene_spec.gd`、`validate.gd`、`validate_walk.gd` 全部通过，失败数为 0。
- 场景中不存在 `GroundCell_`、`Segment_`、`LowStoneKerb`、冷光矩形块或旧木路遗留节点。
- 14 个区域都有连续地面和独立岩壁组；路线数量与连接账本对应，且任意两条道路的面投影不重叠。
- 至少 16 个独立墙体/岩壁碰撞段，所有入口净空可读。
- 最终提交包含设计文档、烘焙脚本和落盘 `world.tscn`，并保留可回退提交。
