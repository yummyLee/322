## 一、坐标系与场景结构

| 项 | 约定 |
|----|------|
| 网格 | **1 格 = 16 px** |
| 轴向 | **X 向东、Y 向南**（屏幕向下为南） |
| 原点 | 区域西北角 `(0, 0)` |
| 章内地图尺寸 | **400 × 520 格**（6400 × 8320 px），单张无缝中图 |
| 建筑门 | **一律朝南**（矩形南缘正中，门宽 4 格） |
| 院落 | 建筑在北、院子在南；主路在建筑南侧 |
