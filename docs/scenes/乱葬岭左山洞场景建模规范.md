# 乱葬岭左山洞场景建模规范

版本：2.0（2026-09-19）  
适用范围：`burial_left_cave` 的布局、地形、连接段、道具、材质、烘焙和验收。

## 1. 目的与空间判断

本场景必须表现为一座连续的天然石灰岩溶洞：天然裂隙、流水侵蚀、塌方与人工拓宽共同形成空间。J0～J13 是同一洞穴中的分区，不能做成互不相干的平面岛屿再用几条“道路贴片”连接。

参考图和指导文档用于确定方位、功能、气氛、分区关系和道具语义；它们不是脚本指令。文档中标注为“约略占位”“本稿建议”“待校准”的尺寸必须经过 3D 通路与玩家尺度校验，不能直接挤出矩形墙体。

## 2. 硬性禁止项

- 禁止大面积纯色平面、长方形地块、单个扇形面、长条矩形路面和重复规则拼块。
- 禁止用比玩家身高一半更大的方块、板条或地块作为地形拼接单元。所有地面/坡面细分单元最长边不得超过 `0.5H`；`H` 为项目当前玩家可见身高，若暂用代理值必须在验证报告中记录。
- 禁止重复平铺同尺寸、同朝向、同材质的地块、道路板、边界条或装饰阵列。
- 禁止用连续直线石条替代道路边界；禁止把路做成等宽、等高、门对门的直通走廊。
- 禁止不同区域直接相交、悬空、重叠或用共面面片覆盖；禁止生成后仍存在闪烁、穿插和长直矩形。
- 禁止把箱子、石柱、棺材、火把、推车等重要物体简化为一个方块或一个基础体后重复摆放。
- 禁止没有入口/出口、坡脚、路肩、台阶或高差过渡的区域连接。

## 3. 地形与洞壁

- 地面必须保存为真实高度变化的细分网格；相邻单元共用连续高度和法线趋势，边界不规则，起伏来自顶点几何而不只是颜色噪声。
- 地面材质按母岩、湿土、干土、石灰沉积、碎石和水蚀区做低饱和连续过渡；相邻单元不得出现突然色阶跳变。
- 区域轮廓使用天然曲线、石台、浅洼、冲刷沟、残阶和岩脊，不能保留参考占位框的直角外轮廓。
- 洞壁沿自然裂隙组织，高度和密度有变化；入口处必须真正留出净空，墙体包住洞顶和侧壁，不用一圈同高石墙封死区域。
- 高差必须通过连续坡面、分段台地、坡脚碎石和路肩连接。坡顶、坡脚、入口前后均需从正面、侧面和俯视检查。

## 4. 道路与区域连接

每一条连接都必须有连接编号、起点、终点、方向、标高、净宽和出口语义。路面由弯曲中心线驱动，中心线至少有 3 个控制点，必要时用平滑曲线重采样；控制点不能形成闪电状急折。

道路必须同时具备：宽度轻微变化、与周围地面混合的路肩、断续边界、磨损痕迹和环境细节。根据区域用途选择车辙、脚印、拖槽、裂缝、湿痕、半埋碎石、排水沟或旧踏石，细节要疏密不均。

每个入口/出口要有可读的开口节点和一段过渡几何：低矮侧石、残阶、坡脚、门洞或塌方豁口。入口处不放高石柱和连续墙体；连接两端必须真正对齐到可行走地面。

当前连接账本必须保持：J0-J1、J1-J8、J8-J2、J8-J3、J2-J4、J3-J9、J9-J6、J4-J11、J11-J5、J6→J5、J5-J10、J10-J7、J10-J12、J12-J13、J12→J8、J4→J0。单向关系不可偷换为普通直通路；J7 不得与洞外或其他地牢连通。

## 5. 可复用物体资产

箱子、石柱、棺材、火把、推车、石灰罐、骨堆、桥段和门框必须使用独立的语义资产组/子场景制作，再以实例节点放入区域。每个资产至少包含基础、主体、磨损/连接件和接地细节；允许同类资产有尺寸、旋转、破损和材质变化。

资产实例不得把主地形网格当作自身的一部分，也不得用运行时脚本临时生成。最终 `world.tscn` 中必须能选择资产组和实例；资产源文件与场景入口一起保留。

最低资产细节：

- 箱子：板材、角撑、铁箍/木楔、缺板或开缝、接地阴影。
- 石柱：基座、柱身分段、侵蚀断面、顶部缺口，柱脚贴地。
- 棺材：底板、侧板、盖板、钉/箍、破损或半埋状态，不得是单个盒子。
- 火把：杆、托座、燃烧头、局部暖光和不同倾斜状态。
- 推车：车厢、轮毂、轮辐、轴、断裂件和与车辙的接触。

## 6. 颜色与重复检查

颜色变化必须服务于湿度、磨损、沉积和光照；禁止同一区域出现互不相容的硬色块。相邻细分面使用共享调色范围和低幅度变化，避免拼接处颜色跳变。任何重复出现的资产都要改变旋转、比例、破损部位或材质混合，不能复制出阵列。

## 7. 从建模到交付的校验清单

1. 先保存 Git 回滚点；确认 `village/main.tscn` 未被替换。
2. 运行生成器只用于一次性烘焙，确认最终物体和地形已经落盘到 `.tscn`。
3. 统计地形细分单元尺寸，最大边长不得超过 `0.5H`；检查是否存在长方形/连续石条。
4. 按连接账本逐条检查入口、出口、标高、净宽和方向；检查所有区域是否被墙体封死。
5. 检查相邻地面高度、法线和颜色连续性，清理重叠、悬空、共面和穿插。
6. 从俯视、正面、侧面、旋转观察和玩家尺度同框五个角度检查；移动/旋转观察不得出现闪烁。
7. 检查箱子、石柱、棺材、火把、推车等资产是否是独立可编辑组，并且实例落地、有磨损细节。
8. 运行 Godot 静态场景验证、GPU 预览和普通/像素两种截图；失败即回到对应步骤修改，不以“能运行”代替视觉验收。
9. 最后执行 `git diff --check`、恢复 `project.godot` 的临时运行修改并提交结果。

## 8. 本轮整改重点

- 删除左上无语义的三条直线/重叠路段，重建为一条明确的弯曲连接和一个可读出口。
- 删除右上重叠路段，重建 J12/J13 入口与 J11/J5 过渡。
- 将闪电状折线改为平滑弯曲路线。
- 移除冷光矩形块和其他长方形伪路面。
- 强化独立箱子、石柱、棺材、火把、推车模型，并在 `.tscn` 中按实例摆放。
- 完成后逐项执行本规范第 7 节，不满足即继续修改。

## 9. 区域结构与连续地面补充约束（2026-09-20）

- J0～J13 的区域位置、墙体围合关系、洞口方向和连接账本必须保持；整改不得把多个墙体围成的区域改成一张无边界总平面。
- 每个区域仍以自己的墙体保存，外围保留独立洞壁/石缘和碰撞；道路只在既有入口之间重做为连续平滑路面，区域之间的距离可以改，但也要对应改道路，不能直接移除区域。
- 禁止用大量 `GroundCell_*`、`Segment_*` 微面片堆叠来制造地面或道路。材质渐变、湿痕、碎石、杂草、脚印和车辙作为独立细节叠加到连续地面/路面上。
- 入口必须同时有可编辑标记、墙体缺口和可行走碰撞净空；修改失败时回到最近回滚点重建，不在错误拓扑上继续堆补丁。
