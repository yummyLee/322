# 乱葬岭圆顶石墓室内场景描述

## 场景重点

画布约 **2800×1500 px**，人物 **32×32 px = 1 身位**，整体约 **87×47 身位**。圆顶石墓内部是一座被放大的椭圆墓室，中央石棺是唯一视觉核心，环形步道让玩家能完整绕棺查看。空间不靠棺木数量制造规模，而以宽阔空地、厚重石壁和规律铺地表现封闭与年代感。

## 布局

- **墓室轮廓**：可玩区约 **74×39 身位**，外轮廓近椭圆，内部碰撞边界保持平滑，不切成多间小墓室。
- **中央棺台**：椭圆地面中央设置约 20×10 身位的低石台，台上横放 14×5 身位石棺；棺台四周留 6～9 身位环行通道。
- **北侧祭置区**：北壁凹龛内放一张 10×3 身位石案，两侧各有一只陶瓮；凹龛不做深通道。
- **东西壁龛**：两侧各设三个浅壁龛，仅保留少量空陶罐、铜钱和腐朽木片，避免形成宝物陈列墙。
- **南侧入口**：5 身位宽石门位于正中，门内铺一段 12×6 身位的下沉石阶；南缘不展示墓门外立面。

## 关键物件

- **中央石棺**：墓室主视觉，棺盖略微错位，边缘有旧撬痕；内部内容只在交互时呈现。
- **北侧石案**：案面保留干涸灯盏和一只裂口祭碗，不摆文字牌位。
- **洛阳旧戳残件**：收在石棺西北角的小石匣中，外观只是半枚旧金属印块。
- **排水孔**：石台南侧地面有一条浅槽通向墙根，暗色沉积沿槽集中分布。
- **空壁龛**：多数保持空置，局部积灰轮廓暗示原有陪葬物已被搬走。

## 美术约束

- 深灰石、灰褐尘土与少量铜绿为主；光照均匀偏暗，石棺顶面比四周略亮。
- 环形构图必须一眼可读，墙壁与中央棺台之间保持大片净空，不摆满骨骸和陪葬品。
- 纯俯视像素；不画可读文字、光柱、透视景深、夸张鬼火或南侧外墙立面。
