# 山地场景（mountain1_scene）设计说明

## 概览

探索场景。**当前 `mountain1_scene.tscn` 实际使用的背景贴图是 `resources/world/testworld.png`**（历史遗留：早期使用的 `moutain1.png` 仍保留在 `resources/world/` 下作为候选素材，可按需切回）。  
背景图缩放 0.5 倍展示，场景世界空间为 **1376×768 单位**，坐标原点居中。

> 下文「碰撞体布局」与「可通行道路」是基于早期 `moutain1.png` 的像素坐标标注；切换到 `testworld.png` 后部分墙体位置和图像不完全对齐。如果后续重新确定贴图，请同步更新像素区间。

## 访问方式

在任意场景按 **U 键** 打开调试场景跳转菜单，选择 **"山地场景 · 石径探幽（mountain1）"** 即可进入。  
进入场景后同样可按 U 键跳转至其他场景。

## 碰撞体布局

道路限制采用 **StaticBody2D 不可见墙体** 实现，将非道路区域封堵，玩家只能在道路范围内移动。

坐标转换公式（原图像素 → 场景坐标，缩放 0.5）：
```
scene_x = img_x * 0.5 - 688
scene_y = img_y * 0.5 - 384
```

| 碰撞体节点 | 封堵区域（原图坐标） | 备注 |
|------------|---------------------|------|
| LeftCliff | x:0-250, 全高 | 左侧黑色悬崖 |
| UpperLeftRock | x:250-850, y:0-420 | 左上岩石区 |
| TopRightArea | x:1080-2752, y:0-200 | 上方非可通区域 |
| Pond | x:1900-2600, y:220-1020 | 右侧水池/湖泊 |
| LowerRight | x:1500-2600, y:950-1536 | 右下草地 |
| LowerCenter | x:700-1500, y:1020-1536 | 下方中段草地 |
| LowerLeft | x:250-700, y:1050-1536 | 左下草地 |
| PagodaBlock | x:1480-1820, y:490-810 | 中央凉亭建筑 |
| TopBound / BottomBound / LeftBound / RightBound | 场景四边 | 防止玩家出界 |

## 可通行道路

图中可通行区域（沙土小径）：
- **主路**：左下角 → 中央（穿越踏石区）→ 石阶 → 上方区域
- **凉亭支路**：主路中段向右延伸至凉亭及木桥
- **石阶**：约图像 x:770-1100, y:100-560，连接中段与上方平台

## 玩家出生点

当前场景里 `Player` 实例坐标 `(-338, 62.7)`（见 `mountain1_scene.tscn`）。对应早期 `moutain1.png` 原图约 `(700, 893)`。

## 后续优化建议

- 可将矩形碰撞体替换为 **Polygon2D + ConcavePolygonShape2D** 以更精确贴合路径边缘
- 可添加 NavigationRegion2D 支持 NPC 寻路
- 凉亭处可添加互动物体（参考 `chapter1/interactable_object.gd`）
