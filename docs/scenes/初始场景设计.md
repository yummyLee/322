# 初始场景设计

> 玩家出生点：周伯屋东间卧房。第一个可探索的室内场景。

---

## 一、卧房室内

**坐标**：周伯屋东间 `bld_zhou_house`，建筑中心格 (200, 228)，32×10格。

**空间**：约10×8格的小房间。三面为土坯墙（黄褐），南面开门通向堂屋。东墙高处开一扇小窗。

**地面**：夯土地面，压实光滑，长期踩踏呈暗褐色。床边铺了一块编织草席。

### 物件

| 物件 | 位置 | 描述 |
|------|------|------|
| 木床×2 | 西墙下（周伯）、东墙下（槐生） | 松木架子床，铺稻草垫+粗布褥。槐生床头搁板放一本翻烂的《千字文》，封面卷边，纸页泛黄。 |
| 矮桌 | 房间正中 | 旧榆木，桌面坑洼，一角被烛火烧出焦痕。桌上一个粗陶碗、一双竹筷。 |
| 衣箱 | 东南墙角 | 樟木旧箱，铜扣生绿锈。箱盖半开，露出叠好的灰布衣。 |
| 墙上旧剑 | 西墙，周伯床头 | 黑漆剑鞘，鞘尾铜箍磨损露黄。挂在两枚木钉上，位置偏高（少年够不着）。 |
| 小窗 | 东墙高处 | 木框糊纸，纸已泛黄。窗缝透青灰天光。窗外可见村中几缕炊烟，远处山影。 |

**光源**：清晨。主要光源来自东墙小窗（冷灰白光）和南侧堂屋透入的光（暖黄，周伯在堂屋点了油灯）。室内整体偏暗，物体边缘柔和。

**色调**：土黄（墙）+ 深褐（地面/木器）+ 灰蓝（天光）+ 一点暖橘（堂屋灯光）。

---

## 二、堂屋（卧房出门即是）

**空间**：约12×10格。房屋正中，南门通院子。

### 物件

| 物件 | 位置 | 描述 |
|------|------|------|
| 方桌 | 中央 | 老槐木，四条长板凳围放。桌面有茶杯烫出的白圈。 |
| 水墨挂轴 | 北墙 | 纸本，画远山与一座孤峰，峰顶有树。笔墨极简，无题字落款。 |
| 香案 | 东墙 | 矮木案，案上供一块无字木牌（巴掌大，素面无纹）。案前一只小香炉，炉内积了厚香灰。 |
| 书箱（上锁） | 西北墙角 | 樟木箱，铜锁。箱面刻"周"字。 |
| 油灯 | 方桌上 | 粗陶灯盏，棉芯，火光暖黄。灯下摊开一册手抄本，墨迹未干。 |

**南门**：双扇木门，敞开着。门外可见院子夯土地面、碎石矮墙、墙角草药畦。更远处是村路和对面人家的茅草屋顶。门框上方横楣贴着一张褪色的红纸（去年春节的"福"字）。

---

## 三、院子（出门即景）

**范围**：周伯屋南侧，约32×14格。碎石矮墙围合，墙高半人，爬满枯藤。

### 物件

| 物件 | 位置 | 描述 |
|------|------|------|
| 木桩靶×3 | 东南角 | 松木桩，裹粗绳。近靶、中靶、远靶各一，桩面有剑痕。 |
| 草药畦 | 西南角 | 约2×2格小畦，种着薄荷和几株矮草。畦边插了一圈枯枝当围栏。 |
| 柴垛 | 西墙根 | 劈好的青冈木柴，垒半人高。垛顶盖了一片破瓦挡雨。 |
| 石墩 | 院门内侧 | 一块平顶山石，当凳子用。石面被坐得光滑。 |
| 油纸灯笼 | 屋檐下 | 竹骨纸糊，悬于堂屋门外横梁。灯纸被油烟熏出焦黄，透光呈暖橘色。 |

### 院外视野

出院子矮墙向南望：
- **脚下**：村主路（夯土，东西向车辙两道），路面散落碎炭渣。
- **正南**：村中央空地的大槐树树冠（约60格外），树下一口石井。
- **东南**：木匠家的茅草屋顶在树影间露出一角。
- **西南**：瞎眼阿婆屋的矮屋檐，檐下晾着两件灰白旧衣。
- **远处**：南面山影层层淡出。西侧可见乱葬岭方向有薄雾。北面是后山的深绿林带。
- **天空**：青灰，云层薄而匀，太阳尚未翻过东山。几只鸟（非鸦探）在村上方低飞。

## 五、初始可探索范围

出门后，以周伯屋为中心可自由走动的区域：

- **向北**：穿过院子北侧 → 夜塾（废弃柴房改建，布帘遮窗）→ 出村 → 炭道 → 后山炭窑群
- **向南**：沿村主路 → 经祠堂横路（祠堂青砖墙、院门半掩）→ 村中央空地（大槐树+石井+石磨）→ 村口牌坊（青石柱+老槐树）
- **向东**：绣坊岔道 → 哑姑绣坊（窗前五色绣线）→ 胡老大窑坊（院堆炭篓）→ 双生兄弟家
- **向西**：井台小径 → 猎户小路 → 燕九屋（屋檐挂兽皮）
