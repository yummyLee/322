# 北坡过渡带场景描述

> 俯视角室外场景。深秋午后。窑村大地图 **右上角补图区** —— 衔接乱葬岭北缘、窑村西北坡、后山炭窑群南麓。  
> **贴图**：整条约 **2800×800 px**，左→右三块，每块 **900×800 px**。  
> **尺度**：角色约 **64×64 px** → 单块可玩面宽约 **14 身位**、深约 **12 身位**；宜 **1 条主路 + 1 处地标**，余为林坡与空地。大块建筑（主窑全貌、神龛、藏书洞等）在 **本条贴图以北/以东的延拓区**，此处只画 **入口一截或远景**。

**整体**：西高东低、北高南低。西接乱葬岭林线，南接窑村（燕九屋、村北炭道），东接后山窑群。色调自 **灰冷林** → **青冈坡** → **炭烟暖**。

## A · 岭北林缘（900×800）

### 一、地形与方位

西北高、东南低。乱葬岭柏树林 **向东收束** 的最后一截；南缘能瞥见燕九屋后墙与树冠。地表灰白泥石渐变为褐腐叶土。

### 二、建筑与可探索点

本块 **一处地标**：西南 **老槐根下洞** —— 树根拱起，露出矮石口（约 2×1 身位）；洞外两三步有 **无顶石亭基**（四柱，顶已失），燕九作「莫再西行」界标。洞浅，不通大穴；可交互刻痕「燕」。

不另设界石排、废窑、栈台等——林缘气氛靠 **树与苔** 完成。

### 三、道路

**一条** 林道沿 **北缘** 向东出块，宽仅一人；南缘 **草径** 下坡接燕九屋后（猎户小路北岔）。无车路。

### 四、植被

半枯 **柏** 为主，越往东 **青冈** 增多。老槐一株（即根下洞）。林下高草及腰，叶色带灰绿（乱葬岭余韵）。

### 五、岩石与地面

西半碎灰岩、灰白苔藓；东半腐叶厚。无夯土。

### 六、色调与光照

午后林隙光， **青灰偏冷**。西望薄雾，东望渐暖绿。

---

## B · 北坡攀升（900×800）

### 一、地形与方位

北高南低，村北 **第一截上坡**。西接 A 林道；东接 C 台地坎；南缘为 **炭道** 自村里上来的起点。碎石渐多，已有锯末与淡炭味。

### 二、建筑与可探索点

本块 **两处**，均不宜过大（各约 3×2 身位级）：

- **柴垛场**（偏南、贴炭道）：两垛青冈、一垛松枝，旁放斧与锯架。R1-01 伐木入口； **不画工棚** 。
- **废窑 `bld_abandoned_kiln`**（偏东、路北）：半塌窑口一截，外草淹没。M1-03 藏人、M1-06/07、M1-12 用；窑内一线天光即可，体量 **半座小窑** 。

药草丛可在废窑西侧画 **一小丛**（R1-04）；不单独占区。

### 三、道路

**北山炭道** 为本块主轴：自南缘北上，宽可容炭车，两道辙、碎炭渣；北出接 C 块台阶。林道自西 **斜穿** 后在柴垛旁并入炭道——仅此 **一路网** 。

### 四、植被

青冈、栎为主；柴垛旁清出空地。西缘残存半枯柏一两棵。

### 五、岩石与地面

南半土路夯实；北半碎石坡。废窑周炭黑染土。

### 六、色调与光照

饱和度较 A 回升：深绿 + 土黄路 + 褐木垛 + 东缘淡烟。乱葬岭 ↔ 后山的 **色调中点** 。

## C · 窑群南麓（1800~2800）

### 一、地形与方位

人工 **劈坡台地** 的 **南缘一截** —— 玩家在此仰望窑体，而非俯瞰全村。北缘台地之上、贴图外另延：副窑、神龛、藏书洞等（见 `窑村场景详细设计.md` 第四节， **不在本 900×800 内** ）。

### 二、建筑与可探索点

本块 **一处主景 + 一处远景暗示**：

- **主窑南坡 `bld_main_kiln`（局部）**：馒头窑 **出炭口与下半截窑壁** 占块中北（约 4×3 身位可见）；顶口与添柴口可画在 **北界外** 。M1-01、S1-06 锚此；南面 **几只炭篓** 即可，不画大片炭场。
- **北上行台阶**（块东北）：几级石阶没入林线，示意通往神龛/高洞—— **只画阶头** ，神龛本体不画。

不画副窑 B/C、窑工棚、环道全车宽——那些在北延贴图。

### 三、道路

炭道自 B 块 **顶到台地南缘** 即止；装炭、上车在窑前 **小平台**（约 3 身位宽）。北阶仅供人行上延。

### 四、植被

台地内清伐；南缘台下与 B 块青冈衔接。北侧贴图外为针叶林。

### 五、岩石与地面

台缘 **废石堆** 一圈（画南侧一段即可）。地面炭灰黑，窑壁黄泥灰石。

### 六、色调与光照

午后 **烟柱直、偏暖** 。炭黑 + 暗红窑口 + 灰白烟。本三条贴图 **东端视觉锚** 。
