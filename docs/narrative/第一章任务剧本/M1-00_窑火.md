# M1-00【窑火】

## 定位

- 运行时 ID：`main_01_000_kiln_breakfast`
- 章节：第一章【槐下萌芽】
- 类型：不可重复主线序幕
- 一句话概括：深秋清晨，槐生替周伯把一篮热饼送到后山窑场，在一顿寻常早饭里认识了日后可能失去的人。
- 情感目标：让玩家感到“这里的人认识我、需要我，这是我的家”，并为塌窑事件建立具体的人命重量。

## 触发与状态

1. 新游戏进入周伯屋左门房间，玩家可自由探索旧书箱、书桌和饭桌。
2. 玩家从左门出屋，靠近菜地里的周伯后自动触发开场对话。
3. 对话结束后接取任务，并以剧情载荷的方式获得“热饼篮”。
4. 与后山窑场的三娃交互，完成专属交付对话后，任务自动完成并交付。

防重复记录：

- `ch1_m1_00_intro_started`：开场对话曾经开始，用于诊断；若异常中断且任务未接取，允许安全重播。
- `ch1_m1_00_intro_finished`：周伯已经派发任务。
- QuestManager 的 active/completed 状态：防止任务重复接取和重复发奖。

## 场景一：菜地

**旁白**：周伯蹲在菜畦边，正把一片发黄的叶子掐下来。露水沾湿了他的袖口。

**周伯**：醒了？昨夜又看书看到几更？

**槐生**：没多晚。

**周伯**：油灯少了半寸。你小时候撒谎先摸鼻子，如今倒是学会不摸了。

**槐生**：您在这儿等我？

**周伯**：等你，也等日头把露水晒干。石墩上那篮热饼，给后山窑场送去。三娃和石锁天不亮就上工，多半又拿凉水对付肚子。

**槐生**：胡叔不是管饭吗？

**周伯**：他管一窑人的饭，未必顾得上两个半大小子。去吧。饼若凉了，他们也会笑着说热。

**槐生**：那我走快些。

**周伯**：走稳些。篮子翻了，跑得再快也没用。

## 场景二：窑场交付

**旁白**：你刚把篮布掀开，白汽便裹着麦香冒了出来。

**三娃**：槐生哥？你来得正好。我刚跟石锁说，闻着村里的炊烟也能顶半顿。

**槐生**：周伯让我送来的。他说你们又拿凉水当早饭。

**旁白**：三娃抓起一张饼，被烫得左右倒手，嘴上还不肯认：“谁说的？我今早还嚼了两颗生栗子。”

**旁白**：石锁把篮子接稳，数出一张放回布下：“这张给胡叔。他昨晚守火，到现在还没合眼。”

**槐生**：你们先吃。我去看看窑口。

**旁白**：三娃已经塞得两颊鼓起，只能用力点头。石锁朝你笑了笑，把那张留下的饼裹得更严实了一些。

## 后续接口

任务完成时暂不自动接取 M1-01。待“塌窑”关卡可玩后，为 M1-01 配置：

- `prerequisites = ["main_01_000_kiln_breakfast"]`
- `auto_accept_when_unlocked = true`

这样可在不修改 M1-00 脚本的前提下连续推进。
