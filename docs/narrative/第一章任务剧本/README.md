# 第一章任务剧本索引

> 本目录只归档《槐火》fable5 版第一章任务对白与演出文本。世界观总纲仍以 `../../剧情设计fable5v1.md` 为准。

## 编号规则

- `M1-xx`：第一章主线，按剧情顺序排列。
- `S1-xx`：第一章固定支线。
- `R1-xx`：第一章重复或随机委托。
- 运行时任务 ID 使用 `main_01_xxx_name` / `side_01_xxx_name`，编号一经进入存档不得改名。

## 归档要求

每条任务独立一份文档，至少包括：一句话概括、情感目标、触发条件、防重复规则、任务目标、完整对白、结束状态和后续任务接口。代码改动涉及对白时，必须同步对应剧本文档。
