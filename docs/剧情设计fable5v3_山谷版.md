# 《槐火》剧情设计 fable5 v3 · 山谷版（废案保留）

> **状态：已废止，不作为后续制作依据。**  
> 废止原因：错误地把“以现有窑村地图作为第一章起点”理解为“全作不离开窑村”。  
> 修正版见 `docs/剧情设计fable5v3_章节扩展版.md`。

> 类型：2D 俯视角、章节制、剧情动作冒险  
> 目标体量：单周目约五小时  
> 核心制作原则：以现有窑村、后山窑场、乱葬岭、地下窑洞和室内场景为主体，让天下进入山谷，不让主角跑遍天下。  
> 本文是面向低美术成本与低开发成本的重构提案；确认后再取代 `剧情设计fable5v2.md`。

# 一、作品的新形态

## 1.1 一句话概括

亡国遗志所化的少年槐生，一直以为自己只需要守住窑村的一炉火；当征服王朝准备封死陉口、掘开祖坟、把整座山改造成军炭庄时，他必须联合彼此仇视的人与妖，在同一片山谷里决定旧国、百姓和两族未来谁更值得被保全。

## 1.2 核心体验

玩家不是周游天下的英雄，而是一个越来越了解家乡的人。

同一口井，最初是村民闲谈之处，封锁时成为配给点，焚村时成为救火点，结局时成为两族共同立约之处。同一条炭道，最初运饼和木料，中期运军炭与尸体，终章运送逃难者或反攻队伍。

游戏的主要乐趣来自三件事：

- 熟悉地图，并在地图状态改变后重新理解它。
- 用战斗、潜行和环境操作保护具体的人，而不是处理抽象天下大事。
- 让玩家的处置改变山谷中的人际关系、兵力和终局，而不是生成大量平行关卡。

## 1.3 明确不做

- 不做半开放世界和大舆图旅行。
- 不做七座城市和八王逐个讨伐。
- 不做阵营声望、随机委托、日程模拟和大量可消耗支线。
- 不做八套一次性谜题框架。
- 不做同伴编队、复杂装备词条和大规模城战。
- 不为三结局分别制作三套终章地图。

## 1.4 规模上限

| 内容 | 上限 |
|---|---:|
| 主线任务 | 10 个 |
| 正式 Boss | 3 个 |
| 精英战 | 3 个以内 |
| 可探索室外地图 | 现有主地图分区 + 1 条短连接路 |
| 室内地图 | 优先使用现有室内；新增不超过 2 间 |
| 核心有名角色 | 8 人 |
| 通用敌人骨架 | 4 类 |
| 结局 | 3 个文本与场景状态变体，共用终局空间 |

# 二、保留的叙事灵魂

## 2.1 固定设定

- 作品名仍为《槐火》。
- 主角槐生是承祯帝遗诏、白绫怨气与老槐精魄凝成的遗志，不是皇帝转世。
- 周念椿是槐生养父，也是教村民识字的先生。
- 二十字血诏不变：“朕死，无面目见祖宗。任尔分朕之尸——勿伤百姓一人。”
- 三个价值方向仍为社稷、苍生、化育。
- 人妖冲突源于土地、军役、身份和司法制度，不解释为族群天性。
- 周伯固定死亡，但他的死亡由主动选择造成，不由玩家任务失败造成。
- 最终问题仍然是：遗志要求槐生复国、救民，还是阻止新的报复循环。

## 2.2 从宏大历史改为山谷切片

玄朝正在北境用兵，需要大量木炭、铁器与运输牲口。摄政王金獾下令把太行陉口改设为直属军炭庄：圈山、查户、追逃、迁坟、封路。

这道命令把原稿中的多种制度矛盾压进一个可见地点：

- 圈田：山林、泉水和窑场被写成王产。
- 投充：欠税村民被迫编入军炭庄。
- 身份司法：妖兵伤民由军法内部处置，人族抗命则全村连坐。
- 修史灭忆：乱葬岭埋着三十年前漯阳屠城的无名死者，官方要掘坟烧骨，消灭旧案证据。
- 八纛生计：驻守汛塘的底层妖兵同样欠饷，被迫靠克扣炭粮活命。

天下大势通过难民、军令、名册、墓碑、货物和人的伤口进入山谷，不需要展示七座城市。

# 三、舞台与地图复用

## 3.1 主舞台

现有地图直接成为完整游戏舞台：

| 地点 | 开篇用途 | 中期用途 | 终章用途 |
|---|---|---|---|
| 周伯屋与夜塾 | 家、教学、日常对话 | 藏伤员与禁书 | 周伯遗物处置、路线锁定 |
| 窑村中央与水井 | 认识村民、交付早饭 | 配给、审户、公开惩罚 | 决战后的立约场地 |
| 村祠堂 | 村议与祖先牌位 | 临时军署 | 三衡抉择与结局碑 |
| 后山窑场 | 劳作教学、塌窑救人 | 军炭生产、工人抵抗 | 焚窑或夺窑战场 |
| 地下旧窑洞 | 探索、发现藏物 | 藏匿逃人与史料 | 最终 Boss 战主要空间 |
| 乱葬岭 | 猎踪、无名碑 | 掘坟冲突、恢复姓名 | 两族死者共同墓地或封禁区 |
| 猎人小屋 | 燕九与雪爪的家 | 侦察据点 | 撤离者中转站 |
| 石祠小庙 | 环境叙事 | 两族秘密会面 | 化育线立誓处 |
| 村口与南陉道 | 送饼、进出村 | 关卡、难民与军队到来 | 援军方向与结局远景 |

王家坞堡、陉口镇和汛塘若当前尚未完成，不作为首发刚需。王家势力通过进入窑村的账房、运炭队和巡兵表现；需要室内潜入时，复用胡老大窑坊室内并改陈设为临时账房。

## 3.2 四次地图易貌

### 状态 A：深秋日常

暖土色、炊烟、窑火与稀疏落叶。道路开放，村民处于日常位置。重点是让玩家认识家园。

### 状态 B：初冬封锁

村口出现界桩、绳索和检查棚；祠堂外贴军炭告示；窑场堆放编号木料；乱葬岭出现掘坟标记。只需增加覆盖物、巡逻和封路碰撞。

### 状态 C：雪夜占领

积雪、火盆、巡逻灯、军帐和封锁线。周伯屋成为伤员点，祠堂成为军署，窑场夜间强制开工。主要通过光照、敌人和少量道具改变体验。

### 状态 D：焚后黎明

局部焦黑、倒塌棚架、余烟和残雪。并非全村换图，只替换粮棚、祠堂前、村口和窑场等关键节点。结局再以旗帜、碑文、开放或封闭的道路表现制度差异。

# 四、主要人物

## 4.1 槐生

十七岁的炭工少年，温和、嘴拙、怕黑、认死理。开场只想把饼送到、把窑火守住。故事推进中，他逐渐发现自己并非某位帝王的继承人，而是一道未完成的问题。

玩法身份只有一套：承槐木剑负责近战和格挡，白绫负责牵引、缴械及环境互动。“文心”不再发展成庞大技能树，只保留“辨名”这一核心能力：读取被涂改、烧残和重叠的文字。

## 4.2 周念椿

槐生的养父。前朝翰林，三十年来在夜塾用沙盘教人写字。他保存的不是复国兵书，而是漯阳屠城死者名册与玄朝早期军令副本。

他的矛盾是：他教槐生不能遗忘忠义，却最怕槐生为一个死去的朝代牺牲活人。

## 4.3 燕九

猎户，也是玩家最常见的现场伙伴。父亲死于妖军征鹰，因此拒绝相信妖族的善意。她不承担恋爱线；她的弧光是从“所有妖都该还债”走到“罪应当有名字”。

她主要通过远处射箭、猎鹰提示和战中呼喊提供帮助，无需完整同伴 AI。

## 4.4 阿芦

逃离军炭庄的窑奴，右腕留有投充烙印。他带来的不是开启下一座城市的线索，而是一份即将把窑村全体编为庄奴的新户册。

阿芦熟悉地下旧窑洞，是剧情中连接制度暴力与具体劳作的人。

## 4.5 哑姑

不能说话的绣娘，用暗纹保存被禁的日月图案，也用绣线记录死者姓名。她不是任务发布器，而是“无声保存记忆”的人物象征。

终章前，玩家收集到的姓名会出现在她铺开的长布上；无需制作独立收集界面。

## 4.6 老格

驻守汛塘的老妖卒，原形是灰狼。多年欠饷，儿子偷偷在周伯夜塾识字。他执行过追逃命令，也曾悄悄放走孩子。

老格不是无罪好妖。他是否愿意在终章打开村口封锁，取决于玩家此前是否保护他的孩子、是否处死投降妖兵以及是否保存妖卒欠饷名册。

## 4.7 王敛

人族豪强，主动承包军炭庄。他证明压迫并非只来自妖族。他不需要专属战斗动画，主要以立绘、普通 NPC 形体和家丁战斗呈现。

王敛相信政权换多少次，账房永远比刀活得久。玩家最终可以公开账册使其失势，或利用他组织生产，由此承担不同后果。

## 4.8 巴掩

鼬妖佐领，陉口封锁的实际执行者，也是游戏第一个正式 Boss。他地位不高，因此极度依赖令牌和连坐制度维持威严。

巴掩死后，玩家才发现杀掉一个坏官并不会让军炭令消失。

## 4.9 金獾

摄政王、游戏最终敌人。他不在前期反复露面，只通过军令、印章与别人对他的恐惧存在。终章来到陉口，是因为地下旧窑藏着能证明玄朝开国屠城与侵吞军籍的原档。

金獾只制作一套人形战斗素材，通过披甲、掘地冲击和场地塌陷形成阶段变化，不制作三套兽化形态。

# 五、完整剧情结构

## 第一幕【一炉秋火】

目标：让玩家爱上这张地图和住在这里的人。时长约一小时。

### M1【热饼】

直接沿用现有 `M1-00【窑火】`：槐生从周伯屋醒来，把热饼送到后山窑场。

途中玩家会经过水井、祠堂、村口和炭道。任务不设置战斗，不介绍天下设定，只通过村民叫槐生名字、托一句话、让一条路，让玩家感到自己属于这里。

到达窑场后发生轻微塌方。玩家第一次使用移动、冲刺和环境交互，救出小栓并扶正通风木板。塌方不是阴谋，只表现窑工生活本就危险。

任务结束：三娃把留给胡老大的饼重新包好。玩家记住这些人。

### M2【岭上的名字】

燕九发现乱葬岭最近有陌生脚印。槐生随她沿猎户小路追踪，学习基础战斗与猎踪。

敌人只使用现有野兽。脚印最终进入石祠小庙，玩家发现一块被刮去姓名的旧碑。白绫第一次自行伸出，炭灰中短暂显出几个名字。

回程时，两人发现负伤的阿芦藏在废窑。他只说：“他们不是来抓我一个，是来收整座山。”

任务结束：玩家选择把阿芦藏在地下窑洞、猎人小屋或交给周伯。三种选择只改变下一任务的入口和一两段对话，不生成独立任务线。

## 第二幕【山有了主人】

目标：让日常地点被制度逐步占据。时长约一小时二十分钟。

### M3【白绳落地】

巴掩、王敛和巡兵从南陉道进入窑村。他们不立刻杀人，而是丈量水井、林地与窑场，在道路上拉起白绳。

王敛宣布：窑村欠下的旧税可以免除，代价是全村投充军炭庄。巴掩给三天期限。玩家必须在巡逻形成前抢出旧地册和新户册。

行动发生在熟悉的村庄中：跟随书办、绕过巡逻、从胡老大窑坊的临时账房取证。任务支持潜行，也允许被发现后直接短战。

玩家取得两类证据：王敛伪造地册，以及底层妖卒被克扣军饷的账页。二者分别服务于苍生与化育方向，但不显示加分提示。

### M4【窑下之窑】

阿芦带槐生进入现有地下旧窑洞。这里不是普通迷宫，而是全作唯一大型探索空间。

玩家沿车辙、炭痕和旧木撑寻找三十年前藏入山腹的箱子。途中遭遇王家家丁和被派来探路的妖兵。敌人也可能被塌方隔断，玩家可救或不救。

箱内是漯阳屠城名册、早期军令副本和周伯的翰林印。槐生由此质问周伯。周伯承认他的身份，却明确说：“你是遗诏留下的一问，不是遗诏册立的皇帝。”

本任务只使用一种贯穿全作的文字机关：辨认被烧毁或覆盖的字。之后所有证据互动复用同一规则。

### M5【村口法】

期限到来。巴掩在村口抓捕阿芦，并宣布窝藏者连坐。无论阿芦藏在哪里，他都会主动出现，避免巴掩逐户烧屋。

周伯当众拿出地册，试图把争端限制在官契和个人责任内。王敛命家丁抢册，场面转为战斗。玩家需要保护拿着不同证据的村民退到祠堂，而不是击杀所有敌人。

Boss：巴掩。

- 第一阶段使用短刀、令旗与两名巡兵。
- 第二阶段令旗被毁，巴掩露出鼬尾，以高速突进和烟灰遮蔽战斗。
- 不制作巨大真身。

巴掩败后，玩家可以杀死、交给妖兵军法或将罪证钉在村口。无论如何，远处都会出现更多军炭队的火把。个人胜利没有废除制度。

## 第三幕【雪落无门】

目标：让玩家在有限时间内决定先保什么。时长约一小时二十分钟。

### M6【封山】

金獾的正式军令抵达：封闭南陉道，掘乱葬岭旧坟，窑村全部迁入军庄。祠堂被改为军署，后山窑场昼夜烧炭。

玩家在一轮连续行动中处理三个地点，但只能完整解决其中两个：

- 后山窑场：救出被强迫开窑的工人，取得炸窑用的火药。
- 乱葬岭：阻止焚骨，恢复部分姓名。
- 周伯屋：转移夜塾孩子与书箱，保护老格的儿子。

未选择的地点不会变成“任务失败”，而是留下可见代价。地图随后进入雪夜占领状态。

### M7【先生不走】

燕九准备从地下窑洞带人逃出封锁，周伯却拒绝先走。他发现军令允许“斩一户以儆百户”，于是决定留在祠堂公开认下藏书与藏人的全部罪责，阻止士兵逐户搜杀。

玩家的行动目标不是改变周伯之死，而是：

- 护送尽可能多的村民进入地下窑洞。
- 抢出周伯散落在祠堂与夜塾的姓名册。
- 选择是否救下受伤并投降的妖兵。

槐生赶回祠堂时，周伯已经被处死。这里不播放长篇死亡对白。周伯只留下那条白绫和一句写在沙盘上的话：“先问活人。”

槐生的来历在悲痛中完全显现，但玩家立即要面对燃烧的粮棚，避免觉醒沦为纯演出。

### M8【雪里一把火】

王敛为销毁伪册，命人纵火，并准备把罪名推给逃村者。火从粮棚、祠堂前和窑场三处蔓延。

这是全作的综合关卡，复用同一地图：战斗、开水路、搬开障碍、救人。玩家此前的选择决定谁来帮助：燕九提供远程支援，老格打开封锁，阿芦熟悉窑道，胡老大控制窑火。

精英战：王敛的家丁头目。王敛本人不成为武力 Boss。抓到他后，玩家决定公开账册、逼他调粮或让愤怒村民处死他。这一决定影响终局资源与秩序，而不分出新地图。

## 第四幕【槐根之下】

目标：用一次集中的终局回答全作问题。时长约一小时。

### M9【谁的山河】

金獾亲自进入山谷。他表面为收回屠城原档，实际还要开启地下旧窑最深处的吞天珥分阵。它能维持周边妖军化形，也是玄朝控制底层妖卒军粮与身份的凭证。

槐生在周伯屋、乱葬岭和石祠小庙之间完成最终准备。没有传统支线列表，只有三次“如何使用已有成果”的处置：

- 把血诏交给自称昭朝遗民的人，号召复国。
- 把地册与粮册交给村民，组织共同议约。
- 把屠城名册与欠饷名册并列公开，争取妖卒倒戈。

选择最多的方向决定终章援军与结局倾向；玩家仍可在最终处置中反悔，但要付出更大代价。

### M10【槐火】

终战从后山窑场开始，深入地下旧窑大厅。玩家沿游戏最初送饼的路线逆向而行：村庄、炭道、主窑、旧窑洞。熟悉的道路成为最后战场。

Boss：金獾。

- 第一阶段：披甲长刀与护卫，场地为旧主窑大厅。
- 第二阶段：金獾击断木撑，利用掘地冲击和落石改变道路。
- 第三阶段：吞天珥分阵抽取妖卒生命维持其甲胄；玩家必须在攻击金獾和切断阵眼之间移动。

玩家此前若保护妖卒，老格会带人破坏一处阵眼；若保住窑工，胡老大会引燃旧通风道；若恢复足够姓名，白绫能暂时定住金獾。它们只减少战斗压力，不制作新阶段。

金獾败亡后，槐生在旧窑深处面对吞天珥分阵与二十字血诏，作出最终处置。

---

# 六、三结局

三个结局共用“地下窑洞—焚后窑村—村口远景”三段场景，只替换 NPC、旗帜、碑文、道路状态与旁白。

## 6.1 社稷【树冠】

槐生以血诏号召昭朝遗民，占据陉口作为复国第一座山寨。吞天珥分阵被封存，用作与妖军谈判的筹码。

正向状态：若玩家保护平民、约束私刑，村口立下约法碑，明确军队不得圈田、不得因族株连。燕九负责山口防务，阿芦登记自愿入伍者。

阴影：若玩家多次以复仇解决问题，王敛留下的账房体系会换上日月旗继续征粮。结尾中，夜塾重新开门，但门外已有持枪卫兵检查来人。

## 6.2 苍生【树根】

槐生毁掉吞天珥分阵，把王庄、窑场与山林契据投入窑火。窑村与妖卒家眷共同订立《陉口约》，土地按居住与劳作重新确认。

正向状态：水井旁设置公开粮册，祠堂改作议事与识字之所。村口不挂王朝旗。

阴影：失去旧军粮后，妖卒家庭与贫困村民都面临饥荒。若玩家没有保住粮棚或王敛的调粮网络，结尾会出现漫长配给队伍，提醒玩家烧掉契据不能直接生产粮食。

## 6.3 化育【年轮】

槐生不立刻毁掉分阵，而是限定期限维持需要化形的伤病妖众，同时公开其控制原理和全部名册。人妖共同守住陉口，等待分阶段停用。

正向状态：乱葬岭建立双名碑，人的屠城死者与被玄廷吞没姓名的妖卒分列两面，罪责不相互抵消。老格必须以证人身份承认自己参与过追逃。

阴影：部分村民认为这是宽恕侵略者，部分妖卒认为公开军籍是背叛。石祠小庙成为艰难谈判的常设地点，而不是和解大团圆。

## 6.4 共同结尾

春天，槐生再次从周伯屋提着一篮热饼走向后山。

第一次送饼时，路上的每个人都认识他；这一次，道路和人群已经因玩家选择而不同。到达窑场后，他把最后一张饼留在熄灭的旧窑口。

画面转向村口老槐。树上新叶刚生，白绫没有消失，只是不再绷紧。

# 七、选择与回写

不保留复杂三衡数值和几十个跨章变量。只记录六个可被玩家直接理解的结果：

| 状态 | 取得方式 | 可见回写 |
|---|---|---|
| `names_saved` | 保护乱葬岭与姓名册 | 白绫能力、终局碑文、金獾战辅助 |
| `villagers_saved` | 封山与火灾中的救援 | 终战窑工援助、结局村庄人口 |
| `yao_soldiers_spared` | 救助或接受投降妖卒 | 老格倒戈、化育结局开放 |
| `grain_saved` | 保住粮棚或逼王敛调粮 | 苍生结局的灾后状态 |
| `land_ledgers_exposed` | 取得并公开地册 | 王敛失势、苍生路线权重 |
| `edict_used_for_restraint` | 使用血诏约束己方而非索取效忠 | 社稷结局正向变体 |

最终路线不使用隐藏分数突然裁决。M9 会通过现场支持者、祠堂陈设和对白明确告诉玩家，自己此前更接近哪条道路。

# 八、玩法和系统复用

## 8.1 只保留三种任务结构

1. 探索战斗：沿环境痕迹进入一个区域，遭遇少量敌人，取得具体物证或救出具体人物。
2. 熟图危机：在已经熟悉的地图中发生封锁、火灾或追捕，考验玩家对空间的记忆。
3. 集中 Boss：使用同一套移动、近战、白绫和环境交互，不增加仅服务一次 Boss 的新系统。

## 8.2 两套贯穿机关

- 辨名：斜光、炭粉与白绫共同恢复被覆盖文字。用于地册、墓碑、军令和终局阵眼。
- 窑路：操作风门、水槽、撑梁和火道。用于救人、灭火、制造烟幕和终战破阵。

每套机制至少复用四次，逐步增加组合，不制作一次性文化小游戏。

## 8.3 敌人资源

| 骨架 | 变体方式 |
|---|---|
| 野兽近战 | 狼、山獾用色调和参数区分 |
| 人形近战 | 家丁、妖卒、王府护卫换衣色与武器 |
| 人形远程 | 猎弓、军弓换弹道与站位 |
| 精英/Boss 人形 | 巴掩与金獾各自一套核心轮廓和攻击特效 |

燕九、老格等援助人物通过预设射击点、开门事件和一次性技能表现，不建设通用同伴系统。

# 十、制作顺序

## 第一阶段：可玩序幕

完成 M1【热饼】和 M2【岭上的名字】。目标是验证：现有地图移动是否舒服、玩家是否能记住人物、探索到乱葬岭是否形成气氛变化。

## 第二阶段：完整试玩章

加入 M3【白绳落地】至 M5【村口法】以及巴掩 Boss。至此形成约两小时、有开端和阶段结局的试玩版。

## 第三阶段：复用地图状态

制作封锁、雪夜和焚后覆盖物，完成 M6 至 M8。优先验证同一地图变化是否足以产生新鲜感。

## 第四阶段：地下终局

完成 M9、M10、金獾 Boss 与三结局。最后再补必要立绘、插画和环境音，不提前扩建陉口镇或王家坞堡。

# 十一、验收标准

- 玩家在没有小地图箭头时，能凭水井、祠堂、炭道、猎户屋和窑火找到主要区域。
- 第一小时结束时，玩家能说出至少三名村民，以及他们在村中的位置。
- 地图从日常变为封锁时，玩家能意识到熟悉空间被权力侵占，而不只觉得换了天气。
- 周伯之死让玩家感到是人物主动承担的代价，而不是自己没赶上倒计时。
- 三种结局都回答土地、身份和记忆如何处置，不只回答谁当皇帝。
- 全作不依赖新建大地图也能完成起承转合。

# 十二、与 fable5 v2 的关系

v2 仍可作为世界观资料库，保留八纛、玄昭历史、外部世界和完整制度设定；v3 只从中抽取窑村能够亲眼见证的部分。

未在 v3 出场的维扬、玄京、金鸮、金隼等内容不声明不存在，而是通过军令、旧报、人物来历或片尾传闻留下。若首作完成并获得市场反馈，它们可以成为后续作品，而不成为本作必须偿还的制作债务。
