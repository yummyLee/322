# 采集材料目录设计

> **状态**：策划草案（未写入 `item_catalog.json`）  
> **关联**：[采矿与采集草药系统设计](../systems/采矿与采集草药系统设计.md)、[物品与背包系统设计说明](../systems/物品与背包系统设计说明.md)  
> **范围**：**30 种植物**（`HERB`）+ **30 种矿物**（`ORE` / `STONE`）= **60 种**主目录

---

## 0. 规模说明（为何从 200 缩到 60）

### 0.1 参考：100 小时量级 RPG 的材料量

| 游戏 / 类型 | 可采集物大致量级 | 玩家实际常用 |
|------------|----------------|-------------|
| 上古卷轴 5 | 炼金 ~80+ 种 | 常用药草约 25–35 种 |
| 艾尔登法环 | 全材料 ~50 种 | 锻造/附魔核心 ~30 种 |
| 旷野之息 | 矿石 + 地域特材 ~25 种 | 几乎全用得上 |
| 典型 100h 单机 ARPG | **可识别材料 40–70 种** | 核心循环 20–40 种 |

**结论**：200 种（100+100）适合「每样都有独立配方」的大型 MMO 或多资料片；对本项目这种 **100h 开放世界动作 RPG 原型**，60 种更合适——玩家能记住名字，图鉴可集齐，每种都有明确用途，后续 DLC 再往附录扩。

### 0.2 本版配额

| 品级 | 植物 | 矿物 | 说明 |
|------|------|------|------|
| T1 COMMON | 6 | 6 | 新手区全覆盖 |

## 1. 设计原则

### 1.1 与现有系统对齐

| 字段 | 约定 |
|------|------|
| `item_type` | 固定 `MATERIAL` |
| `item_sub_type` | 植物 → `HERB`；矿石 → `ORE`；岩块 → `STONE` |
| `rarity` | 对应采集节点品级 T1~T7 |
| `max_stack` | T1–T2: 64；T3: 48；T4: 32；T5: 16；T6: 8；T7: 4 |
| `weight` | 草药 0.1~0.5；矿石 2.0~6.0；石材 1.5~4.0 |

### 1.2 命名与 ID

- **ID**：`herb_*` / `ore_*` / `stone_*`，小写蛇形。
- **显示名**：2–4 字为主；每种对应 **至少一条** 消耗出口（炼药 / 锻造 / 任务 / 贸易）。
- **已落地**（计入 30+30，不再重复编号）：
  - 植物：`herb_windgrass` 风绒草、`herb_moonpetal` 月瓣花、`herb_redroot` 赤根草
  - 矿物：`ore_copper` 铜矿石、`ore_iron` 铁矿石、`ore_tin` 锡矿石

### 1.3 用途标签（策划用）

| 标签 | 说明 |
|------|------|
| `炼药` | 药剂、Buff 食物 |
| `附魔` | 词条、法术媒介 |
| `锻造` | 锭材、工具修复 |
| `任务` | 交付、图鉴、主线 |
| `贸易` | 城镇收购、以物易物 |
| `元素` | 火/冰/雷/毒/光/暗专材 |

## 4. 区域分布（每区 3–5 种，不堆叠）

| 区域 | 植物（示例 ID） | 矿物（示例 ID） |
|------|----------------|----------------|
| 官道 / 新手村 | windgrass, redroot, mugwort, mint | copper, iron, limestone |
| 平原野外 | licorice, plantain, angelica, coptis | tin, hematite, malachite |
| 河泽 | lotus_seed, salvia | sulfur, fluorite |
| 丘陵浅洞 | astralagus, fritillaria | silver, gold, graphite |
| 高山 | snow_lotus, rhodiola, thunder_bamboo | jade_rough, agate_rough, electrum |
| 深林 | moonpetal, ginseng, lingzhi, mandrake | realgar, garnet_rough |
| 元素秘境 | flame_bloom, frost_thistle, jade_lotus | mithril, firestone, froststone |
| 旧战场 / 饥荒带 | corruption_bloom, plague_wort | corrupted_iron, obsidian |
| 传说节点 | fate_petal, kunlun_ice_lotus, moon_tear, dragon_blood | fate_fragment, kunlun_iron, meteorite |

**原则**：同一区域可见材料 **≤5 种**，避免「每走几步一个新名字」；其余品级在相邻区域或洞穴递进出现。

## 6. 落地 `item_catalog.json` 模板

```json
"herb_mugwort": {
  "item_name": "艾草",
  "name_sort_key": "aicao",
  "description": "端午前后最盛，燃之驱虫，亦入温经方。",
  "rarity": "COMMON",
  "value": 3,
  "icon_color": [0.38, 0.55, 0.32, 1.0],
  "item_type": "MATERIAL",
  "item_sub_type": "HERB",
  "max_stack": 64,
  "weight": 0.15
}
```

**价值曲线**（`value` 金币单价）：

| 品级 | 草药 | 矿石/石材 |
|------|------|----------|
| T1 | 2–5 | 3–6 |
| T2 | 8–15 | 10–18 |
| T3 | 18–35 | 22–40 |
| T4 | 40–80 | 50–90 |
| T5 | 90–180 | 100–200 |
| T6 | 200–450 | 250–500 |
| T7 | 500–1200 | 600–1500 |

## 7. 与任务 / 图鉴

| 系统 | 建议 |
|------|------|
| **COLLECT 任务** | `target_id` 用本文 ID |
| **图鉴** | 全收集 60 条；分「药草 30 / 矿材 30」两页 |
| **节点 drop_pool** | 每节点 1–2 种主产物 + 低概率副产物，不铺 10 种 |
| **贸易** | 收购价 = `value` × 0.6 |
