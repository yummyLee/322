1. **裂地脉动（Ground Pulse）**  
   以鼠标点为圆心，0.8s 预警后连续 3 次同心圆扩散，每次只对敌对单位造成递减魔法伤害并短暂减速（叠一层易伤）。  
   *意图：读走位、惩罚站桩。*

2. **荆棘囚笼（Bramble Cage）**  
   延迟生成环形多边形障碍（类似禁锢圈但留一个随机缺口），圈内敌人移速下降，出圈时受到一次刺击伤害。  
   *意图：地形控制 + 出口博弈。*

3. **逆流风墙（Gale Wall）**  
   在施法方向生成一道短时矩形区域：敌对投射物速度反向/销毁，敌对单位被持续向外推力（用你的“外力通道”思路）。  
   *意图：反弹幕 + 推开。*

4. **血印追猎（Blood Mark）**  
   对单个敌对目标打上 6s 印记：期间你对其造成的任意伤害附带小额吸血；印记结束时若目标仍存活则爆炸造成真实伤害。  
   *意图：单体集火、风险回报。*

5. **幻影分身诱敌（Mirror Decoy）**  
   下一次冲刺，会在冲刺的起点位置召唤不可攻击的和施法者一模一样的幻象 4s，施法者会得到一个隐身buff，持续1.5s，怪物无法看见施法者，原本以玩家为追逐攻击对象的怪为也会以幻想为目标；幻象消失时对周围小范围眩晕 0.5s。  
   *意图：利用现有追逐 AI，不打断战斗节奏。*  
   *实现说明：[幻影分身诱敌设计记录](../spells/幻影分身诱敌设计记录.md)*

6. **星落阵雨（Meteor Shower）**  
   在矩形区域内随机落点若干小圈预警，0.5s 后坠落造成范围魔法伤并留下 2s 燃烧地面（tick 伤）。  
   *意图：区域压制、和 `intersect_shape` 批量结算契合。*

7. **冰霜轨迹（Frost Trail）**  
   策划意图：接下来 3s 你移动时在身后铺窄条冰带：敌对单位踩上叠“寒冷”，叠满冻结 1s；冻结状态敌人无法移动。  
   *意图：走位型控制，和玩家移动耦合。*  
   **实际实现**：已铺冰时长改为 `frost_trail_duration`（默认 5s）；当前只做 `SlowBuff` 减速（`frost_trail_slow_level` 默认 3 档，即 -30% 移速），**尚未实装"叠满冻结 1s"与"对冻敌暴率↑"**；详见 [冰霜轨迹设计记录](../spells/冰霜轨迹设计记录.md)。

8. **雷霆锁链（Chain Spark）**  
   对最近一个敌对目标造成闪电伤害，自动弹射至多 4 个额外目标（距离递减），弹射路径上的敌对单位受到一半伤害。  
   *意图：清群、和“去重命中”逻辑一致。*

9. **重力阱（Gravity Well）**
   在一点生成吸引场（默认 5.5s）：敌对单位被脉冲式拉向中心，中心内每秒叠一层"重压"减速，结束时**对外圈敌对施加 1.5s 眩晕**并结算小额魔法伤害（**实现里已改为结束眩晕，不是向外爆发击退**）。
   *意图：聚怪 + 和你的推挤/外力系统呼应。*
   *实现说明：[重力阱设计记录](../spells/重力阱设计记录.md)*

10. **誓约庇护（Oath Aegis）**  
   自身获得可吸收伤害的护盾 5s；护盾存在时你对护盾范围内友方（若以后有）分摊 10% 伤害；破裂时对周围敌对造成神圣伤害并沉默 1s。  
   *意图：防御向法术，扩展阵营与 HitContext。*

## 新增十法术（11–20）

11. **墨缚真言（Ink Shackle Verse）**  
   以施法朝向为轴展开扇形预警，0.6s 后地面浮现墨字锁链：范围内敌对定身 1.2s（仍可受击、可被净化/韧性抵抗若你以后加）。  
   *意图：锥形/扇形 `intersect_shape` + 短硬控，和鼠标/朝向技能共用表现。*

12. **焚页烬雨（Ash Litany）**  
   指定矩形区域上空飘落纸灰 3s：敌对每秒叠一层「烬蚀」（小幅降低物抗/魔抗），结束时以区域中心再结算一次范围魔法爆发（对已有层数加成）。  
   *意图：贴「灭典令」母题，延迟压迫走位，适合分段 Timer + 最终 blast。*

13. **鸽信铃音（Carrier Bell）**  
   以自身为圆心短促铃音扩散：显形范围内潜行/隐身敌对轮廓 2s，并造成微量魔法伤害（可配低打断值）。  
   *意图：信息战与反伏击，复用圆形查询 + debuff 标记。*

14. **赤水遗志（Chishui Resolve）**  
   自身 4s「舍身」：受到伤害提高，但对敌对造成伤害提高；结束时若仍存活则回复少量生命。  
   *意图：高风险换伤 Buff，走 `CombatantComponent`/modifier，和主角村名呼应。*

15. **兵俑犁阵（Terracotta Rush）**  
   沿施法方向连续生成 3 段矩形冲撞预警，短暂延迟后土俑幻影犁过：小额物理伤害 + 强击退，对同一目标击退递减。  
   *意图：推挤通道、拆散阵型，贴近矩形 `intersect_shape` + 外力通道。*  
   *实现说明：[兵俑犁阵设计记录](../spells/兵俑犁阵设计记录.md)*

16. **天命一瞥（Fate Glimpse）**  
   对单体敌对施加「窥真」3s：期间其受到的下一次来自你的直接伤害无视部分抗性（或视为带固定穿透），并短暂高亮轮廓。  
   *意图：贴天命玉「照见真实」，单体辅助爆发，易与 `HitContext.penetration` 对齐。*

17. **夜伏雾行（Nightveil Shroud）**  
   自身周围球形灰雾 3s：雾内敌对对你远程命中/投射物精度下降（或用短暂「目盲」代替）；首次穿出雾边界的敌对受到一次冰霜伤害并短暂减速。  
   *意图：生存向场地技，边界触发一次结算，可做 Area2D 或环形检测。*

18. **锁旗定阵（Broken Standard）**  
   在地面插残旗，圆形领域内敌对移速递减；若敌对试图离开圆环边缘，触发一次向心的短拉扯（小力，不吃眩晕仅位移）。  
   *意图：软聚怪 + 「别想出圈」博弈，和重力阱区分在弱拉与旗标叙事。*

19. **剥甲锥（Armor Flayer Bolt）**  
   对最近敌对发出细长矩形预警线，0.4s 后穿刺命中：降低目标护甲与魔抗（可叠 2 层、持续数秒），本身伤害偏低。  
   *意图：团队辅助 / 刺杀起手，优先最近目标 + 延迟细形状查询。*

20. **蝉蜕替身（Cicada Shell）**  
   原地留下蝉影残像 ~0.5s，吸收或大幅减免下一次「单体锁定」伤害（或第一次受击），同时自身向施法方向短位移；残像消失时对贴身敌对造成微量震慑（可选）。  
   *意图：贴第一章「夏蝉」，保命位移 + 单次伤害窗口，和指向性技能对冲。*

## 再扩十法术（21–30）

21. **引魂灯（Soul Lantern）**  
   在指定点放下一盏纸灯笼 5s：每 0.5s 向最近敌对发射一束柔弱魂火（小额魔法伤害），若期间有敌对单位被击杀，灯笼持续时间延长 1s（上限 +3s）。  
   *意图：放置型持续输出，连杀奖励节奏，贴志怪母题。*

22. **镜面涟漪（Mirror Ripple）**  
   在面前 0.3s 后展开一面短时「水镜」矩形 1.0s：正面方向的敌对投射物被反射（或销毁），穿过镜面的敌对短暂沉默 0.8s。  
   *意图：定向反制 + 读预判，补足逆岚壁之外的精确反弹。*

23. **九幽钉（Underworld Nail）**  
   对单个敌对目标施加「钉魂」3s：期间该目标的位移距离被强制限制（超过阈值会被拉回一小段）；钉子持续期间每次其攻击命中你，自身获得一层「护魂」减伤（上限 3 层）。  
   *意图：单体定桩 + 防守反击，贴「阴差锁魂」志怪视觉。*

24. **桃木令（Peachwood Ward）**  
   抛出一张桃木符在地面钉住，0.5s 后对圆形区域内所有「鬼怪/灵体类」敌对额外结算一次高伤害；对普通敌对只造成小额神圣伤。  
   *意图：种族克制向技能，为以后鬼怪类敌人（第六章志怪关卡）埋钩子。*

25. **流萤结界（Firefly Veil）**  
   以自身为圆心 2.5s 持续释放萤火环：自身获得小额闪避提升，环内敌对远程命中时有概率触发「错位」—弹体落点偏移小幅度。  
   *意图：软生存向场地技，弱化投射物压制，给弓/法敌人破绽窗口。*

26. **鹤归云（Crane Dash）**  
   向施法方向瞬移一段中距离，落点半径内敌对短暂浮空 0.3s（轻飘飘而非强硬控）；瞬移路径上留下一道白光残影 0.4s，触碰残影的敌对受到一次风系切削伤害。  
   *意图：位移 + 路径伤害，补足蝉蜕单体保命之外的进场/脱战选择。*

27. **朱砂戒律（Cinnabar Edict）**  
   以自身为圆心绘制符圈（1.5s 引导，可被打断）：引导完成后圈内敌对被「定律」束缚 2s（攻击间隔拉长、技能前摇增加），圆圈持续到被打破或 4s 结束。  
   *意图：长前摇换团队级软控，测试你「引导条 + 可打断」管线。*

28. **岚雾迷踪（Mistveil Ambush）**  
   立即进入 1.5s 隐匿状态（不受目标锁定、AI 丢失索敌），结束时的第一次普通攻击或法术伤害必定暴击，且对目标附加「恐惧」使其短暂远离你。  
   *意图：一次性消失-起手-反向逃跑机制，给偷袭派与刺杀流玩家节奏。*

29. **震山掌（Mountain-Shaker Palm）**  
   向施法方向推出一道扇形冲击波（近身范围）：对直接命中的敌对造成物理+震荡伤害并击退，若其撞到墙体/障碍物则追加眩晕 0.6s。  
   *意图：近战派法术，和场景地形交互，强化「撞墙更痛」的战斗语言。*

30. **天命共鸣（Mandate Resonance）【终技向】**  
   短暂引导后进入 4s 状态：施法者与所持天命玉共鸣，期间所有技能冷却流速 ×2（只对 CD 生效，不对引导/持续技能本身生效），且释放的法术范围 +15%；状态结束后进入一段长公共 CD。  
   *意图：高潮/终章可用的 meta-技能，直接挂在冷却系统上，避免破坏平衡的「瞬回」叙事。*
