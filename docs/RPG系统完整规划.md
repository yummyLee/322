## 四、建议新增的 RPG 系统 🆕

### 4.1 装备打造与强化（核心经济循环）

| 子系统 | 说明 | 依赖 |
|--------|------|------|
| **装备锻造** | 用采集材料 + 金币找铁匠打造武器/防具 | 掉落系统、采集系统 |
| **装备强化** | 消耗材料提升装备等级/基础属性（+1~+15） | 锻造系统 |
| **装备分解** | 拆解不需要的装备获得材料 | 掉落系统 |
| **装备重铸** | 重新随机装备的词条 | 词条系统 |
| **装备觉醒** | 特定装备达到条件后解锁隐藏属性 | 强化系统 |

### 4.2 消耗品与炼金

| 子系统 | 说明 | 依赖 |
|--------|------|------|
| **炼药/炼金** | 用草药 + 配方炼制药品（回血/回蓝/属性Buff） | 采集系统、配方系统 |
| **烹饪** | 用食材制作料理（长期 Buff / 经验加成） | 采集/狩猎 |
| **卷轴/符箓** | 一次性战斗消耗品（范围伤害/控制/召唤） | 炼金系统 |
| **药水冷却** | 限制连续喝药的 CD，防止无限续航 | — |

### 4.3 法术/技能成长

| 子系统 | 说明 | 依赖 |
|--------|------|------|
| **技能树/天赋** | 每个武器/职业的被动天赋树 | 等级系统 |
| **法术升级** | 使用熟练度或技能点提升法术等级（伤害/范围/CD 减少） | 法术系统 |
| **法术进化** | 法术达到特定等级后解锁分支进化（如冰霜轨迹→冰封领域） | 法术升级 |
| **技能点获取** | 升级 + 任务奖励 + 稀有物品 | 等级/任务系统 |

### 4.4 宝石与附魔

## 五、推荐实现优先级

### 第一优先：让游戏"可玩"（P0）

> 没有这些系统，游戏无法形成完整闭环

```
1. 死亡/复活      ← HP 归零后的处理逻辑
2. 掉落/战利品    ← 战斗→收获→成长的闭环
3. 世界状态       ← 剧情推进的前提
4. 存档完善       ← 玩家进度的保障
5. 游戏设置       ← 音量/画面可调
```

### 第二优先：让游戏"好玩"（P1）

> 核心循环之外的体验层

```
 6. Boss 机制      ← 阶段/弱点/护盾/暴怒
 7. 任务追踪 UI    ← 屏幕目标指示
 8. 小地图         ← 探索导航
 9. Buff/Debuff UI ← 战斗状态可见
10. 场景过渡       ← 沉浸感
11. 怪物 AI 协作   ← 编队策略
12. 武器特色机制   ← 每种武器差异化
```

### 第三优先：让游戏"丰富"（P2）

> 内容和深度的扩展

```
13. 装备锻造       ← 材料→装备 经济循环
14. 炼药/炼金      ← 消耗品体系
15. 法术升级       ← 法术→熟练度→进化
16. 装备强化       ← +1~+15 强化体系
17. 怪物图鉴       ← 收集动力
18. 成就系统       ← 长期目标
19. 采集深度       ← 熟练度/品质/完美采集
20. 日夜循环       ← 世界动态
21. 天气系统       ← 环境影响
22. 20 技能流派    ← 构建多样性
```

### 第四优先：让游戏"完整"（P3+）

> RPG 世界的血肉

```
23. 宝石镶嵌       ← 装备深度定制
24. 阵营/声望      ← NPC 关系网络
25. NPC 好感度     ← 角色羁绊
26. 伙伴/队友      ← 队伍玩法
27. 转职/进阶      ← 角色成长分支
28. 家园/建造      ← 玩家归属感
29. 钓鱼/烹饪      ← 休闲副玩法
30. 随机副本       ← 终局重复可玩性
31. 肉鸽模式       ← 独立玩法模式
```
