# 扇形视野系统 — 设计记录与实现记录

> 代码为准：`scripts/components/vision_cone_component.gd`、`patrol_component.gd`、`character_ai_controller.gd`  
> 测试场景：`scenes/test/vision_patrol_test.tscn`（U 键 →「视野锥 · 巡逻测试」）

---

## 设计目标

- **组件即功能**：视野检测、巡逻、AI 状态切换各自独立脚本，`.tscn` 只做组装；可挂到任意 `CharacterBody2D`（敌人、NPC、守卫）。
- **信号解耦**：`VisionConeComponent` 只负责「看见 / 看不见」，不直接写追逐或攻击逻辑；上层通过信号或 `CharacterAIController` 桥接。
- **与追逐系统解耦**：视野触发后由 `CharacterAIController` 启用已有 `ChaseController`（见 `./怪物追踪系统.md`），不重复实现移动策略。
- **双圈差异化**：内圈（近距）检测任意目标；外圈（远距）仅检测移动目标，便于区分「贴身发现」与「远处警觉」。
- **遮挡**：射线检测地形层；墙后目标不可见；调试扇形随墙截断显示。

| 日期/阶段 | 内容 |

| 测试场景 | `ObstacleWalls`：中墙 + 侧墙，默认出生点在墙后 |

### 遮挡修复说明（实现记录）

初版 `_has_line_of_sight` 存在两处问题，导致「墙后仍被看见」或行为不稳定：

1. **错误判定**：使用 `result.get("collider") == target`。射线 `collision_mask` 仅含地形层 `1`，不会命中玩家（层 `8`），有墙时 `collider` 为 `StaticBody2D`，比较恒为 `false`，逻辑与预期相反。
2. **排除列表类型**：`PhysicsRayQueryParameters2D.create(..., exclude)` 要求 `Array[RID]`；普通 `Array` 在部分 Godot 4 版本下排除观察者自身可能失效。

**当前实现：**

- 视线畅通：`intersect_ray` 返回 **空字典**（`result.is_empty()`）。
- `_ready()` 中 `_exclude_rids: Array[RID]` 追加父节点 `get_rid()`，每帧复用。
- 检测与绘制共用 `_space_state`（`_physics_process` 开头从 `get_world_2d().direct_space_state` 取得）。
- 射线起点/终点使用 **`VisionCone` 节点的 `global_position`**（子节点挂在怪物下，与怪物中心一致）。

## 架构概览

```
CharacterBody2D（ForestMonster / NPC / …）
├── CombatantComponent          ← 可选
├── ChaseController             ← 巡逻时 process_mode = DISABLED
├── VisionCone (Node2D + VisionConeComponent)
├── Patrol (Node + PatrolComponent)
└── AIController (Node + CharacterAIController)   ← 可选
```

**数据流：**

```
PatrolComponent → velocity（巡逻）
VisionConeComponent → 检测 → 信号
CharacterAIController → 切换 process_mode → ChaseController → velocity（追逐）
```

三个移动相关组件**不会同时写 velocity**。

## VisionConeComponent — 实现细节

### 每帧流程（`_physics_process`）

```
1. _space_state = get_world_2d().direct_space_state
2. 若父节点 |velocity|² > 4 → 更新 _facing_direction
3. 累计 _timer；达 detection_interval → _run_detection()
4. 若 show_debug → _update_draw_points() → queue_redraw()
```

### 目标检测管线（`_run_detection`）

对每个 `target_group` 内节点，**全部通过**才计入可见：

| 步骤 | 函数 | 条件 |
|---|---|---|
| 1 | — | 有效 `Node2D`，非自身 |
| 2 | — | `dist ≤ outer_radius` |
| 3 | `_in_cone` | 与 `_facing_direction` 夹角 ≤ `half_angle_deg` |
| 4 | `_has_line_of_sight` | 观察者 → 目标 无地形遮挡 |
| 5 | — | `dist ≤ inner_radius` → 内圈；否则若 `_is_target_moving` → 外圈 |

### 双圈规则

| 圈 | debug 色 | 参数 | 触发 |
|---|---|---|---|
| 内圈 | 浅红 | `inner_radius` | 锥内 + 视线 + **静止也可** |
| 外圈 | 灰 | `outer_radius` | 锥内 + 视线 + 距离 > 内圈 + **正在移动** |

移动判定：优先 `CharacterBody2D.velocity`；否则用 `detection_interval` 内位移估算。

### 遮挡（Line of Sight）

```gdscript
# _has_line_of_sight(world_pos) 核心逻辑
query.from = global_position          # VisionCone 节点世界坐标
query.to = world_pos
query.collision_mask = obstacle_collision_mask  # 默认 1 = 地形
query.exclude = _exclude_rids         # 仅排除观察者 CharacterBody2D
return result.is_empty()              # 空 = 无墙 = 可见
```

- `obstacle_collision_mask = 0`：关闭遮挡，始终可见（仅锥形+距离）。
- 物理层约定见 `./怪物追踪系统.md`：墙 `StaticBody2D.collision_layer = 1`。

### 视觉截断绘制

| 项 | 值 |
|---|---|
| 常量 | `DRAW_STEPS = 32`（脚本内 const，非 export） |
| 触发 | `show_debug == true` 时每 physics 帧 |
| 方法 | `_update_draw_points()` → `_ray_hit_dist(angle, outer_radius)` |
| 内外圈 | 同角度共用一条射线，`min(障碍距离, inner/outer_radius)` |
| 绘制 | `_draw()` 仅读 `_outer_draw_pts` / `_inner_draw_pts`，不访问物理 |

每帧射线次数（`show_debug` 开启时）：约 `32 + N_targets`（检测间隔内目标检测另计）。

### 信号（边沿触发）

| 信号 | 何时 |
|---|---|
| `target_entered_inner` | 新进入内圈 |
| `target_left_inner` | 离开内圈 |
| `target_entered_outer` | 新进入外圈（移动中） |
| `target_left_outer` | 离开外圈 |
| `target_lost` | 内外圈均不可见 |
| `response_requested` | **本组件未 emit**；预留给上层 |

### 导出参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `inner_radius` | 120 | 内圈半径（px） |
| `outer_radius` | 280 | 外圈半径（px） |
| `half_angle_deg` | 70 | 半角（°） |
| `target_group` | `player` | 目标组 |
| `obstacle_collision_mask` | 1 | 遮挡层；0=关 |
| `movement_speed_threshold` | 10 | 外圈移动阈值（px/s） |
| `detection_interval` | 0.1 | 检测间隔（s） |
| `show_debug` | true | 截断扇形绘制 |

### 公开 API

`set_facing_direction(dir)` · `get_inner_targets()` · `get_outer_targets()` · `has_any_target()`

### 已知限制

- 站桩/巡逻等待时速度为零，锥形朝向不更新，不与 `flip_h` 同步。
- 目标检测为观察者到目标**中心**的单条射线；墙角、大体型可能不准。
- `DRAW_STEPS` 为代码常量，暂不能在编辑器调节。

## PatrolComponent — 实现摘要

- `patrol_offsets`：相对 `_ready` 时 `_origin` 的偏移。
- `loop`：false = ping-pong，true = 循环。
- `auto_start`：搭配 AI 控制器时建议 **false**。
- **限制**：`start()` 重置 `_target_index = 0`，追逐结束回巡逻会跳回路径起点。

## CharacterAIController — 实现摘要

### 工作模式（`AIMode`）

| 模式 | `_enter_patrol()` 行为 | 典型场景 |
|---|---|---|
| `PATROL_AND_CHASE`（默认） | 启用 `PatrolComponent.start()` | 野外、草地、开放世界 |
| `CHASE_ONLY` | 不启动巡逻，ChaseController DISABLED，原地待机 | 地牢守卫、驻守型怪物 |

两种模式下，追逐**只由视野锥触发**，不受 ChaseController 自身的 `detection_radius` 驱动。

### AI 状态机

| 状态 | 内部含义 | `CHASE_ONLY` 下含义 |
|---|---|---|
| `PATROL` | 巡逻中 | 原地待机 |
| `CHASE` | 追逐中 | 追逐中 |
| `INVESTIGATE` / `ALERT` | 枚举已有，逻辑未实现 | 同左 |

### 视野事件 → 行为

| 信号 | `response_hint` | 控制器动作 |
|---|---|---|
| `target_entered_inner` | `chase` | `_enter_chase(target)` |
| `target_entered_outer` | `investigate` | 仅 `PATROL` 态时 `_enter_chase(target)` |
| `target_lost` | — | 延迟 `return_to_patrol_delay` 后 `_enter_patrol()` |

### `pursuit_behavior` 行为替换

```
_enter_chase()
  → _apply_pursuit_behavior()
      → 保存 ChaseController.behavior → _original_behavior
      → 替换为 pursuit_behavior（ChasePursueBehavior）

_enter_patrol()
  → _restore_pursuit_behavior()
      → 恢复 _original_behavior
      → _original_behavior = null
```

- `pursuit_behavior` 留空 = 保持 ChaseController 原策略（`detection_radius` 仍有效，兼容旧行为）。
- 推荐：设为 `ChasePursueBehavior` 实例，使感知完全由视野锥驱动。

### `ChasePursueBehavior`

`scripts/enemies/chase/chase_pursue_behavior.gd`

`ChaseTowardInRangeBehavior` 去掉 `detection_radius` 检测的精简版：

```gdscript
func evaluate(ctx: ChaseContext) -> Vector2:
    if ctx.distance_to_target <= attack_range:
        return Vector2.ZERO
    return (ctx.target_position - ctx.chaser_position).normalized() * ctx.move_speed
```

`"是否追"` 由 `CharacterAIController` 的 `process_mode` 控制，策略本身只管 `"怎么追"`。

### 扩展方式

监听 `response_requested(target, hint)` / 子类化 `_on_detected_*_impl` / `force_patrol()` / `force_chase(target)`。

## 与 ChaseController 的关系

| 职责 | 由谁负责 |
|---|---|
| **何时开始追** | `VisionConeComponent` 信号 → `CharacterAIController` |
| **何时停止追** | `VisionConeComponent.target_lost` → 延迟 → `CharacterAIController._enter_patrol()` |
| **怎么追（移动策略）** | `ChaseController` + `ChasePursueBehavior` |
| **ChaseController 自身 detection_radius** | 巡逻态：无效（process_mode=DISABLED）；追逐态：被 `pursuit_behavior` 替换后同样无效 |

- 巡逻态：`ChaseController.process_mode = DISABLED`，无任何自动感知。
- 追逐态（配合 `pursuit_behavior`）：`ChaseController` 只执行「朝目标移动到 `attack_range`」，感知完全由视野锥负责。
- 丢失视野后：`chase_target` 保留但 process_mode 倒计时后变 DISABLED，怪物停追。

## 挂载与配置

### 野外巡逻型（`PATROL_AND_CHASE`）

```
ForestMonster
├── ChaseController         ← detection_radius 可保留，被 pursuit_behavior 屏蔽
├── VisionCone (Node2D)     ← obstacle_collision_mask=1
├── Patrol (auto_start=false)
└── AIController
      mode = PATROL_AND_CHASE
      pursuit_behavior = <ChasePursueBehavior 内联资源>
```

### 地牢驻守型（`CHASE_ONLY`）

```
DungeonGuard
├── ChaseController
├── VisionCone (Node2D)
└── AIController            ← 不需要 PatrolComponent
      mode = CHASE_ONLY
      patrol_path = (空)
      pursuit_behavior = <ChasePursueBehavior 内联资源>
```

怪物原地待机，视野锥检测到玩家立即追击；丢失玩家后延迟回待机。

### 遮挡墙

```text
StaticBody2D
  collision_layer = 1
  └── CollisionShape2D
VisionCone.obstacle_collision_mask = 1   # 默认即可
```

### 仅视野、无巡逻

只挂 `VisionCone`，直接连 `target_entered_*` 信号。
