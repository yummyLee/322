## 2. 数据流

```
怪物死亡
  │
  ▼
CombatantComponent.died(last_hit_context)
  │   last_hit_context.attacker_node = Player
  │
  ▼
KillXpGranter._on_combatant_died(last_hit)              ← 怪物侧组件
  │
  ├── 仅当 attacker_node is Player 才发放
  ├── 解析怪物等级 L（attributes.get_base(CHARACTER_LEVEL)）
  ├── kill_xp_config (或 MonsterKillXpConfig.default()) .compute_kill_xp(...)
  ├── XpAward.of(amount, &"kill")
  │
  ▼
XpReceiver.receive_award(award)                          ← 玩家侧唯一入口
  │
  ├── compute_final_amount()  ← 加成倍率在此叠加
  ├── PlayerProgression.add_experience(final)
  │      │
  │      ├── 升级 → leveled_up.emit(new_level)
  │      │           ├── LevelUpFloat → "等级提升! Lv.N"
  │      │           ├── PlayerAttributePoints.grant_for_levels(1)  ← Player 桥接
  │      │           └── Player.sync_primary_stats_from_progression()
  │      └── experience_changed.emit(level, xp, need)
  │             ├── GameHUD 更新等级/经验条
  │             └── PlayerStatsPanel 刷新（如已打开）
  │
  └── xp_earned.emit(final, &"kill")
         └── XpFloatHost → "+{final} 经验"
```

## 3. 击杀者判定

`HitContext.attacker_node` 持有最后一击者节点引用。武器/冲刺/弹丸/法术在构造 `HitContext` 时填入 `wielder`。`CombatantComponent.receive_hit()` 保存 `last_hit_context`，并在 `died(last_hit)` 信号中携带。

| 场景 | 处理 |
|------|------|
| `attacker_node` 为 null（环境/自爆/坠落） | 不发放 |
| `attacker_node` 不是 Player（怪物互殴） | 不发放 |
| 持续伤害（DOT）最后一跳 | DOT 应回溯原始施法者 |
| 召唤物击杀 | `attacker_node` 应指向召唤者 Player |
| 多个攻击者 | 第一版：最后一击者全额（无助攻） |

## 4. 经验公式（`MonsterKillXpConfig`）

\[
\text{base}(L) = \mathrm{round}\bigl(f + k\cdot(L-1) + q\cdot(L-1)^2\bigr),\quad L \ge 1
\]

| 符号 | 字段 | 默认 |
|------|------|------|
| f | `base_floor` | 7 |
| k | `base_linear_per_level` | 3.35 |
| q | `base_quadratic_per_level_sq` | 0.018 |

\[
\text{xp} = \max\bigl(1, \mathrm{round}(\text{base}(L) \cdot m_\text{rarity} \cdot m_\text{fusion} \cdot m_\text{mut})\bigr)
\]

| 倍率 | 默认 |
|------|------|
| 稀有度 COMMON / CHAMPION / BOSS / WORLD_BOSS | 1.0 / 1.75 / 4.0 / 9.0 |
| 融合（生成器命中 `fusion_chance`） | 1.45 |
| 变异（`MonsterMutationRoll.Result` 上有玩法向效果） | 1.22 |

L 在运行时夹到 `[1, 999]`。结果至少 1。

## 5. KillXpGranter 组件

```gdscript
# 在生成阶段由 MonsterStatApplier 注入：
var granter := KillXpGranter.ensure_on(enemy)
granter.configure(rarity_tier, is_fusion, has_mutation)
```

| 字段 | 作用 |
|------|------|
| `kill_xp_config: MonsterKillXpConfig` | 可在编辑器指定 `.tres`；空则 `MonsterKillXpConfig.default()` |
| `rarity_tier: int` | `MonsterRarity.Tier` 取值（int） |
| `is_fusion: bool` | 是否融合生成 |
| `has_mutation: bool` | 是否携带变异效果 |

**生命周期**
- `_ready()`：查找同级 `CombatantComponent`，连 `died`
- `_exit_tree()`：断开信号
- `_on_combatant_died(last_hit)`：判定玩家击杀 → 通过 `XpReceiver.receive_award` 发放

**EnemyBase 不再处理击杀经验**：删掉了 `kill_xp_*` 字段、`_default_kill_xp_table`、`_fallback_kill_xp_amount`、`_grant_kill_xp_if_player_kill`，从 211 行降到 131 行。

## 6. XpAward 数据对象

```gdscript
class_name XpAward
extends RefCounted

var base_amount: int
var source_tag: StringName
var add_multipliers: Array[float]   # "+10% 经验" → 0.1（最终累加为 1 + Σ）
var multipliers: Array[float]        # "双倍经验" → 2.0（连乘）
var metadata: Dictionary             # 任意附加（击杀目标 id 等）
```

```gdscript
# 简单调用：
XpReceiver.find_on(player).receive_xp(50, &"kill")

# 携加成：
var award := XpAward.of(50, &"kill") \
    .add_bonus(0.10)   # +10% 装备
    .add_bonus(0.05)   # +5% buff
    .multiply(2.0)     # 双倍经验活动
XpReceiver.find_on(player).receive_award(award)
# final = round(50 × (1 + 0.10 + 0.05) × 2.0) = 115
```

未来扩展点（装备/Buff/活动加成）在构造 `XpAward` 时往 `add_multipliers / multipliers` 里塞即可，**不动 XpReceiver 接口签名**。

## 7. XpReceiver

```gdscript
signal xp_earned(amount: int, source_tag: StringName)

static func find_on(node: Node) -> XpReceiver
func receive_xp(amount: int, source_tag: StringName = &"") -> void   # 简化入口
func receive_award(award: XpAward) -> void                            # 完整入口
```

- 同时是"经验入口收口"：怪物击杀（`KillXpGranter`）、商人购买（`ExperiencePurchaseUI`）、任务奖励、道具均通过此入口
- `xp_earned` 信号的 `amount` 是已应用加成的"最终经验"，飘字/HUD 据此显示

## 8. FloatingTextHost —— 飘字模板

`Node2D` 基类，封装 Label + Tween 上移 + 渐隐 + 堆叠错位 + 自销毁的样板。子类只需配置参数 + 调 `spawn_text(text, override_color = null)`。

| 子类 | 用途 | 主要差异 |
|------|------|---------|
| `XpFloatHost` | "+N 经验" | 绿、14 号、1.0s |
| `LevelUpFloat` | "等级提升! Lv.N" | 金、18 号、1.8s、起始偏移 (0, -28) |
| `DamageFloaterHost` | 伤害飘字 | 红/暴击金、15 号、0.78s；带暴击颜色覆盖 |

旧的 `FloatingDamageNumber` 单条飘字类已删除。
