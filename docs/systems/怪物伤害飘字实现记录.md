# 怪物伤害飘字实现记录

怪物受击并在 `CombatantComponent` 结算出 **最终伤害** 后，在怪物本体右侧显示形如 `-19` 的飘字；多条伤害 **起始高度依次上移**，整体上移的同时 **淡出**，动画结束节点自销毁。

与 [`战斗与属性统一体系.md`](./战斗与属性统一体系.md) 中的受击管线一致：飘字读的是 **`damage_received(final_damage, HitContext)`** 里的 `final_damage`（已含护甲/抗性等减免后的数值）。

## 相关代码

| 角色 | 路径 |
|------|------|
| 挂载与订阅入口 | `scripts/enemies/enemy_base.gd`（`_ready` 内创建 `DamageFloaterHost` 并 `setup(combatant)`） |
| 监听受击、堆叠层数、生成单条飘字 | `scripts/components/damage_floater_host.gd`（`DamageFloaterHost`，继承 `FloatingTextHost`） |
| 通用飘字模板（上移 + 淡出 + 堆叠 + 自销毁） | `scripts/components/floating_text_host.gd`（`FloatingTextHost`） |

## 接入方式

- **无需改怪物 `.tscn`**：凡继承 `EnemyBase` 且存在 `CombatantComponent` 子节点的敌人，在 `EnemyBase._ready()` 中会自动挂上飘字宿主。
- 子类若实现 `_ready()`，须 **`super._ready()`**，否则会跳过上述挂载。
- **玩家、训练假人**等只要同样走 `EnemyBase` + `CombatantComponent`，行为一致。

## 行为说明

1. **触发**：`CombatantComponent` 在 `_apply_damage` 后发出 `damage_received`；`DamageFloaterHost` 订阅该信号。
2. **过滤**：`final_damage <= 0.001` 时不生成飘字（避免闪避或 0 伤仍出字）。
3. **位置**：飘字宿主为怪物根节点下的 `Node2D`，使用 **怪物本地坐标**。起始偏移由 `FloatingTextHost.start_offset` 控制（默认 `(14, -16)`）。
4. **堆叠**：`FloatingTextHost` 内维护 `_active_stack`，每生成一条上移 `stack_step_y`；动画结束 `_active_stack -= 1` 自动回收槽位。
5. **动画**：`Tween` 并行：`position:y` 上移 `float_rise`（时长 `float_duration`，Quad Out）、`modulate:a` 滞后 `fade_delay` 淡出（Ease In）；`finished` 后 `queue_free()`。
6. **层级**：飘字 `z_index = floater_z_index`（默认 64），便于压在默认绘制的血球/受击闪之上（可按场景再调）。

## 文案与样式

- 文本：`-%d`，对 `final_damage` **四舍五入取整**。
- 颜色：**普通受伤**为偏红字色 + 深色描边；**暴击**（`HitContext.is_crit == true`）为**金色字** + 棕色描边，通过 `spawn_text(text, override_color)` 在不修改基类默认色的前提下覆盖单条颜色。
- 武器近战/玩家弓箭命中怪物时走 `receive_hit(HitContext)`，暴击标记由攻击侧写入上下文（见 `WeaponBase.build_physical_hit_context`）；法术等其它来源若在 `HitContext` 中带 `is_crit`，飘字同样会变黄。

## 实现注意（Tween 属性路径）

Godot 4.x 中 `Tween.tween_property()` 第二参数类型为 **`NodePath`**，不能使用 `StringName`（`&"position:y"`）。本仓库使用 NodePath 字面量 **`^"position:y"`**、**`^"modulate:a"`**；亦可写成 `NodePath("position:y")` 等形式。

## 扩展建议（未实现）

- **暴击**：可读 `HitContext.is_crit`，加大字号或改金色。
- **元素/治疗**：按 `HitContext.damage_type` 或伤害符号区分颜色（当前仅常规受伤红色）。
- **玩家侧飘字**：玩家受击若需同款 UI，可在 `Player` 或专门 UI 层挂同类宿主，订阅玩家 `CombatantComponent.damage_received`，避免与怪物脚本强耦合。
