# 武器系统扩展设计

> **项目**：openworldtest  
> **引擎**：Godot 4.x  
> **设计日期**：2026-05-04  
> **目标**：扩展武器类型至10+种，建立等级缩放体系，设计特殊武器机制避免数值俗套

---

## 1. 现状回顾

### 1.1 已有设施

| 组件 | 状态 | 说明 |
|------|------|------|
| `WeaponData` | ✅ | 继承 ItemData，含7个属性词条 + AttackPattern + 连击链 |
| 5种攻击行为 | ✅ | HORIZONTAL_SLASH / VERTICAL_SLASH / SPIN_SLASH / THRUST / PROJECTILE |
| 连击系统 | ✅ | combo_patterns 循环，1.5s 重置窗口，每段可配不同倍率 |
| 7级稀有度 | ✅ | COMMON → LEGENDARY，颜色体系完整 |
| 装备栏 | ✅ | WEAPON 槽已启用，属性词条自动注入/移除 |
| `DamageCalculator` | ✅ | 物攻/魔攻/元素/真伤四路，闪避→减伤→穿透完备 |

### 1.2 当前缺口

1. **仅3种武器类型**（剑/矛/弓），缺乏多样性
2. **武器基础伤害硬编码**在 `Player._build_weapon_data_for_item()`，无等级缩放
3. **所有武器使用相同的属性词条池**（7个），无类型差异化词条
4. **缺乏特殊武器机制**（剑气、蓄力、追踪、弹射等）
5. **武器与稀有度的关联仅有颜色**，无实质属性差异
6. **无独特武器（Unique）**，所有同类型武器体验一致

---

## 2. 设计目标

1. **类型多样** — 10+种武器类型，每种有独特的攻击行为和机制
2. **等级匹配** — 武器数值按等级缩放，与玩家属性曲线对齐
3. **避免数值俗套** — 通过"签名机制"让每种武器改变的是**战斗方式**而非仅仅改变伤害数字
4. **稀有度有意义** — COMMON→LEGENDARY 在词条数量、数值范围、机制强度上均有梯度
5. **独特武器（Unique）** — 命名的特殊武器，类似于 Diablo 的 Legendary / Path of Exile 的 Unique，拥有改变玩法规则的能力
6. **最小侵入** — 扩展现有架构，新增行为类型和词条类型，不推倒重建

---

## 3. 武器数值等级缩放

### 3.1 设计原则

- 武器基础伤害随等级**渐进增长**，不做跳跃式膨胀
- 高等级时武器占伤害比重略降（让属性加点仍是主力），但特殊机制的价值放大
- 同等级不同武器类型的**理论DPS持平**，差异在"伤害分布"而非总量

### 3.2 基础伤害公式

```
weapon_base_damage(level) = round(8 + level^0.88 × type_base_mult)
```

| 武器类别 | type_base_mult | 设计理由 |
|---------|---------------|---------|
| 轻快型（匕首/双匕/拳套） | 2.5 | 单次低但频率高，DPS靠攻速实现 |
| 均衡型（剑/鞭/枪） | 3.5 | 攻速与伤害均衡 |
| 重型（大剑/锤/弩） | 5.0 | 单次高伤害，慢速 |
| 魔法型（法杖/魔典） | 2.8 | 受INT驱动，物伤为辅助 |
| 远程型（弓/火枪） | 3.2 | 安全边际换略低伤害 |

### 3.3 全等级基础伤害表

| 等级 | 轻快型 | 均衡型 | 重型 | 魔法型 | 远程型 | 参考玩家物攻 |
|------|--------|--------|------|--------|--------|------------|
| 1 | 11 | 15 | 21 | 12 | 13 | 18 |
| 10 | 24 | 33 | 46 | 26 | 29 | 46 |
| 20 | 40 | 55 | 76 | 43 | 49 | 81 |
| 30 | 56 | 77 | 107 | 60 | 68 | 115 |
| 40 | 72 | 100 | 139 | 78 | 89 | 150 |
| 50 | 90 | 124 | 172 | 97 | 111 | 184 |
| 60 | 108 | 148 | 207 | 116 | 133 | 219 |
| 70 | 126 | 174 | 242 | 136 | 156 | 253 |
| 80 | 145 | 200 | 279 | 157 | 180 | 288 |
| 90 | 165 | 227 | 316 | 178 | 204 | 322 |
| 99 | 184 | 254 | 353 | 199 | 228 | 355 |

*"参考玩家物攻"来自同等级均衡构建的 PhysATK 值*

### 3.4 伤害占比分析

以均衡型武器为例，武器基础伤害占"最终出手伤害"的比例：

| 等级 | 武器基础 | 玩家物攻 | 武器占比 |
|------|---------|---------|---------|
| 1 | 15 | 18 | 45% |
| 30 | 77 | 115 | 40% |
| 50 | 124 | 184 | 40% |
| 99 | 254 | 355 | 42% |

武器占比稳定在 **40-45%**，既保证了武器升级的感知，又保留了属性加点的核心地位。配合武器词条（bonus_attack_power + bonus_damage_all），高稀有度武器可额外提升10-30%的等效伤害。

## 4. 武器类型扩展

### 4.1 总览（12种武器类型）

```
近战（7种）
├── 均衡类：剑 Sword、枪 Spear
├── 速度类：匕首 Dagger、双匕首 Twin Daggers
├── 重型类：大剑 Greatsword、战锤 War Hammer
└── 特殊类：锁链鞭 Chain Whip

远程（4种）
├── 弓 Bow、弩 Crossbow
├── 火枪 Flintlock
└── 飞刀 Throwing Knives

魔法（2种）
├── 法杖 Staff
└── 魔典 Grimoire
```

### 4.2 各类型详细设计

---

#### 4.2.1 剑（Sword）— 均衡战士

| 属性 | 值 |
|------|-----|
| 类别 | 均衡型近战 |
| 攻击距离 | 60px |
| 攻击冷却 | 0.7s |
| 攻击行为 | HORIZONTAL_SLASH → VERTICAL_SLASH → SPIN_SLASH（三段连击） |
| 主要属性 | STR ×1.5, AGI ×0.3 |
| 副属性 | LUK |

**签名机制 — 剑气（Sword Aura）：**

> 连击计数达到3的倍数时，下一次攻击额外释放一道剑气（Projectile），飞行距离180px，伤害为本次攻击的50%。剑气不可被格挡。

设计意图：让剑在近战中有一定的中距离威胁，奖励持续进攻（不断连击）。

#### 4.2.2 枪/矛（Spear）— 距离掌控

| 属性 | 值 |
|------|-----|
| 类别 | 均衡型近战 |
| 攻击距离 | 90px（+30%于剑） |
| 攻击冷却 | 0.9s |
| 攻击行为 | THRUST（主）→ SWEEPING_THRUST（横扫突刺） |
| 主要属性 | STR ×1.2, AGI ×1.0 |

**签名机制 — 尖锋伤害（Tip Damage）：**

> 命中判定分两段：枪尖（最远30%）部位造成 **1.5× 伤害**；枪杆（近70%）造成 **0.7× 伤害**。鼓励玩家精确控制距离。

设计意图：引入"最佳距离"概念，高手通过走位获得高额回报，站桩则伤害打折。

#### 4.2.3 匕首（Dagger）— 暗杀专家

| 属性 | 值 |
|------|-----|
| 类别 | 轻快型近战 |
| 攻击距离 | 38px |
| 攻击冷却 | 0.4s |
| 攻击行为 | RAPID_STAB（快速3连刺）→ SHADOW_STRIKE（瞬移到目标背后） |
| 主要属性 | AGI ×1.4, LUK ×0.8 |

**签名机制 — 背刺（Backstab）：**

> 从目标背后发动的攻击必定暴击，且暴击伤害×1.5。对满血目标的第一击额外+30%伤害。配合 SHADOW_STRIKE 行为可实现"绕背→爆发→脱离"的刺客循环。

设计意图：鼓励走位和时机把握，不鼓励站桩。高风险（近身+脆皮）高回报。

---

#### 4.2.4 双匕首（Twin Daggers）— 连击狂热

| 属性 | 值 |
|------|-----|
| 类别 | 轻快型近战 |
| 攻击距离 | 35px |
| 攻击冷却 | 0.25s |
| 攻击行为 | 6段交替连击：左斩→右斩→交叉斩→左挑→右挑→旋风（360°） |
| 主要属性 | AGI ×1.6 |

**签名机制 — 动量（Momentum）：**

> 每次命中目标叠加一层"动量"：攻击速度 +6%，最高10层（+60%）。脱离战斗2秒后清空。满层时第6段"旋风"伤害×2并击退。

设计意图：高风险高回报的"站桩输出"型武器。一旦开始连击就不想停，但需要判断什么时候该中断躲避。类似 Monster Hunter 双刀的"鬼人化"概念。

#### 4.2.5 大剑（Greatsword）— 蓄力重击

| 属性 | 值 |
|------|-----|
| 类别 | 重型近战 |
| 攻击距离 | 75px |
| 攻击冷却 | 1.3s |
| 攻击行为 | WIDE_SLASH（180°横扫）→ OVERHEAD_SLAM（竖劈）→ CHARGED_SLASH（蓄力斩） |
| 主要属性 | STR ×2.0（双倍系数） |

**签名机制 — 蓄力与冲击波（Charge & Shockwave）：**

> **蓄力**：按住攻击键蓄力（最高2秒），松开发动 CHARGED_SLASH。蓄力分3段：
> - 0.3s：伤害1.3×，无特殊效果
> - 0.8s：伤害1.8×，附带击退
> - 2.0s：伤害2.5×，附带冲击波（扇形180px，50%武器伤害），无视目标30%护甲
>
> 蓄力期间移动速度-40%，可被击退打断。

设计意图：高风险蓄力玩法，需要判断Boss出招间隙。类似 Monster Hunter 大剑的"溜め斬り"。

#### 4.2.6 战锤（War Hammer）— 眩晕控制

| 属性 | 值 |
|------|-----|
| 类别 | 重型近战 |
| 攻击距离 | 55px |
| 攻击冷却 | 1.1s |
| 攻击行为 | OVERHEAD_SMASH（竖砸）→ WIDE_SWEEP（横扫）→ GROUND_POUND（砸地AoE） |
| 主要属性 | STR ×1.5, CON ×0.5 |

**签名机制 — 眩晕值（Stagger）：**

> 每次命中积累"眩晕值"（与伤害成正比）。当眩晕值超过目标最大HP的15%时，目标进入**眩晕**状态（无法行动2秒，受到伤害+20%）。大型/Boss目标阈值更高（30% HP）。
>
> GROUND_POUND 命中已眩晕目标时，眩晕时间刷新。

设计意图：以控制替代纯伤害，提供团队价值（队友可在眩晕期爆发），同时让坦克构建有输出贡献。类似 Elden Ring 的重武器"架势破坏"机制。

#### 4.2.7 锁链鞭（Chain Whip）— 中程拉扯

| 属性 | 值 |
|------|-----|
| 类别 | 均衡型中程 |
| 攻击距离 | 120px（2倍于剑） |
| 攻击冷却 | 0.8s |
| 攻击行为 | WHIP_CRACK（直线鞭击）→ SPIN_TETHER（360°甩链）→ GRAPPLE_PULL（勾拉） |
| 主要属性 | AGI ×1.3, STR ×0.9 |

**签名机制 — 死亡之链（Death Chain）：**

> **拉扯**：GRAPPLE_PULL 将第一个命中的敌人拉到你面前（Boss免疫但受到额外伤害）。
>
> **弱点标记**：被拉扯的目标获得"标记"，受到所有来源伤害+25%，持续4秒。
>
> **鞭长莫及**：攻击无法命中距离 < 30px 的目标（鞭子需要空间展开）。被近身时自动切换为踢击（伤害为武器伤害的30%）。

设计意图：中程控制型武器，克制远程怪物（拉过来），被近战怪物克制。形成明确的克制循环。类似恶魔城的"吸血鬼杀手"鞭子。

#### 4.2.8 弓（Bow）— 蓄力狙击

| 属性 | 值 |
|------|-----|
| 类别 | 远程型 |
| 攻击距离 | 400px（弹丸射程） |
| 攻击冷却 | 1.0s |
| 攻击行为 | PROJECTILE（单箭）→ CHARGED_SHOT（蓄力箭，贯通）→ MULTI_ARROW（扇形3箭） |
| 主要属性 | STR ×1.0, AGI ×1.2 |
| 弹丸速度 | 600px/s |

**签名机制 — 蓄力贯通与必杀计数：**

> **蓄力射击**：按住攻击键蓄力，松开发射。蓄力分2段：
> - 0.5s：伤害1.5×，箭矢变大
> - 1.0s：伤害2.0×，箭矢**贯通**（穿过敌人继续飞行，最多命中3个目标）
>
> **MULTI_ARROW**（三连矢）：三段连击最后一段，呈20°扇形发射3支箭，每支造成70%武器伤害。面对大型Boss可全中（210%总伤害）。

设计意图：远程蓄力玩法，贯通的加入让弓在面对群怪时有了"排队枪毙"的快感。类似 Dragon's Dogma 的弓手蓄力。

#### 4.2.9 弩（Crossbow）— 破甲狙击

| 属性 | 值 |
|------|-----|
| 类别 | 重型远程 |
| 攻击距离 | 350px |
| 攻击冷却 | 1.4s |
| 攻击行为 | BOLT_SHOT（高伤单发）→ EXPLOSIVE_BOLT（小AoE爆炸箭）→ NET_BOLT（减速网箭） |
| 主要属性 | STR ×1.4 |
| 弹丸速度 | 900px/s（比弓快50%） |
| 装填时间 | 攻击冷却的40%为装填动画 |

**签名机制 — 破甲与特殊弹药：**

> **天生破甲**：弩矢无视目标30%护甲（固定值，不与穿透叠加）。
>
> **特殊弹药轮换**：弩的连击三段使用不同弹药，而非不同斩击：
> 1. BOLT_SHOT：标准高伤弩矢
> 2. EXPLOSIVE_BOLT：命中后小范围爆炸（半径60px），对群伤害
> 3. NET_BOLT：伤害仅50%但附加减速40%（持续3s），对Boss时间减半
>
> 3段打完自动循环回BOLT_SHOT。

设计意图：比弓更重、更慢、但更有"工具感"——不同弹药应对不同情况。类似 Monster Hunter 轻重弩的弹药系统简化版。

#### 4.2.10 火枪（Flintlock）— 高风险高爆发

| 属性 | 值 |
|------|-----|
| 类别 | 远程型 |
| 攻击距离 | 300px |
| 攻击冷却 | 0.3s（连射间隔） |
| 攻击行为 | SINGLE_SHOT → FAN_THE_HAMMER（6连射） |
| 主要属性 | STR ×1.1, LUK ×0.8 |
| 弹丸速度 | 1200px/s（瞬时命中） |
| 弹药 | 6发弹巢，打空后强制装填 2.0s |

**签名机制 — 弹巢管理与精准射击：**

> **6发弹巢**：6发射完后必须装填2秒（期间可移动但不可攻击，速度-30%）。
>
> **FAN_THE_HAMMER**（连射）：快速射出剩余全部弹药（最多6发），每发造成70%伤害，总爆发420%——但打空后进入更长的2.5秒装填。
>
> **精准命中小游戏**：射击命中目标弱点（头部判定区，中心30px圆）时造成3×伤害。火枪弹丸速度极快，奖励精确瞄准。

设计意图：类似于 Bloodborne 的枪反枪或 Hunt: Showdown 的火器。节奏感来自弹巢管理——何时装填、何时爆发。高手用精准射击获得高回报，菜鸟打身体也能过关。

#### 4.2.11 法杖（Staff）— 魔法导体

| 属性 | 值 |
|------|-----|
| 类别 | 魔法型 |
| 攻击距离 | 250px（魔法弹射程） |
| 攻击冷却 | 0.9s |
| 攻击行为 | MAGIC_BOLT（魔法弹）→ MAGIC_BURST（自身周围AoE）→ CHANNEL_BEAM（持续射线） |
| 主要属性 | INT ×1.6 |
| 伤害类型 | 全部为 MAGICAL |

**签名机制 — 织法（Spell Weaving）：**

> 法杖普通攻击与魔法技能交替使用时触发"织法"：
> - 法杖攻击 → 技能：技能MP消耗-30%
> - 技能 → 法杖攻击：法杖伤害+25%
>
> **CHANNEL_BEAM**：持续发射魔法射线（最长2.5秒），每秒造成3次伤害（每次30%武器伤害）。可转向但移动速度-70%。对护盾/装甲有+40%伤害加成。

设计意图：法杖不是单纯的"远程魔法弓"，而是配合技能系统的桥梁。织法机制鼓励"普攻+技能"交替循环，避免无脑丢技能。类似 FFXIV 黑魔导士的"冰火循环"简化版。

#### 4.2.12 魔典（Grimoire）— 区域控制

| 属性 | 值 |
|------|-----|
| 类别 | 魔法型 |
| 攻击距离 | 200px（符文放置距离） |
| 攻击冷却 | 1.0s |
| 攻击行为 | RUNE_MARK（放置符文）→ HEX_BOLT（诅咒魔弹）→ DETONATE（引爆所有符文） |
| 主要属性 | INT ×1.8 |
| 伤害类型 | MAGICAL / 各元素 |

**签名机制 — 符文区域（Rune Zones）：**

> **放置符文**：在地上放置一个魔法符文（最大同时存在3个）。符文持续8秒，每秒对站在上面的敌人造成30%武器伤害。符文可附加元素效果（通过词条/稀有度）。
>
> **引爆**：DETONATE 引爆场上所有符文，每个造成120%武器伤害的AoE爆炸。引爆后符文消失。
>
> **诅咒**：HEX_BOLT 命中后附加"受到符文伤害+40%"debuff（持续4秒）。
>
> 不放置符文时，魔典没有直接伤害能力——玩家需要预先布阵。

设计意图：高操作需求高回报的"陷阱型"武器。Boss战中预判走位布符文→引诱→引爆的循环。类似 Dota 2 的"地雷工程师"或 Grim Dawn 的"符文法师"。

## 6. 特殊武器机制详解

### 6.1 需要新增的攻击行为类型

为实现上述武器类型的签名机制，需要扩展 `AttackPattern.BehaviorType` 枚举：

| 新行为 | 用途 | 参数 |
|--------|------|------|
| `RAPID_STAB` | 匕首快速多段刺 | stab_count, stab_interval |
| `WIDE_SLASH` | 大剑180°横扫 | angle=180°, sweep_duration |
| `OVERHEAD_SLAM` | 大剑/锤竖砸 | impact_radius, shockwave |
| `CHARGED_SLASH` | 大剑蓄力斩 | charge_stages[], can_hold |
| `GROUND_POUND` | 战锤砸地AoE | aoe_radius, stagger_mult |
| `WHIP_CRACK` | 鞭直线打击 | min_range, max_range |
| `GRAPPLE_PULL` | 鞭勾拉 | pull_force, pull_distance |
| `CHARGED_SHOT` | 弓/弩蓄力 | charge_stages[], pierce_count |
| `MULTI_ARROW` | 弓扇形多箭 | arrow_count, spread_angle |
| `FAN_THE_HAMMER` | 火枪连射 | shots_per_burst, burst_interval |
| `MAGIC_BOLT` | 法杖魔法弹 | damage_type=MAGICAL |
| `CHANNEL_BEAM` | 法杖持续射线 | beam_duration, tick_rate |
| `RUNE_MARK` | 魔典放置符文 | rune_duration, zone_radius |
| `DETONATE` | 魔典引爆符文 | detonate_damage_mult |

### 6.2 剑气/冲击波实现（Sword Aura / Shockwave）

剑气本质上是一种特殊的弹丸（Projectile）：
- 使用 `ProjectileBase` 作为基类
- 不可被格挡（penetration = 999 或 damage_type = TRUE 的部分）
- 飞行距离有限（180px），速度中等（400px/s）
- 继承攻击者的属性加成（已有 compute_hit_damage 支持）

新增 `ProjectileBehavior` 参数：
```
can_be_blocked: bool = true
is_sword_aura: bool = false  # 剑气特殊标签，用于词条加成
```

### 6.3 蓄力系统实现

蓄力是一个武器层面的状态机，不是在行为层面：

```
WeaponBase 新增:
  _charge_time: float = 0.0
  _is_charging: bool = false
  _charge_stage: int = 0
  
  try_charge_attack(direction) -> bool:
    _is_charging = true
    _charge_time = 0
    start tweening visual feedback (glow, shake)
    
  release_charge(direction) -> bool:
    determine charge_stage from _charge_time
    look up damage_mult from pattern's charge_stages[stage]
    execute behavior with charge_stage
    _is_charging = false
```

`AttackPattern` 新增：
```
charge_stages: Array[ChargeStage]
  每个 ChargeStage 定义: { charge_time: float, damage_mult: float, extra_effects: Array }
```

### 6.4 追踪箭/弹射箭实现

在 `ProjectileBase` 基础上扩展特殊弹丸行为：

```
SeekingProjectile (extends ProjectileBase):
  seek_target: Node2D
  seek_strength: float (弧度/秒)
  max_seek_angle: float
  _physics_process: 转向目标而非直线飞行

BouncingProjectile (extends ProjectileBase):
  bounce_count: int
  bounce_range: float (搜索下一个目标的半径)
  _on_collide: 如果没有 bounce_count 耗尽，寻找附近敌人并转向

PiercingProjectile (extends ProjectileBase):
  pierce_count: int
  _on_collide: 造成伤害但不 self.queue_free()，继续飞行
```

这些特殊弹丸可通过词条或独特武器赋予普通武器。

### 6.5 三连矢/扇形多箭实现

`MULTI_ARROW` 行为通过 `ProjectileBehavior` 的变体实现：在 `execute()` 中循环 `arrow_count` 次，每次创建一个弹丸，方向在 `[direction - spread/2, direction + spread/2]` 之间均匀分布。

```
func _execute_multi_arrow(data, direction, count, spread):
    for i in range(count):
        var angle_offset = spread * (i / (count - 1.0) - 0.5)
        var arrow_dir = direction.rotated(angle_offset)
        spawn_projectile(data, arrow_dir, damage_mult)
```

### 8.1 武器类型设计借鉴

| **Borderlands** | 红字特效+厂商差异化 | 独特武器的命名与特效设计 |

### 8.2 核心哲学

> "一把好的武器不只是让数字变大，而是让玩家用不同的方式思考战斗。"

- 剑 —— 经典可靠，连击的爽感在于节奏
- 匕首 —— 刺客的耐心，等待那一击必杀的时机
- 大剑 —— 对Boss出招的理解，找到蓄力的窗口
- 鞭子 —— 空间控制，把敌人放在你想要的位置
- 魔典 —— 陷阱预判，提前布局的智力博弈
- 火枪 —— 弹巢管理，每一发都要认真瞄准
