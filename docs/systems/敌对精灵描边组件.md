# 敌对精灵描边（红框）说明

用于给 `AnimatedSprite2D` 按 **Alpha 外轮廓** 显示描边（常用红色表示敌对），随动画帧自动贴合剪影，无需逐帧手绘描边。

## 相关资源

| 资源 | 路径 |
|------|------|
| 组件脚本 | `scripts/components/animated_sprite_alpha_outline.gd`（`AnimatedSpriteAlphaOutline`） |
| 着色器 | `shaders/enemy_sprite_outline.gdshader` |

## 如何挂到角色上

1. 在角色场景根节点（如 `CharacterBody2D`）下 **新建 Node**。
2. 将脚本设为 `animated_sprite_alpha_outline.gd`。
3. 在检查器中配置 **Sprite Path**：
   - 组件作为根的**子节点**时，默认可用 `../AnimatedSprite2D`（与精灵同一父节点）。
   - 若把脚本直接挂在**根节点**上，则改为 `AnimatedSprite2D`（指向其子节点精灵）。

参考实例：`scenes/animals/forest_monster.tscn` 中的 `AnimatedSpriteAlphaOutline` 节点。

## 开启方式（Display Mode）

组件用 **Display Mode** 控制描边是否出现，互斥三选一：

| 模式 | 含义 |
|------|------|
| **Disabled** | 关闭描边，精灵材质恢复为挂上本组件**之前**的记录值。 |
| **Always** | 始终显示描边。 |
| **Selected Animations** | 仅当当前播放的动画名在 **Outline Animations** 列表里时显示；其它动画不描边。 |

`Selected Animations` 下列出的名称需与 `SpriteFrames` 里定义的动画名一致（例如 `attack`、`idle`）。

## 可调参数

| 参数 | 说明 |
|------|------|
| **Outline Color** | 描边颜色，默认偏红。 |
| **Outline Width** | 厚度（纹理空间像素量级），数值越大圈越粗。 |
| **Alpha Cutoff** | 判定「不透明 / 透明」的阈值；边缘发灰时可略调小以贴紧轮廓。 |

## 注意事项

- 描边依赖贴图的 **透明区域**：若整张贴图几乎无透明，外轮廓描边会很不明显。
- 启用描边期间，组件会把自己的 `ShaderMaterial` 赋给目标精灵；关闭（Disabled）时会还原挂接时缓存的原始材质。
