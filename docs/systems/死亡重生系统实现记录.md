# 死亡重生系统实现记录

玩家 HP 归零后的战败流程、可配置惩罚、重生点与恢复策略（保留状态复活 / 读档）。设计见 [`核心循环补全详细设计.md`](../核心循环补全详细设计.md) §2。

## 相关代码

| 角色 | 路径 |
|------|------|
| 总配置 | `resources/config/death_system.tres`（`DeathSystemConfig`） |
| 惩罚配置 | `scripts/core/death/death_penalty_config.gd` |
| 枚举 | `scripts/core/death/death_enums.gd` |
| 协调器 Autoload | `scripts/core/death/death_manager.gd` |

| 重生点存档 | `SaveManager.set_active_respawn()` / `get_active_respawn()` |

## 恢复方式（RecoveryMode）

| 模式 | 行为 |
|------|------|
| `RESPAWN_KEEP_STATE` | 应用惩罚 → 传送到当前场景激活重生点 → 满血/按配置比例复活 → **保留背包/装备/金币（扣惩罚后）/任务进度** |
| `LOAD_LAST_SAVE` | 按 `load_save_slot_policy` 读取存档（默认优先自动存档）→ **整局回到存档快照** |

UI 上可让玩家二选一（`allow_choose_recovery = true`）；也可只暴露一种（`allow_choose_recovery = false`）。

## DeathSystemConfig 字段

| 字段 | 说明 |
|------|------|
| `enabled` | 总开关 |
| `default_recovery_mode` | 不显示 UI 或自动恢复时使用 |
| `allow_choose_recovery` | 战败界面是否提供多种恢复选项 |
| `allow_respawn_keep_state` / `allow_load_save` | 各按钮是否可见 |
| `load_save_slot_policy` | `AUTOSAVE_FIRST` / `MOST_RECENT_ANY` / `AUTOSAVE_ONLY` |
| `fallback_when_no_checkpoint` | 无重生点时：`SCENE_DEFAULT_SPAWN` 或 `FORCE_LOAD_SAVE` |
| `pause_game_on_death` | 死亡时暂停场景树 |
| `show_game_over_ui` | 是否弹出战败面板 |
| `autosave_on_checkpoint_touch` | 触碰重生点是否自动存档 |
| `penalty` | 嵌套 `DeathPenaltyConfig` |

## DeathPenaltyConfig 字段（当前默认全关闭）

| 字段 | 说明 |
|------|------|
| `gold_loss_enabled` + `gold_loss_ratio` | 扣金币比例；`gold_loss_min/max` 上下限 |
| `drop_gold_in_world` | 扣除的金币是否散落在死亡点可捡回 |
| `respawn_hp_ratio` / `respawn_mp_ratio` | 复活后 HP/MP 比例 |
| `equipment_durability_loss` | 全身装备耐久扣除 |
| `inventory_durability_loss` | 背包内带耐久物品扣除 |
| `xp_loss_enabled` + `xp_loss_ratio` | 当前等级段经验扣除比例 |
| `clear_buffs_on_respawn` | 复活时清除 Buff |

**当前 `death_system.tres` 默认：无惩罚、满血复活、保留状态。**

## 重生点 RespawnPoint

- 挂 `scenes/world/respawn_point.tscn`；`is_default = true` 表示场景默认落点（无激活 checkpoint 时使用）。
- 玩家进入区域 → `SaveManager.active_respawn` 写入 `{ scene_path, point_id, display_name, pos }`。
- 出生点与玩家重叠时会 deferred 自动激活（避免 `body_entered` 未触发）。

已放置：`main.tscn`、`grassland_test.tscn` 的玩家出生位置。

## 运行时流程

1. `CombatantComponent.died` → `DeathManager` 锁定输入、可选暂停、弹出 `GameOverUI`。
2. **复活**：惩罚 → 传送 → `DeathPenaltyApplier.revive_combatant()` → 解锁。
3. **读档**：`SaveManager.load_game(slot)` 切换场景并恢复快照。
4. **回标题**：`title_screen.tscn`。

## 测试

1. 运行 `scenes/test/grassland_test.tscn` 或 `main.tscn`。
2. 让怪物击杀玩家（或临时调低玩家 HP）。
3. 战败界面应出现；选「在重生点复活」→ 回出生点、满血、物品保留。
4. 修改 `resources/config/death_system.tres` 中 `penalty.gold_loss_enabled = true`、`gold_loss_ratio = 0.1` 验证惩罚预览与实际扣款。
