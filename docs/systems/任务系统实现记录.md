## 3. 数据流

```
EnemyBase._on_died()
    ↓
QuestManager.notify_enemy_killed(enemy_id)
    ↓
遍历 _active_quests，对 ObjectiveType.KILL_ENEMY && target_id 命中的目标 +1
    ↓
QuestInstance.advance_progress(...) → 回写到 .progress 字典
    ↓
emit objective_progressed(quest_id, objective_id, current, required)
    ↓
若 are_all_objectives_complete() → state := OBJECTIVES_DONE
                                  → emit quest_objectives_completed(quest_id)
    ↓
QuestJournalUI / QuestDialogUI 监听信号 → 重绘 UI
玩家回到 NPC → QuestGiverNpc._open_dialog → QuestDialogUI.open_for_quest
玩家点"复命领赏" → QuestManager.turn_in_quest → player.gold += gold_reward
                                              → state := TURNED_IN
                                              → emit quest_turned_in
```

## 4. NPC 与任务的对应

NPC 自身**不存任务状态**，只持 `npc_id: String`。每次交互调用：

```gdscript
QuestManager.get_relevant_quest_for_npc(npc_id) -> QuestDef
```

返回 NPC 当前应该展示的最优先任务，优先级（高 → 低）：

1. 该 NPC 是 giver 且任务处于 `OBJECTIVES_DONE` —— 等待复命
2. 该 NPC 是 giver 且任务处于 `ACTIVE` —— 进行中
3. 该 NPC 是 giver 且任务尚未接取 —— 可接取
4. 该 NPC 是 giver 且任务已交付 —— 闲聊回顾
5. 都不满足 → 返回 `null`，NPC 不弹窗

## 5. 实例任务：草原狩猎

| 字段 | 值 |
|---|---|
| quest_id | `forest_grassland_hunt` |
| 触发 NPC | `veteran_quest_giver`（main 场景中的"老兵"） |
| 目标 1 | 击杀 `forest_monster` × 25 |
| 目标 2 | 击杀 `archer` × 25 |
| 奖励 | 100 金币 |

### 流程演示

1. 启动游戏 → 主场景中"老兵"头顶显示 `!`
2. 走到老兵旁按 E → 弹出对话框，点"接取任务"
3. 按 U → 切换到"草地测试场景（grassland.png）"
4. 在那里击杀 25 只森林怪 + 25 名弓箭手；按 J 实时查看进度
5. 全部完成 → 老兵头顶变 `?`（QuestState.OBJECTIVES_DONE）
6. 按 U 切换回主场景 → 走到老兵旁按 E → 点"复命领赏" → 金币 +100

## 6. 扩展指南

### 6.1 新增一个击杀任务

在 `resources/quests/` 下复制 `forest_grassland_hunt.tres` 改字段即可，QuestManager 启动时会自动扫描该目录。

### 6.2 新增其他目标类型

详见 [任务目标类型扩展实现记录](任务目标类型扩展实现记录.md)。

| 类型 | 实现入口 |
|---|---|
| COLLECT_ITEM | 自动：`Inventory.inventory_changed`；手动：`QuestManager.notify_inventory_changed()` |
| TALK_TO_NPC | `QuestManager.notify_npc_talked(npc_id)`（NPC 交互处已接入） |
| ENTER_AREA | `QuestAreaTrigger` → `QuestManager.notify_area_entered(area_id)` |
| CUSTOM | `QuestManager.advance_objective(qid, oid)` 或 `QuestCustomTrigger` |

### 6.3 新增任务发布 NPC

把 `scenes/world/quest_giver_npc.tscn` 实例化进场景，设置：
- `npc_id`：与对应 QuestDef 的 `giver_npc_id` 一致
- `npc_name`：头顶显示的名字
- `npc_color`：标记色块颜色
- `quest_dialog_path`：指向当前场景的 `QuestDialogUI` 节点

### 6.4 多阶段任务

当前 QuestDef 只有"目标列表"（扁平）。未来引入 `StageDef` 时建议在 QuestDef 上加 `stages: Array[StageDef]`，并在 `QuestInstance` 中维护 `current_stage`。`QuestManager.notify_enemy_killed` 改为只对当前 stage 的目标做命中匹配即可，UI 层只需稍作调整。

## 7. 已知限制 / TODO

- 不支持任务放弃（abandon_quest 暂未实现）
- 不支持失败条件（fail_condition）
- 任务奖励仅金币，未支持经验、物品、Buff
- 没有 QuestTracker（屏幕常驻追踪），后续可加在 `scripts/ui/` 下
- 任务定义与对话耦合：当前对话文本写在 QuestDef 中，若引入分支对话需对接 Dialogic 系统
