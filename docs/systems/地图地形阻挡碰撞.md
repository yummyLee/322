# 地图地形阻挡碰撞

> **用途**：在背景图场景里挡住树林、悬崖、深水等**不可通行地形**（与建筑脚底碰撞、任务区域触发器区分）。  
> 首版落地：`scenes/chapter1/yaocun_v1_map.tscn` · `World/Collision/`  
> 相关：[地图建筑碰撞与遮挡虚化](./地图建筑碰撞与遮挡虚化.md)（单栋建筑）· [窑村地图建筑进门与图层实现记录](./窑村地图建筑进门与图层实现记录.md)（建筑总览）

---

## 一、三种「边界」别混用

| 类型 | 节点 | 是否挡玩家 | 典型用途 |
|------|------|------------|----------|
| **地形阻挡** | `World/Collision` 下 `StaticBody2D` | 是 | 林缘、河岸、悬崖、地图外缘 |
| **建筑脚底** | `MapBuilding/FootCollision` | 是 | 墙基、侧墙；门洞留空 |
| **任务区域** | `QuestAreaTrigger`（`Area2D`） | 否 | `ENTER_AREA` 目标推进 |

**道路不用单独画碰撞**：主路、岔路 = 碰撞之间的空地；只沿不可走区域描边即可。

---

## 二、场景树约定

背景图室外场景（以窑村 v1 为例）推荐结构：

```
YaocunV1Map (Node2D)
├── Background          # Sprite2D 背景图
├── World
│   └── Collision       # 所有地形阻挡放这里
│       ├── ForestSouthWest   (StaticBody2D + CollisionPolygon2D)
│       ├── NorthWest
│       └── …
├── Entities (y_sort_enabled)
│   ├── Player
│   └── House1 …        # MapBuilding 实例
├── Markers / Doors
└── Camera2D
```

- 地形碰撞放在 **`World/Collision`**，不要放进 `Entities`（避免与 `y_sort`、建筑脚本搅在一起）。
- 每个不可走片区一个 `StaticBody2D`，命名用英文 + 方位/地貌（如 `ForestSouthWest`、`CliffNorthEast`）。

## 三、添加一块新阻挡（标准步骤）

### 1. 新建节点

1. 打开目标场景（如 `scenes/chapter1/yaocun_v1_map.tscn`）。
2. 在 `World/Collision` 下 **添加子节点 → `StaticBody2D`**，命名。
3. 在 Inspector 设置：
   - **`Collision Layer`**：勾选 **第 1 层**（与 `LayoutBlock`、建筑脚底、扇形视野射线一致，层值 `1`）。
   - **`Collision Mask`**：勾选 **第 4 层**（玩家 `CharacterBody2D` 所在层，层值 `8`）。

### 2. 加碰撞形状

在 `StaticBody2D` 下添加子节点：

| 形状节点 | 适用 |
|----------|------|
| **`CollisionPolygon2D`** | 林缘、河岸、悬崖等不规则边界（**首选**） |
| **`CollisionShape2D` + `RectangleShape2D`** | 笔直的墙、规则矩形禁区 |

### 3. 对齐背景图

1. 选中 `CollisionPolygon2D`（或 `CollisionShape2D`）。
2. 在 **2D 视图** 用顶点编辑工具，沿背景图上树线 / 水边 / 崖边描多边形。
3. 主路、广场、院门出口处 **留空**，不要把可走路径包进多边形里。

### 4. 验收

1. 运行场景，菜单 **调试 → 可见碰撞形状**（或编辑器运行时的碰撞调试）。
2. 控制玩家走向该区域，应被挡住且不穿模。
3. 确认主道、出生点、门洞仍可正常通过。

## 四、碰撞层速查

| 对象 | collision_layer | collision_mask | 说明 |
|------|-----------------|----------------|------|
| 玩家 `CharacterBody2D` | `8` | 默认 `1` | 与第 1 层障碍物碰撞 |
| 地形 `StaticBody2D` | `1`（默认） | `8` | 只挡玩家 |
| `MapBuilding/FootCollision` | `1`（默认） | `8` | 同地形 |
| `QuestAreaTrigger` | `0` | `8` | 仅检测玩家，不挡路 |

地形阻挡使用第 1 层时，**扇形视野**等地形射线也会把它当作遮挡物（见 [扇形视野系统设计记录](./扇形视野系统设计记录.md)）。

## 五、多边形 vs 矩形

- **不规则地貌**：用 `CollisionPolygon2D`，顶点顺时或逆时针均可，Godot 会自动处理。
- **子节点 `position`**：整块碰撞可挂在偏移的 `StaticBody2D` 或 `CollisionPolygon2D` 上（如 `NorthEast` 将多边形挂在 `position = (852, -751)`），世界坐标 = 父节点变换 × 局部顶点。
- **复杂凹形区域**：可拆成多个 `StaticBody2D`，每个一个凸多边形，比单个大凹多边形更稳、更好调。

## 六、镜头边界（补充）

地形挡的是**玩家移动**；**镜头**另由 `Camera2D.limit_*` 限制。窑村 v1 在 `yaocun_v1_map.gd` 中按背景图显示范围自动设置：

```gdscript
var bounds: Rect2 = _background.global_transform * _background.get_rect()
_camera.limit_left = int(bounds.position.x)
# … limit_top / right / bottom 同理
```

换背景图或改 `Background.scale` 后无需手改数值。

## 八、常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 玩家直接穿过去 | `collision_mask` 未包含玩家层 `8` | 地形 `StaticBody2D` 设 `mask = 8` |
| 主路被挡 | 多边形包进了土路 | 缩小多边形或挪顶点，给道路留走廊 |
| 建筑门口被挡 | 地形块与 `FootCollision` 重叠 | 地形多边形在门洞前收边，或略退后 |
| 编辑器里看不见碰撞 | 未开调试显示 | **调试 → 可见碰撞形状** |
| 与建筑碰撞混淆 | 节点放错层级 | 建筑在 `Entities`；地形在 `World/Collision` |

## 九、与占位布局场景的区别

`jingkou_region.tscn` 使用 `JingkouLayoutBuilder` 生成的 **L0 色块**（分区、道路）仅用于**对齐与预览**，`collision: false`，不挡玩家。

贴图场景（`yaocun_v1_map`）的地形阻挡需在 **`World/Collision` 手摆或按背景描边**，与策划文档中的格坐标（`docs/scenes/窑村场景详细设计.md`）无自动同步。
