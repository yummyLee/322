# 技能面板与技能栏设计记录

## 目标

- 提供独立的技能面板（`K` 开关，`Esc` 关闭）。
- 面板展示当前已实现技能列表，使用正方形网格排列。
- 支持将技能从面板拖拽到技能栏，替换目标键位绑定。
- 同一技能在技能栏中全局唯一：拖拽到新槽位后，旧槽位自动清空。
- 玩家按键施法由技能栏绑定驱动，而不是写死键位到固定技能。

## 交互规则

- 打开/关闭：
  - `K`：打开或关闭技能面板。
  - `Esc`：当技能面板打开时关闭面板。
- 拖拽：
  - 从技能面板的技能方块拖动到技能栏任意槽位。
  - 目标槽位替换为拖拽技能。
  - 若该技能已在其他槽位，原槽位会置空（显示为“空”）。
- 施法：
  - 按快捷键时（当前默认 **Q / R / T / E / F / G / H / Y** 共 8 键，见 `spell_hotbar.gd.slot_configs`），先查询技能栏当前绑定，再触发对应技能施法逻辑。
  - 若槽位为空，则该按键不施放技能。
  - 按键集合由 `slot_configs` 决定；要加/减快捷槽时改这个数组即可。

## 当前脚本结构

### 0) 技能描述数据：`scripts/magic/spell_catalog_data.gd`（`SpellCatalogData`）

- **单一数据源**：`spell_id`、`display_name`、`description`、`tags`、`targeting`、`cooldown_seconds`（与 `SpellSystem` 各技能默认冷却对齐，用于 Tooltip 展示）。
- `get_entries()`：技能面板网格枚举；`find(spell_id)`：技能栏校验合法 id、Tooltip 查表。
- 新增可展示法术时：**先在此追加一条目录**，再确保 `SpellSystem` / 玩家施法表已接入。

### 0b) 悬停说明：`scripts/ui/spell_tooltip_manager.gd`（Autoload `SpellTooltipManager`）

- **全局 CanvasLayer**（较高 layer），鼠标悬停在技能栏槽位或技能面板方块上时显示。
- 展示内容：**名称**（加粗）、**标签**（伤害/控制类型等）、**施放方式**、**快捷键**（仅技能栏）、**冷却**（就绪为绿色文案；冷却中由 `SpellSystem` 每帧刷新剩余秒数）、**详细描述**。
- 技能栏：锚点在槽位右侧；超出视口则翻到左侧/上移。
- 技能菜单：说明框固定在**整块技能面板底边下方**水平居中；下方空间不足时改贴面板顶边上方。

### 1) 技能栏：`scripts/ui/spell_hotbar.gd`

- 职责：
  - 从 `SpellCatalogData` 解析展示名与合法性。
  - 维护键位槽配置 `slot_configs`（每项 `spell_id`；键位由 `KeybindManager` 的 `spell_1`…`spell_N` 决定）。
  - 绘制技能槽 UI（技能名、冷却遮罩、键位角标）。
  - 接收拖拽并更新绑定；槽位 `mouse_entered` / `mouse_exited` 驱动 `SpellTooltipManager`。
  - 对外提供 `get_bound_spell_id_for_slot(slot_index)`。
- 关键方法：
  - `_on_spell_dropped_to_slot(slot_index, spell_id)`：处理替换与唯一占位。
  - `_refresh_slot_visual(slot_index)`：刷新槽位显示。
  - `get_bound_spell_id_for_slot(slot_index)`：供玩家输入层按槽位索引查询绑定。

### 2) 技能面板：`scripts/ui/skill_panel.gd`

- 职责：
  - 处理面板开关输入（`K`/`Esc`）。
  - 以网格形式展示 `SpellCatalogData.get_entries()` 中的技能方块。
  - 方块悬停同样调用 `SpellTooltipManager`。
  - 作为拖拽源输出拖拽数据 `{type: "spell_drag", spell_id}`。
- 布局：
  - 居中 `PanelContainer`。
  - `GridContainer` 按列排布技能方块（正方形）。

### 3) 玩家施法分发：`scripts/player/player.gd`

- 职责：
  - 在 `_unhandled_input` 中处理施法按键，调用 `_try_cast_bound_spell(keycode)`。
  - 通过 `SpellHotbar.get_bound_spell_id_for_slot()` 获取绑定技能。
  - 通过 `_spell_casters`（`spell_id -> Callable`）分发到具体施法函数。
- 关键点：
  - 避免了“键位写死技能”的旧问题，保证拖拽改绑定后立即生效。

## 数据模型

- 技能目录项（`SpellCatalogData` 字典）：
  - `spell_id: String`
  - `display_name: String`
  - `description: String`
  - `tags: String`（展示用短标签）
  - `targeting: String`（施放方式说明）
  - `cooldown_seconds: float`（与实现默认 CD 一致，供 Tooltip）
- 技能槽配置项（`spell_hotbar.gd.slot_configs`）：
  - `spell_id: String`（可为空字符串；对应快捷键见 `KeybindManager` → `spell_1`…）
- 当前默认槽位配置为 8 项：`Q:ground_blast / R:ground_root / T:cone_volley / E:pincer_clamp / F:chain_spark / G:gravity_well / H:terracotta_rush / Y:mirror_decoy`。其它法术（冰霜轨迹 / 引魂灯 / 地脉三震 / 时针错位）默认不占槽，玩家可从面板拖入任意槽位。

## 拖拽数据协议

- 数据结构（`Variant` 字典）：
  - `type: "spell_drag"`
  - `spell_id: <技能ID>`
- 接收校验：
  - 仅当 `type == "spell_drag"` 时允许落入技能槽。

## 已修复问题记录

- 问题 1：拖拽替换后按键施法不变。
  - 原因：玩家输入曾把 Q/R/T/E/F 写死到固定技能函数。
  - 修复：改为按键 -> 查询技能栏绑定 -> 按 `spell_id` 分发施法。`_spell_casters` 表在 `player.gd._ready` 按组件字段动态注册。
- 问题 2：同技能可在多个槽位重复存在。
  - 修复：拖拽到新槽位时，遍历其他槽位并清空同 `spell_id` 的旧槽位。
- 问题 3：面板与技能栏耦合。
  - 修复：拆分为独立脚本（`skill_panel.gd` 与 `spell_hotbar.gd`）。

## 场景挂载
