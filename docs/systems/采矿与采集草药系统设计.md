# 采矿与采集草药系统设计

## 文档目的

为开放世界中的 **采矿** 与 **采草** 提供完整规则框架，与现有 **物品/背包/装备/属性/Buff/任务** 系统对齐，可直接指导实现。

核心回答三个问题：
1. 采集速度的提升应该靠 **被动能力成长** 还是 **工具**？
2. 矿物和草药的 **品级** 如何影响采集速度？
3. 除了速度和品级，还有哪些 **必须考虑** 的因素？

---

## 1. 核心设计决策：被动能力 vs 工具

### 1.1 结论：混合模型，工具为主，熟练度为辅

```
采集效率 = 工具基础性能 × (1 + 熟练度加成 + 属性加成 + Buff加成)
```

**工具承担"台阶"**，熟练度承担"坡度"——两者缺一不可。

### 1.2 为什么不能二选一

**纯工具方案的问题：**
- 成长完全阶梯化——换一把镐瞬间质变，旧工具立刻沦为废铁
- 经济曲线僵硬：玩家只需攒钱买顶级工具，之后采集再无成长
- 无法体现"老矿工"的练度差异——新手拿传奇镐和老手拿传奇镐，体感一模一样
- 缺少持续投入的动力——工具到顶后采集行为失去意义

**纯熟练度方案的问题：**
- 前期缺乏获得感——"采了100个矿还是用同一把破镐"
- 数值容易堆叠失控——如果每级+3%，100级就是+300%，读条缩到0.1秒
- 缺少装备驱动的兴奋点——RPG玩家期待"爆一把好镐"的惊喜
- 无法用工具做硬门槛——高品级资源无法通过"需要更好的镐"来控制进入节奏

### 1.3 职责划分

| 维度 | 工具（主导） | 熟练度（辅助） |
|------|-------------|---------------|
| **能否采集该节点** | ✓ 硬门槛：品级不足的镐无法对高阶矿点按F | ✗（极低概率"越级"需消耗特殊道具） |
| **基础采集时间** | ✓ 工具品级决定基础速度系数 | ✓ 每级熟练度 -1%，设下限（不低于基础40%） |
| **采集成功率** | ✓ 工具品级覆盖主要区间 | ✓ 熟练度缩小失败窗口 |
| **完美采集窗口** | 可选（工具词条扩大窗口） | ✓ 熟练度扩大完美判定区间 |
| **耐久消耗** | ✓ 工具基础耐久 + 品级损耗曲线 | ✓ 熟练度减少每次采集的耐久消耗 |
| **产出数量** | 可选（工具词条+1产量） | ✓ 熟练度触发"双倍收获"暴击 |
| **副产物概率** | 可选（工具附魔增加池子） | ✓ 熟练度解锁稀有副产物掉落池 |
| **特殊能力** | ✓ 工具可带词条（如"采铁矿+20%速度"） | ✓ 高熟练度解锁机制性被动（识别富矿、免伤采集等） |

### 1.4 工具系统设计

#### 工具作为装备物品

在现有 `Equipment.Slot` 枚举中新增 `TOOL` 槽位：

```
Equipment.Slot:
  WEAPON
  HEAD (占位)
  BODY (占位)
  LEGS (占位)
  ACCESSORY (占位)
  TOOL      ← 新增，启用
```

工具类物品新增 `ItemType.TOOL`，子类对应采集类型：

```
ItemSubType:
  PICKAXE    ← 新增，用于采矿
  SICKLE     ← 新增，用于采药
  (未来) AXE ← 用于伐木
```

#### 工具属性（ToolData 或直接扩展 ItemData）

| 属性 | 类型 | 说明 |
|------|------|------|
| `tool_tier` | int (1~7) | 工具品级，对应 ItemRarity 的 7 个等级 |
| `gather_speed` | float | 基础速度系数（1.0 = 标准，越小越快） |
| `min_node_tier` | int | 可采集的节点最低品级要求（硬门槛） |
| `success_rate_base` | float | 基础成功率（0.0~1.0） |
| `perfect_window` | float | 完美采集判定窗口（秒，0 = 无完美采集） |
| `max_durability` | int | 最大耐久度 |
| `durability_per_gather` | int | 每次采集消耗耐久 |
| `bonus_yield_chance` | float | 额外产出概率（0.0~1.0） |
| `affix_pool` | Array | 词条池（如"铁矿专精""夜间采集加速"） |

#### 工具品级曲线

| 品级 | 名称 | 速度系数 | 最低可采节点 | 基础成功率 | 耐久 |
|------|------|---------|-------------|-----------|------|
| COMMON | 破旧镐/镰 | 1.5 | T1 | 85% | 50 |
| UNCOMMON | 铁镐/镰 | 1.2 | T2 | 90% | 80 |
| ADVANCED | 钢镐/镰 | 1.0 | T3 | 92% | 120 |
| RARE | 秘银镐/镰 | 0.85 | T4 | 94% | 180 |
| EXCEPTIONAL | 附魔镐/镰 | 0.7 | T5 | 96% | 250 |
| EPIC | 史诗镐/镰 | 0.55 | T6 | 97% | 350 |
| LEGENDARY | 传说镐/镰 | 0.4 | T7 | 98% | 500 |

### 1.5 熟练度系统设计

#### 独立于战斗等级

采集熟练度是 **完全独立** 的生活技能等级，不与玩家战斗等级挂钩。这样：
- 纯生活玩家不需要打怪就能成为大师矿工
- 高级战斗玩家面对高阶矿点也需要从零练采集
- 两条成长线互不干扰，各自有追求

#### 熟练度等级

```
MiningSkill（采矿熟练度）: 1~99
HerbalismSkill（采药熟练度）: 1~99
```

每级经验曲线复用现有 `PlayerLevelCurve` 的公式框架（`45 × L^1.62`），调整系数使采集节奏合理。

#### 熟练度收益表（每级）

| 收益类型 | 每级增量 | 上限 |
|---------|---------|------|
| 采集速度 | -0.5%（减少读条时间） | -50%（即最低读条不低于基础40%） |
| 成功率 | +0.1% | +10% |
| 完美窗口扩大 | +0.3% | +30% |
| 耐久节省 | -0.3%（减少每次采集消耗） | -30%（最低消耗为1） |
| 双倍收获概率 | +0.15% | +15% |

#### 里程碑被动（特定等级解锁机制）

这些不是数值加成，而是改变采集行为的 **机制性被动**：

| 等级 | 采矿被动 | 采药被动 |
|------|---------|---------|
| 10 | **矿脉感知**：小地图显示30m内矿点图标 | **草木识别**：小地图显示30m内草药图标 |
| 20 | **稳定手法**：受击不再打断采集读条 | **抗毒体质**：采集毒草不再受伤 |
| 30 | **富矿识别**：矿点品质在交互前可见 | **花期辨识**：草药品质在交互前可见 |
| 40 | **矿工直觉**：10%概率采集不消耗耐久 | **采药妙手**：10%概率采集不消耗耐久 |
| 50 | **矿脉续采**：矿点可多采1次才枯竭 | **植株再生**：草药点可多采1次才枯竭 |
| 60 | **深层开采**：解锁T6矿点的越级采集（原需T6工具，现T5即可） | **稀有辨识**：解锁T6草药的越级采集 |
| 70 | **矿脉共鸣**：采矿时5%概率触发"富矿爆发"，3倍产量 | **自然恩赐**：采药时5%概率触发3倍产量 |
| 80 | **不竭矿脉**：采集后矿点10%概率不枯竭 | **生生不息**：采集后草药10%概率不消失 |
| 90 | **大师矿工**：全矿点采集时间-20%（与工具/属性乘算） | **药草大师**：全草药采集时间-20% |
| 99 | **传说级被动**：可同时采集周围5m内所有同类节点 | **传说级被动**：可同时采集周围5m内所有同类节点 |

### 1.6 与现有 HARVESTING 属性的整合

游戏已有 `HARVESTING = LUK × 0.5%` 派生属性。保留它作为采集系统的 **属性维度加成**：

```
最终采集速度 = 工具速度系数 × (1 - 熟练度速度加成 - HARVESTING加成 - Buff加成)
最终成功率   = clamp(工具基础成功率 + 熟练度成功率加成 + LUK×0.3%, 0.5, 1.0)
双倍收获概率 = 熟练度双倍概率 + HARVESTING加成 + 工具词条
```

这样 LUK 属性对采集有实际意义，但不至于让战斗玩家的 LUK 加点完全覆盖生活玩家的熟练度投入。

## 2. 品级对采集的影响

### 2.1 设计原则

品级不应该只线性拉长读条时间——那样会 **惩罚玩家探索高级区域的动力**。

核心思路：**高品级 = 高门槛 + 高风险 + 高回报**，而不是"采得更慢"。

### 2.2 品级影响的五个维度

| 维度 | 低品级 (T1~T2) | 中品级 (T3~T4) | 高品级 (T5~T7) |
|------|---------------|---------------|---------------|
| **工具门槛** | 徒手或基础工具 | 需要对应品级工具 | 需要稀有以上工具 + 可能额外条件 |
| **采集时间** | 短（1~2秒基础） | 中等（2~4秒基础） | 较长（4~8秒基础），但**高回报大幅补偿** |
| **失败惩罚** | 几乎无 | 失败消耗双倍耐久 | 失败可能触发"矿脉坍塌"（节点消失）或"药性挥发"（降品级） |
| **采集段数** | 1段完成 | 1~2段 | 2~3段，每段产出递增，末段产出最高 |
| **产出** | 1~2个基础材料 | 2~3个，概率出同品级材料 | 多量 + 高品级主产物 + 稀有副产物 |

### 2.3 分段采集机制（高品级专属）

T4+ 节点采用分段采集，给玩家决策空间：

```
T4矿脉（3次采集机会）：
  第1段（1.5秒）：必定成功，产出1个
  第2段（2.0秒）：成功率90%，产出1~2个
  第3段（2.5秒）：成功率75%，产出2~3个 + 概率出稀有副产物
  
  每段完成后玩家可以主动停止（拿到已采集的），
  也可以冒险继续——但如果下一段失败，
  可能触发"矿脉坍塌"损失全部未入袋的产出。
```

这个设计让采集不是"按F然后等"，而是有 **风险决策** 的玩法。

### 2.4 采矿 vs 草药的品级差异

| | 采矿 | 采药 |
|---|------|------|
| **节点形态** | 矿脉/矿堆，固定位置，显眼 | 草丛/花丛，可隐藏，需靠近才显示 |
| **品级表达** | 矿石光泽、矿脉大小、伴生矿种类 | 花期、植株大小、是否有光环特效 |
| **风险类型** | 声响引怪、矿脉坍塌、环境伤害（落石） | 毒雾、伪装怪、误采Debuff |
| **工具特色** | 镐的冲击力、耐久消耗高 | 镰的范围采收、耐久消耗低 |
| **采集节奏** | 单点深挖，读条较长 | 可范围采收多株，读条较短 |
| **招牌差异** | 高阶矿"分段采集"赌狗玩法 | 高阶草药"辨识"机制（采前不知品质，需技能揭示） |

### 2.5 采药的"辨识"机制（差异化亮点）

草药与采矿的核心玩法区别：

- **采矿**：矿脉品级 **直观可见**（矿石越大越亮 = 品级越高），核心玩法是 **风险决策**（分几段采）
- **采药**：草药品级 **初始不可见**（外观模糊），需要 **熟练度或道具** 来辨识。核心玩法是 **信息博弈**：
  - 低熟练度：看到一丛草，不知道是普通还是稀有，采了才知道
  - 熟练度30级：解锁"花期辨识"，采集前可看到品级
  - 熟练度50级：解锁"药性预感"，靠近高品级草药时屏幕边缘有微光提示

## 3. 必须考虑的其他因素

### 3.1 节点与刷新系统

#### 刷新策略

采用 **个人实例 + 公共节点** 混合：
- 普通节点（T1~T3）：**个人刷新**，每个玩家独立计时，互不抢矿
- 稀有节点（T4~T6）：**世界共享**，先到先得，增加竞争和社交
- 传说节点（T7）：**世界共享 + 长刷新**（现实时间6~24小时），地图唯一或极少

#### 刷新规则参数

| 参数 | 普通节点 | 稀有节点 | 传说节点 |
|------|---------|---------|---------|
| 刷新时间 | 3~5分钟 | 15~30分钟 | 6~24小时 |
| 可采次数 | 3~5次后枯竭 | 2~3次后枯竭 | 1次后消失 |
| 枯竭后行为 | 进入冷却，冷却完刷新 | 进入冷却 | 完全消失，新节点在区域内随机位置生成 |
| 是否受区域等级影响 | 是（高级区刷新快但节点品级高） | 是 | 是（仅高等级区域生成） |

#### 性能考虑

- 普通草药密集区使用 **合并交互体**（一片草丛 = 1个交互体，产出3~5株随机草药）
- 矿点天然稀疏，每个独立交互
- 采集后节点隐藏（`visible = false`，碰撞禁用），不删除节点对象，冷却完后恢复

### 3.2 背包与经济

#### 与现有背包系统的集成

```
采集完成 → 检查 inventory.can_add_item(item_id, quantity)
  ├─ 可放入 → add_item，正常流程
  ├─ 可部分放入 → 放入能放的，剩余丢弃（弹提示）
  └─ 完全放不下 → 禁止采集，提示"背包已满"
```

#### 材料经济循环

- 材料的价值在于 **消耗出口**：合成、任务、升级工具、出售
- 采集的"时薪"必须与其他金币获取方式可比（打怪、任务）
- 低品级材料大量消耗（合成基础药剂/强化石），高品级材料稀缺消耗（打造传说装备）
- 工具 **耐久消耗** 是材料经济的核心调节器：
  - 耐久归零 → 工具不消失但采集速度为 **基础3倍慢**
  - 修复需要 **同品级材料 + 金币**，制造持续的采集→消耗循环

### 3.3 交互与反馈

#### 采集流程

```
1. 玩家靠近节点 → 节点高亮边框 + 显示交互提示
2. 按F键开始采集 → 进入采集状态（降低移速或原地不动）
3. 读条阶段：
   - 普通采集：线性读条，可被受击/移动打断
   - 完美采集：读条中出现"完美区间"（高亮段），在区间内松手触发完美
4. 完成采集：
   - 弹出收获图标（物品Icon飞向背包）
   - 耐久数字飘出（"-1耐久"）
   - 节点状态更新（矿脉变小 / 草药消失）
```

#### 完美采集（互动式采集）

不采用纯等待读条，而是加入微交互：

```
读条上有一个移动的"光标"来回摆动，
中间有一段高亮区域（完美窗口）。

玩家在光标进入完美窗口时：
  松F键 → 完美采集（1.5倍产出）
  不松手 → 读条满后普通采集（1.0倍产出）
  过早/过晚松手 → 失败（0产出，消耗耐久）

完美窗口大小 = 工具基础窗口 + 熟练度扩展
光标速度 = 基础速度 × (1 - 熟练度减速)
```

这样采集本身有 **操作维度**，不是挂机行为。

#### 打断规则

| 打断来源 | 行为 |
|---------|------|
| 玩家移动 | 立即打断，已读条进度丢失 |
| 受到伤害 | 打断（熟练度20级被动可免疫） |
| 施放技能 | 打断 |
| 被控制（眩晕等） | 打断 |
| 主动取消（再按F或Esc） | 打断，无惩罚 |

#### UI反馈清单

- 节点高亮边框（品级颜色）
- 交互提示文字（"采矿 F"/"采药 F"）
- 读条UI（带完美窗口标记）
- 收获飘字（"+2 铁矿"）
- 耐久飘字（"-1 耐久"）
- 熟练度获得提示（"+5 采矿经验"）
- 背包满提示（红色警告）
- 工具耐久低警告（耐久<20%时）

### 3.4 安全与风险

#### 采集风险分级

| 风险等级 | 区域示例 | 风险内容 |
|---------|---------|---------|
| 安全 | 新手村周边 | 无主动怪，节点密集，适合挂机采 |
| 低风险 | 野外道路两侧 | 少量主动怪，但离路近可逃跑 |
| 中风险 | 野外深处 | 主动怪巡逻路线经过矿点，需清怪或等时机 |
| 高风险 | 洞穴/深山 | 节点旁固定精英怪，采集=强制战斗 |
| 极端风险 | Boss区域 | 传说级节点，采集可能触发Boss苏醒 |

#### 采矿 vs 采药的风险差异化

- **采矿**：声响大 → 采集时吸引半径内敌人（可设计"消音附魔"工具词条）
- **采药**：隐蔽 → 不引怪，但高品级草药可能是"伪装怪"（采了触发战斗）

### 3.5 昼夜与天气影响

| 条件 | 采矿影响 | 采药影响 |
|------|---------|---------|
| 白天 | 正常 | 正常 |
| 夜晚 | 矿点可见度降低，但某些矿（月光石）只在夜晚发光可见 | 某些草药只在夜晚开花（可采集），白天闭合 |
| 雨天 | 矿点有概率"富含水分"→产量+20% | 草药刷新速度+50% |
| 晴天 | 正常 | 正常 |

这个系统为后续"稀有节点只在特定条件下出现"留出设计空间。

### 3.6 任务与进度系统

#### 采集任务设计

- 任务道具与普通掉落 **分池**：任务物品100%掉落，不被RNG卡进度
- 任务类型：
  - 采集交付：采集N个X物品
  - 品质要求：交付特定品级以上材料
  - 探索发现：首次采集某区域某品级节点
  - 竞速采集：限时采集尽可能多的某物品

#### 图鉴/成就系统（可后期实现）

- 每种矿物/草药：首次采集解锁图鉴条目
- 全品级收集：同一材料的所有品级都采集过 → 成就奖励
- 全区域探索：采集过某区域所有类型节点 → 称号

### 3.7 Buff系统集成

现有Buff系统已成熟，采集Buff直接复用：

```
采集Buff类型：
  - 速度Buff：减少采集读条时间（StatModifier → HARVESTING临时+值）
  - 产量Buff：增加产出数量（独立逻辑）
  - 幸运Buff：增加双倍收获概率
  - 耐久Buff：本次采集不消耗耐久
  - 完美Buff：扩大完美窗口

来源：
  - 食物/药水（临时Buff，DurationPolicy.TIMED）
  - 装备词条（常驻Buff，装备时add、卸下时remove）
  - 天气/区域效果（环境Buff）
  - 熟练度被动（永久Buff，DurationPolicy.PERMANENT）
```

### 3.8 工具修复与损耗经济

```
工具耐久值：0 ~ max_durability

每次采集消耗 = durability_per_gather × (1 - 熟练度耐久节省率)
耐久归零 → 工具变为"破损"状态：
  - 采集速度 × 3.0（极慢）
  - 无法触发完美采集
  - 无法采集高于T2的节点
  - 但不会完全丢失（保护玩家资产）

修复：
  修复消耗 = 同品级材料 × (1 - 当前耐久/最大耐久) + 金币
  可在铁匠NPC处修复（城镇）
  或使用随身"磨刀石"道具（消耗品，战斗掉落/商店购买）
```

## 4. 核心公式

### 4.1 有效采集时间

```
T = T_base × T_tool × (1 - S_proficiency - S_harvesting - S_buff)

其中：
  T_base       = 节点配置的基础采集时间
  T_tool       = 工具速度系数（1.5 ~ 0.4，越低越快）
  S_proficiency = 熟练度每级 +0.5%，上限 50%（即最高-50%）
  S_harvesting  = HARVESTING属性值（LUK × 0.5%）
  S_buff        = 临时Buff的速度加成

约束：
  T ≥ T_base × T_tool × 0.4  （下限：不低于工具基础速度的40%，约0.3~1.8秒）
```

### 4.2 采集成功率

```
P = clamp(P_tool + P_proficiency + P_luk_bonus - P_tier_penalty, 0.5, 1.0)

其中：
  P_tool          = 工具基础成功率（85%~98%）
  P_proficiency   = 熟练度加成（每级+0.1%，上限+10%）
  P_luk_bonus     = LUK × 0.3%
  P_tier_penalty  = (节点品级 - 工具品级) × 5%（当节点品级>工具品级时）
```

### 4.3 产出计算

```
基础产量 = Random(min_yield, max_yield)  （从节点配置中读取）
完美加成 = 基础产量 × 0.5（完美采集时额外50%）
双倍判定 = Random(0, 1) < (熟练度双倍概率 + HARVESTING + 工具词条) ? ×2 : ×1
副产物   = Random(0, 1) < 副产物概率 ? 从副产物池随机选1个 : 无

最终产量 = (基础产量 + 完美加成) × 双倍判定 + 副产物
```

### 4.4 熟练度经验获取

```
exp_gain = base_exp × rarity_multiplier × perfect_bonus

其中：
  base_exp = 10（采矿）/ 10（采药）
  rarity_multiplier: T1=1.0, T2=1.5, T3=2.5, T4=4.0, T5=6.0, T6=9.0, T7=14.0
  perfect_bonus = 完美采集 × 1.5，普通采集 × 1.0
```

## 7. 已实现原型（工程记录）

以下为主场景已落地的 **简化采集** 与 **拾取反馈**，与上文 Phase 1~4 的完整规划并存；实现以当前代码为准，便于后续替换为工具/熟练度公式。

### 7.1 采集节点 `GatheringSpot`

| 项目 | 说明 |
|------|------|
| 脚本 / 场景 | `scripts/world/gathering_spot.gd`（`class_name GatheringSpot`）、`scenes/world/gathering_spot.tscn` |
| 基类 | `InteractableObject`（`scripts/chapter1/interactable_object.gd`） |
| 交互键 | **E**（在 `_ready` 中固定为 `KEY_E`） |
| 读条规则 | **按住 E** 累积进度，**松开** 则进度清零；离开感应范围同样清零 |
| 产出 | `item_id` / `quantity` 来自导出字段，成功后 `Player.try_pickup_item()` |
| 背包满 | 仍视为采集成功：扣耐久并刷新/销毁节点，产物以 **`WorldItem.spawn_at`** 掉在采集点附近，飘字仅提示「背包已满」 |
| 刷新 | `respawn_sec > 0`：隐藏并关闭 `monitoring`，计时结束后恢复并调用 `refresh_player_overlap()`，避免玩家站叠上不触发 |
| 一次性 | `respawn_sec == 0`：成功后 `queue_free()` |
| 工具与耐久 | 需在 **`Equipment.Slot.TOOL`** 装备 **矿镐**（`ItemSubType.PICKAXE`）或 **药锄**（`HOE`），且 **耐久 > 0**；读条中若不符会 **飘字提示**（约 0.85s 节流）；成功采集后 **`Player.apply_gathering_tool_wear(1)`** 扣 1 耐久，**耐久为 0 时物品不消失**，仅无法继续采集 |
| 主场景示例 | `scenes/main.tscn` 下 `GatheringSpots`：铜矿×2、铁矿×1、风绒草×2、月瓣花×1 |

**`InteractableObject` 增补**：`is_player_in_range()`、`is_consumed()`、`refresh_player_overlap()`，供采集点与重生逻辑使用。

### 7.2 物品目录（采集用材料与工具）

在 `resources/items/item_catalog.json` 中已注册示例材料：`ore_copper`、`ore_iron`、`ore_tin`、`herb_windgrass`、`herb_moonpetal`、`herb_redroot` 等；工具：`tool_wood_pickaxe`（木矿镐）、`tool_wood_hoe`（木药锄），`item_type: TOOL`，`max_durability: 10`，`max_stack: 1`。

**装备栏工具槽与耐久存储**：`equipment.gd` 中 `Slot.TOOL` 启用，`set_item` / `get_slot_durability`；`Player.equip_from_inventory` / `unequip_to_inventory` 同步耐久；`inventory.gd` 格子可含 `durability`，耐用品移动时不合并堆叠；`player_runtime_state.gd` 序列化耐久（旧装备存档字符串仍兼容）；`InventorySlotUI` / `EquipmentSlotUI` 与 Tooltip 显示 **当前/最大耐久**。
