## 四、关键机制

### 选择与仁义智（v10 分支表对接）

| 选择点 | 实现 | 数值 |
|---|---|---|
| 算卦 / 不算（M-序-03） | `StoryChoiceUI`，算卦消耗 1 金币；算卦后再次对话触发隐藏台词 | flag `xu_fortune_told` / `xu_fortune_hidden_heard` |
| 上前查看 / 观望（M-序-05，限时 6 秒） | 超时默认「观望」 | 上前 → 仁+1，flag `xu_luhong_approached` |
| 注视周伯（M-序-05 结尾，3 秒窗口按交互键） | `_gaze_window()` | 注视 → 智+1，flag `observed_zhou_bo` |

### 箭靶命中

箭矢（`arrow.tscn`，mask=2）撞上靶身（layer 含 2）→ `ProjectileBase._on_collide` 调 `receive_hit()` → `target_hit(target_id)` → flow 推进 CUSTOM 目标。远距靶首次命中触发周伯「还行。」（v10 设计）。

### 搀扶护送

- 减速：`StatModifier.create_percent_add("story_luhong_carry_slow", MOVE_SPEED, -0.4)`，到院子入口（距离判定 56px）移除
- 暗角：`EscortVignette.set_active(true/false)`
- 陆鸿 CARRIED 状态下每帧贴在玩家身侧

### 读档恢复

`Chapter1QuestFlow._restore_progress()` 按 `QuestManager` 任务状态 + 目标进度重建场景实体（如：追鸡进行中且已抓到 → 鸡直接进入 CARRIED；血路来客已搀扶 → 陆鸿 CARRIED + 减速/暗角生效）。

## 五、接入美术 / 动画的方式

所有占位实体表现集中在各自脚本的 `_draw()`；逻辑通过 `state_changed(new_state)` 信号驱动。替换步骤：

1. 在实体节点下挂 `Sprite2D` / `AnimatedSprite2D` / `AnimationPlayer`
2. 订阅 `state_changed`，按状态切动画（如鸡的 FLEEING → 跑动画）
3. 删除/清空 `_draw()` 占位绘制即可，任务逻辑零改动
