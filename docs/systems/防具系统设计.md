# 防具系统设计

> 头/胸/腿三种防具，覆盖 L1-L30，含基础套装、专精套装、散件，以及套装效果机制。

---

## 一、设计原则

1. **数值不膨胀**：护甲值增速递减，L30 全套 ≈ L1 全套的 10 倍防御 + 8 倍 HP，与角色自身成长（属性 v3 约 5-8 倍 HP 成长）相匹配
2. **三部位权重**：胸甲 = 基准(100%)、头部 ≈ 40%、腿部 ≈ 65%
3. **专精有代价**：专精套装用防御换功能（输出/机动/续航），定位差异化
4. **套装激励**：2 件套小加成、3 件套质变效果，鼓励收集全套

---

## 二、防具基础规则

### 2.1 装备槽位

沿用 `Equipment.Slot`：`HEAD(1)` / `BODY(2)` / `LEGS(3)`。

### 2.2 等级需求

新增 `required_level` 字段（`ItemData`），装备时校验。不满足等级 → UI 红色提示 + 拒绝装备。

### 2.3 词条字段（ArmorData 扩展）

现有 5 字段：`bonus_armor`、`bonus_magic_resist`、`bonus_hp_max`、`bonus_mp_max`、`bonus_attack_power`

新增字段（均可 0，不写 JSON 则默认 0）：

| 字段 | 属性 ID | 类型 |
|------|---------|------|
| `bonus_crit_rate` | crit_rate | flat |
| `bonus_crit_damage` | crit_damage | flat |
| `bonus_attack_speed` | attack_speed | flat |
| `bonus_evasion` | evasion | flat |
| `bonus_cdr` | cdr | flat |
| `bonus_move_speed` | move_speed | flat |
| `bonus_lifesteal` | lifesteal | flat |
| `bonus_hp_regen` | hp_regen | flat |
| `bonus_mp_regen` | mp_regen | flat |
| `bonus_damage_all` | damage_bonus_all | flat |
| `bonus_penetration` | penetration | flat |
| `bonus_res_fire` | res_fire | flat |
| `bonus_res_ice` | res_ice | flat |
| `bonus_res_lightning` | res_lightning | flat |
| `bonus_res_poison` | res_poison | flat |

所有词条通过 `build_modifiers(source_tag)` 自动注入角色属性。

### 2.4 套装字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `set_id` | String | 套装标识（空=非套装），如 `"leather"`, `"iron"` |
| `required_level` | int | 装备等级需求，0=无限制 |

### 7.2 L30 参考值

以属性 v3 的「均衡 30 级」（五维各 ≈50）为基准：

| 指标 | 裸装 | 龙鳞全套 | 提升 |
|------|:---:|:---:|:---:|
| 护甲 | ~72 | ~326 (+254) | +353% |
| HP | ~550 | ~1329 (+779) | +142% |
| 物攻 | ~112 | ~117 (全属性+5) | +4% |
| 减伤(物) | ~42% | ~77% (+10%套装) | — |

L30 怪物对裸装均衡玩家一击约 80-120 伤害，龙鳞套承受约 18-28 → 可抗 47-74 击，符合"坦克 build 站得住"的预期。

### 7.3 极端配装（混搭）

玩家可以混搭不同套装获取多个 2 件套效果（牺牲 3 件套）。例如：
- 龙鳞头+胸（2件：HP+500） + 守护者腿（1件：无加成）
- 暗影头+胸（2件：暴击+4%） + 血骑士腿（1件：无加成）
→ 比纯血骑士套多了暴击，少了吸血 3 件效果

这是有意保留的构建自由度。
