# 玩家行走动画节奏

> 实现：`scripts/player/player.gd` + `scenes/player.tscn`（`AnimatedSprite2D` / `SpriteFrames`）  
> 相关：`./玩家冲刺与撞敌.md`（冲刺位移不受本节奏影响）

---

## 一、目标

侧面行走（`walk_left`）若全程匀速位移，角色会像在冰面上滑，与脚步动画脱节。  
本方案用 **美术重复帧（落脚驻留）** + **代码按帧压移速** 两步，做出「蹬一步 → 略顿 → 再蹬」的步态节奏。

`walk_up` / `walk_down` 目前仍为匀速；若日后有类似重复帧，可复用同一套 `_get_locomotion_speed_scale` 逻辑。

动画名与预设角色统一：`idle` / `walk_down` / `walk_left` / `walk_up`（施法仍为 `spell_west`）。运行时可 `Player.apply_preset_character("mainplayer")` 切换到登记表预设外观。

---

## 二、美术：SpriteFrames 重复帧

在 `scenes/player.tscn` 的 `walk_left` 动画中，将**落脚姿势**的贴图连续插入两帧，延长该姿势在循环中的占比：

| 0-based 帧号 | 说明 |
|-------------|------|
| 0–1 | 迈步 / 过渡 |
| **2、3** | 同一落脚贴图（`AtlasTexture_i4ail`）重复 |
| 4–5 | 蹬地 / 过渡 |
| **6、7** | 同一落脚贴图（`AtlasTexture_l71n6`）重复 |

一个 8 帧循环里约有 **一半帧** 是落脚驻留，视觉上已有顿挫；再配合下文移速倍率，位移与脚点地同步。

调整节奏时优先改：

- 重复帧的 **`duration`**（单帧停留更久 → 动画侧更「黏」）
- `walk_left` 的 **`speed`**（整体播放 FPS，当前 `8.0`）

## 三、代码：按当前帧压移速

### 流程（`_physics_process`）

1. 读输入 `move_vec`
2. 冲刺中 → `DashAbility` 接管速度，**不**应用行走节奏
3. **`_update_locomotion_animation(move_vec)`** — 先确定当前播放哪条动画、哪一帧
4. **`velocity = _get_target_velocity(move_vec)`** — 基础移速 × 属性加成 × **节奏倍率**
5. `move_and_slide()`

必须先更新动画再算速度，保证 `_animated_sprite.frame` 与当帧位移一致。

### 节奏倍率

```gdscript
func _get_target_velocity(move_vec: Vector2) -> Vector2:
    return move_vec * _get_effective_move_speed() * _get_locomotion_speed_scale(move_vec)
```

仅当 **正在播放 `walk_left`** 且当前 `frame` 落在 `walk_side_rhythm_hold_frames` 内时，返回 `walk_side_rhythm_hold_speed_scale`；否则为 `1.0`。

### 动画方向（`_update_locomotion_animation`）

| 输入 | 动画 | 备注 |
|------|------|------|
| 静止 | `idle` | 保持上次水平 `flip_h` |
| 主轴为左右 | `walk_left` | 向右 `flip_h = true` |
| 主轴向下 | `walk_down` | 无则回退 `walk_left` |
| 主轴向上 | `walk_up` | 不翻转 |

坐标系：屏幕上为 **-Y（向北）**，与 `KeyboardInputProvider` 一致。

## 四、检查器可调项（Player 根节点）

| 属性 | 类型 | 默认（脚本） | 说明 |
|------|------|-------------|------|
| `walk_side_rhythm_hold_frames` | `PackedInt32Array` | `[2, 3, 6, 7]` | 落脚驻留帧，**0-based**，须与 SpriteFrames 重复帧对齐 |
| `walk_side_rhythm_hold_speed_scale` | `0.0 ~ 1.0` | `0.9` | 落脚帧上的移速倍率 |

### 调参经验

| `hold_speed_scale` | 体感 |
|--------------------|------|
| `0.0` | 落脚完全停步，节奏最重，容易显「一卡一卡」 |
| `0.5 ~ 0.7` | 有明显重量感，顿挫适中（迭代中常用区间） |
| `0.9 ~ 1.0` | 几乎匀速，仅保留轻微起伏 |

若改完 `walk_left` 帧数或重复位置，务必同步改 `walk_side_rhythm_hold_frames`。

## 五、扩展备忘

1. **`walk_up` / `walk_down` 节奏**：在 `_get_locomotion_speed_scale` 中增加分支，并配置独立 hold 帧列表（或共用 `@export`）。
2. **预设换装**：`apply_preset_character` / `restore_default_visual`；换装时自动合并默认 `spell_west`。
3. **不要对冲刺套用**：冲刺速度由 `PlayerDashAbility` 固定，已绕过 `_get_target_velocity`。
