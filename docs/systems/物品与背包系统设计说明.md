## 1. 功能范围（当前已实现）
- 物品类型（`ItemType`）分为三种：**武器**（`WEAPON`）、**材料**（`MATERIAL`）、**其他**（`OTHER`）。`ItemData.type_display_name()` 可获取中文显示名。
- 物品静态配置来自 **`resources/items/item_catalog.json`**（名称、描述、单价、图标色、类型、堆叠、重量等）；`ItemDatabase` 启动时加载。
- 货币在配置中为「金币」，简称「金」；玩家持有量：`Player.gold`；背包状态栏显示当前金币数。
- 物品数据运行时还包含：`value_gold`（单个价值，来自 JSON 的 `value` 字段）。
- 背包固定 `10` 格（`Inventory.SLOT_COUNT = 10`）。
- 同 `id` 物品可自动堆叠；超过 `max_stack` 会自动分配到新格子。
- 按 `B` 打开/关闭背包，按 `Esc` 关闭背包。
- 背包格子悬停：名称、描述；**提示框右下角**显示单价（简称）与堆叠时的总价。
- 背包格子支持拖拽：可交换位置；同类物品会优先合并堆叠。
- 主场景生成石头、木头世界物品，靠近自动拾取。
- 玩家默认携带三把武器（弓、剑、枪）在物品栏中，品级均为白色普通。
- 当背包容量不足时，拾取失败（物品保留在地上）。
- 世界掉落默认每个节点 `quantity = 1`（已统一调整）。

## 2. 架构与数据流

### 2.1 主要对象关系
- `ItemData`：单个物品定义（静态配置）。
- `ItemDatabase`（autoload）：从 `item_catalog.json` 加载并注册物品；提供 `currency_name` / `currency_abbr`。
- `Inventory`：玩家背包容器，管理槽位数组、堆叠规则、移动规则。
- `Player`：持有 `inventory` 实例，并提供 `try_pickup_item()` 给世界物品调用。
- `WorldItem`：场景中的可拾取物品实体（`Area2D`）。
- `InventoryUI` / `InventorySlotUI`：背包展示和交互层（输入、tooltip、拖拽）。

### 2.2 拾取流程
1. 玩家进入 `WorldItem` 的检测范围（`body_entered`）。
2. `WorldItem` 调用 `Player.try_pickup_item(item_data, quantity)`。
3. `Player` 内部先调用 `inventory.can_add_item(...)` 判断是否可放下全部数量。
4. 可放下则执行 `inventory.add_item(...)`，并触发 `inventory_changed` 信号。
5. `WorldItem` 拾取成功后 `queue_free()`。
6. `InventoryUI` 监听信号后刷新对应格子与状态栏。

### 2.3 拖拽流程
1. `InventorySlotUI._get_drag_data()` 返回 `{ "from_slot": slot_index }`。
2. 目标格子 `_drop_data()` 调用 `inventory.move_item(from, to)`。
3. `move_item()` 内部优先做同类堆叠合并，否则做槽位交换。
4. 发出 `inventory_changed`，UI 自动刷新。

## 3. 关键文件清单

## 数据层
- `scripts/core/items/item_data.gd`
  - `class_name ItemData`
  - 物品字段定义与类型枚举。
- `resources/items/item_catalog.json`
  - 物品目录：`currency` + `items`（按 `id` 配置）。
- `scripts/core/items/item_database.gd`
  - 自动加载单例，读取目录注册全部物品。
- `scripts/core/items/inventory.gd`
  - `class_name Inventory`
  - 核心 API：`can_add_item`、`add_item`、`remove_item`、`move_item`。

## 逻辑层
- `scripts/player/player.gd`
  - 持有 `inventory`、`gold`（金币数量）。
  - 提供 `try_pickup_item(item_data, quantity)`。
- `scripts/world/world_item.gd`
  - 可拾取物，读取 `item_id` + `quantity`，进入范围后触发拾取。

## 展示层
- `scripts/ui/inventory_ui.gd`
  - 背包主 UI，负责 B/Esc 输入、格子创建、tooltip 容器、状态栏。
- `scripts/ui/inventory_slot_ui.gd`
  - 格子绘制、数量显示、悬停信号、拖拽数据。

## 场景与工程配置
- `scenes/world/world_item.tscn`：世界物品预制。
- `scenes/ui/inventory_ui.tscn`：背包 UI 场景。
- `scenes/main.tscn`：挂载 `InventoryUI`，并放置 `WorldItems`（stone/wood）。
- `project.godot`：`[autoload]` 中注册 `ItemDatabase`。

## 4. 数据结构约定

### 4.1 ItemData
- `id: String`：全局唯一主键（必须唯一，建议小写下划线风格）。
- `item_name: String`：显示名。
- `description: String`：描述文本。
- `icon_color: Color`：当前占位图标颜色（后续可替换为贴图字段）。
- `item_type: ItemType`：类型枚举（`WEAPON`=武器, `MATERIAL`=材料, `OTHER`=其他）。
- `max_stack: int`：单格最大堆叠数。
- `weight: float`：预留给负重系统。
- `value_gold: int`：单个物品金币价值（由目录 `value` 填入）。

### 4.2 Inventory 槽位
- 内部结构：`_slots: Array`，长度固定 10。
- 每个槽位取值：
  - `null`：空格子
  - `Dictionary`：`{ "item": ItemData, "quantity": int }`

---

## 5. 交互规则（重要）
- **自动堆叠规则**：同 `item.id` 先填充已有堆叠，再占用空格。
- **拾取判定**：必须“整包可放下”才拾取成功；不做部分拾取。
- **拖拽规则**：
  - 同类物品：优先合并到目标格（受 `max_stack` 限制）。
  - 非同类或无法合并：交换两个格子内容。
- **UI持久性**：
  - 关闭背包只隐藏 UI，不重置 `Inventory` 数据。
  - 当前持久性为“本次运行内持久”；未落盘保存到磁盘。

## 6. 常见改动入口（给后续开发）

### 新增物品（推荐流程）
1. 打开 `resources/items/item_catalog.json`，在 `items` 字典里新增一条 `id -> 配置` 条目（参考已有 `stone` / `wood` / `bow` 写法，填 `item_name` / `description` / `value` / `max_stack` / `item_type` / `icon_color` 等字段）。`item_type` 填写 `WEAPON`、`MATERIAL` 或 `OTHER`。
2. 重启游戏或重新加载 `ItemDatabase` autoload，即可在 `ItemDatabase.get_item_by_id(id)` 取到。
3. 在场景中的 `WorldItem` 设置对应 `item_id`。

> 早期版本在 `item_database.gd._register_all_items()` 里硬编码注册；**当前实现改为从 JSON 读取**（`ItemDatabase._load_catalog()`），不要再回到代码里新增物品。

### 调整背包容量
- 修改 `scripts/core/items/inventory.gd` 中 `SLOT_COUNT`。
- `InventoryUI` 网格是按 `Inventory.SLOT_COUNT` 动态创建，无需额外改动。

### 改为贴图图标
- 在 `ItemData` 增加 `@export var icon: Texture2D`。
- 在 `InventorySlotUI._draw()` 与 `WorldItem._draw()` 中改用贴图绘制。

### 改成“部分拾取”
- 目前 `Player.try_pickup_item()` 依赖 `can_add_item()` 全量检查。
- 可改为：先计算可容纳数量，再部分入包并扣减世界物品 `quantity`。

### 改成“存档持久化”
- 新增存档服务（JSON/Resource）。
- 在场景退出或手动保存时序列化 `inventory._slots`（存 `item_id + quantity`）。
- 启动时读取并重建槽位。

## 7. 已知限制与注意事项
- `ItemDatabase` 现在从 `resources/items/item_catalog.json` 外部加载（非硬编码）。如果 JSON 解析失败，`ItemDatabase` 目前**不会回退**到硬编码，需要留意日志里的加载报错。
- `Inventory` 使用 `Dictionary + Variant`，后续可改为强类型 `InventorySlot` 资源类减少类型警告风险。
- 当前没有“拆分堆叠（半分/按数量拆分）”交互。
- 当前没有“丢弃到地面”的反向流程。
- 当前没有“物品使用/消耗”逻辑，仅有入包/移动/移除基础能力。

## 9. 快速自测清单
- 进入主场景，靠近石头/木头，背包数量应 +1。
- 连续拾取同类物品，应在同格堆叠，超过上限后分配到新格。
- 按 `B` 打开背包，再按 `B` 或 `Esc` 关闭。
- 鼠标悬停物品格，显示名称和描述。
- 拖拽物品到其他格，位置应改变且不在 UI 重开后重置。
- 背包满时，世界物品不应被拾取和销毁。
