# 怪物系统设计

> **项目**：openworldtest  
> **引擎**：Godot 4.x  
> **设计日期**：2026-05-04  
> **目标**：建立与玩家属性体系匹配的怪物数值框架，设计多样化的怪物类型与特殊机制，避免数值俗套

---

## 1. 设计目标

1. **数值匹配** — 怪物属性基于玩家同等级数值推导，确保PVE体验可控
2. **类型差异化** — 不同职业倾向的怪物（战士/刺客/法师/弓箭手/肉盾/狂战士/召唤师）有显著不同的战斗体验
3. **避免数值俗套** — 通过词缀、变异、融合、行为机制创造"数值×机制"的乘法级多样性
4. **易于扩展** — 新怪物类型/词缀/变异均通过 Resource 配置，无需改代码
5. **最小侵入** — 复用现有 `CharacterAttributes` + `CombatantComponent` + `EnemyBase` + `MonsterSpawner` 架构

---

## 2. 怪物属性计算框架

### 2.1 核心公式

```
怪物主属性 = 参考玩家主属性 × 职业倍率 × 稀有度倍率 × 变异倍率
```

其中：
- **参考玩家**：同等级下"自由点均分"的均衡构建玩家（属性公式见 `../narrative/角色属性v3.md`，旧《等级属性系统设计》已删除）
- **职业倍率**：怪物类型的属性倾向（见 §3）
- **稀有度倍率**：普通/精英/Boss 的强度倍率（见 §4）
- **变异倍率**：变异词条的属性修正（见 §6）

### 2.2 计算流程

```
SpawnLevel(区域等级)
    │
    ├── 1. 查表得参考玩家主属性 (STR/AGI/INT/CON/LUK)
    │
    ├── 2. × MonsterType.profile → 类型基础属性
    │
    ├── 3. × Rarity.multiplier → 稀有度缩放
    │
    ├── 4. 叠加 Mutation 属性修正 → 最终主属性
    │
    ├── 5. 通过 CharacterAttributes 计算派生属性 (HP/ATK/DEF等)
    │
    ├── 6. 叠加 Affix StatModifier (词缀修正，如 +30%火伤)
    │
    └── 7. 叠加 Fusion 修正 (融合怪，取双类型平均值 + 额外倍率)
```

### 2.3 怪物派生公式微调

怪物复用玩家的 `CharacterAttributes` 派生公式，但HP/MP截距降低（怪物不需要玩家的生存缓冲）：

| 派生属性 | 玩家公式 | 怪物公式 | 调整原因 |
|---------|---------|---------|---------|
| `hp_max` | `100 + CON×15 + STR×3` | `50 + CON×15 + STR×3` | 降低低等级怪物的HP占比，使稀有度倍率更准确 |
| `mp_max` | `50 + INT×12` | `20 + INT×12` | 同上 |

其他派生公式与玩家完全一致（物攻、魔攻、护甲、魔抗、暴击、闪避、CDR等）。

## 3. 怪物职业类型

### 3.1 七种基础类型

每种类型定义了一个"属性倾向倍率"——相对于同等级均衡玩家的主属性比例：

| 类型 | STR | AGI | INT | CON | LUK | 战斗风格 |
|------|-----|-----|-----|-----|-----|---------|
| **战士 Warrior** | 1.3 | 0.8 | 0.6 | 1.1 | 0.8 | 近战物理，攻守均衡 |
| **刺客 Rogue** | 0.7 | 1.4 | 0.5 | 0.7 | 1.3 | 高速近战，高暴击低血量 |
| **法师 Mage** | 0.4 | 0.7 | 1.5 | 0.6 | 0.9 | 远程魔法，玻璃大炮 |
| **弓箭手 Archer** | 0.9 | 1.2 | 0.5 | 0.8 | 1.0 | 远程物理，机动性高 |
| **肉盾 Tank** | 0.8 | 0.5 | 0.4 | 1.6 | 0.6 | 超高血量，伤害低下 |
| **狂战士 Berserker** | 1.6 | 0.9 | 0.3 | 0.5 | 0.7 | 极限物理输出，极度脆弱 |
| **召唤师 Summoner** | 0.5 | 0.7 | 1.2 | 0.8 | 1.1 | 中程魔法，召唤小怪助战 |

### 3.2 类型的战斗行为差异

| 类型 | 攻击距离 | 移动速度 | 攻击节奏 | AI模式 |
|------|---------|---------|---------|--------|
| 战士 | 近战(40px) | 中(75px/s) | 均匀 | 逼近→近战 |
| 刺客 | 近战(35px) | 快(110px/s) | 爆裂 | 绕后→连击→脱离 |
| 法师 | 远程(200px) | 慢(55px/s) | 蓄力 | 保持距离→施法 |
| 弓箭手 | 远程(180px) | 中(72px/s) | 连射 | 保持距离→射击 |
| 肉盾 | 近战(45px) | 慢(50px/s) | 缓慢 | 缓慢逼近→嘲讽 |
| 狂战士 | 近战(42px) | 中快(90px/s) | 狂乱 | 冲锋→无间断攻击 |
| 召唤师 | 远程(150px) | 中(65px/s) | 间隔 | 召唤→远程魔法→再召唤 |

### 3.3 类型的技能倾向

每种类型携带1-2个代表性技能，而非全部使用相同的"走过去普攻"模式：

| 类型 | 技能1 | 技能2 | 特殊被动 |
|------|------|------|---------|
| 战士 | 横扫（扇形AOE） | 盾击（短暂眩晕） | 格挡几率+10% |
| 刺客 | 暗影突袭（闪现背刺） | 毒刃（中毒DOT） | 背后攻击+30%伤害 |
| 法师 | 火球（远程单体） | 冰环（自身周围冻结） | 魔法穿透+15% |
| 弓箭手 | 多重箭（扇形3箭） | 后跳射击（后撤+1箭） | 远程暴击率+10% |
| 肉盾 | 战吼（范围嘲讽+减伤） | 地裂（直线击退） | 受治疗量+25% |
| 狂战士 | 旋风斩（360°持续伤害） | 狂暴（自损血+高增伤） | 低血量时攻速+30% |
| 召唤师 | 召唤小怪（2-3只） | 暗影箭（远程魔法） | 小怪死亡时回血 |

## 4. 稀有度梯度

### 4.1 四级稀有度

| 稀有度 | 倍率 | 视野标识 | 掉落倍率 | 设计意图 |
|--------|------|---------|---------|---------|
| **普通 Common** | ×0.6 | 白色名字 | ×1.0 | 可轻松处理，3-5只成组出现 |
| **精英 Champion** | ×1.2 | 蓝色名字+光环 | ×3.0 | 需要一定装备支撑，1-2只带领普通怪 |
| **首领 Boss** | ×2.5 | 金色名字+Boss血条 | ×10.0 | 对玻璃大炮有击杀威胁，坦克可持久战 |
| **世界首领 World Boss** | ×4.0 | 红色名字+全屏通告 | ×25.0 | 需要组队或极高练度，限时刷新 |

### 4.2 稀有度对行为的影响

精英及以上稀有度会获得额外的机制能力（不只是数值放大）：

| 稀有度 | 额外机制 |
|--------|---------|
| 普通 | 无 |
| 精英 | 随机获得 1-2 个词缀（Affix），如"火焰附魔"、"吸血鬼"等 |
| 首领 | 固定 2-3 个词缀 + 至少1个阶段转换机制（Phase Shift） |
| 世界首领 | 固定 3-4 个词缀 + 多个阶段 + 环境互动机制 |

## 6. 词缀系统（Affix）

> 参考：Diablo 系列的 Elite Affix、Path of Exile 的 Nemesis Mod、Hades 的 Benefits Package

词缀是附加在精英及以上怪物上的随机能力，是**打破数值俗套的核心机制之一**。词缀改变的不只是数值，而是战斗规则。

### 6.1 词缀分类

#### 元素类（决定伤害属性和特效）

| 词缀 | 效果 | 视觉 |
|------|------|------|
| 火焰附魔 | 攻击转为火焰伤害，命中留下火焰地面(3s) | 红色光晕 + 火焰粒子 |
| 冰霜附魔 | 攻击转为冰霜伤害，命中减速30%/2s | 蓝色光晕 + 冰晶 |
| 闪电附魔 | 攻击转为闪电伤害，命中后连锁弹跳3目标 | 黄色电弧 |
| 毒素附魔 | 攻击附加中毒(5s DOT，可叠加) | 绿色烟雾 |
| 暗影附魔 | 攻击转为暗影伤害，概率致盲(视野缩小) | 紫色暗影 |

#### 攻防类（改变战斗节奏）

| 词缀 | 效果 |
|------|------|
| 吸血鬼 | 造成伤害的15%转化为自身HP |
| 荆棘皮肤 | 反射受到物理伤害的20% |
| 魔法反射 | 每隔8s获得一个反射魔法弹的护盾(持续3s) |
| 石肤 | 护甲+50%，移动速度-25% |
| 迅捷 | 移动速度+40%，攻击速度+30% |
| 巨人 | 体型×1.5，HP+40%，攻击力+25%，速度-20% |

#### 战术类（改变AI和行为）

| 词缀 | 效果 |
|------|------|
| 传送者 | HP<50%时随机传送（CD 8s） |
| 分裂者 | 死亡时分裂为2只小型版（HP/ATK 40%） |
| 复活者 | 死亡后3s原地复活一次（HP 50%） |
| 幻象师 | 每15s制造1个幻象（HP 30%，无伤害，混淆目标） |
| 筑墙者 | 每隔12s在玩家周围生成临时墙壁(持续4s) |
| 牵引者 | 每隔10s将玩家向自己拉近一段距离 |

#### 光环类（影响周围）

| 词缀 | 效果 |
|------|------|
| 强击光环 | 周围怪物攻击力+20% |
| 护盾光环 | 周围怪物获得最大HP 10%的护盾(每10s刷新) |
| 回复光环 | 周围怪物每秒回复1%最大HP |
| 迟缓光环 | 周围玩家移动速度-20% |
| 禁疗光环 | 周围玩家受治疗量-50% |

### 6.2 词缀分配规则

| 稀有度 | 词缀数量 | 词缀池 |
|--------|---------|--------|
| 普通 | 0 | — |
| 精英 | 1-2 | 元素类1 + 攻防/战术/光环类1 |
| 首领 | 2-3 | 元素类必选1 + 其余类 |
| 世界首领 | 3-4 | 任意组合，可重复同类 |

## 7. 变异系统（Mutation）

> 参考：Risk of Rain 2 的 Elite 变体、Path of Exile 的 Bestiary、辐射系列的变异生物

变异是怪物生成时小概率获得的**永久性改变**，影响属性、外观和行为。变异与词缀的区别：变异是**生成时就决定的永久特征**，词缀是**稀有度触发的额外能力**。

### 7.1 变异类型

#### 体型变异

| 变异 | 概率 | 效果 | 视觉 |
|------|------|------|------|
| 巨型化 | 3% | 体型×2，HP+60%，伤害+40%，速度-30% | 放大 + 深色 |
| 微型化 | 2% | 体型×0.5，速度+50%，攻速+40%，HP-30% | 缩小 + 加速动画 |

#### 元素变异

| 变异 | 概率 | 效果 | 视觉 |
|------|------|------|------|
| 腐化 | 3% | 伤害转为暗影，命中附加"腐蚀"减防debuff | 紫色暗影 + 黑雾 |
| 圣化 | 1% | 伤害转为光耀，免疫暗影伤害，掉落增加 | 金色光晕 |
| 狂化 | 4% | 攻击+40%，双防-30%，一直处于攻击状态 | 红光闪烁 |

#### 行为变异

| 变异 | 概率 | 效果 |
|------|------|------|
| 胆怯 | 2% | HP<50%时逃跑，速度+60% |
| 复仇 | 3% | 同伴死亡时获得+30%伤害+30%攻速(持续10s，可叠加) |
| 领地意识 | 5% | 不会离开生成点超过200px，但在此范围内属性+25% |

#### 外观变异（稀有）

| 变异 | 概率 | 效果 |
|------|------|------|
| 白化 | 0.5% | 白色外观，掉落×5，成就相关 |
| 暗影 | 0.3% | 半透明，概率闪避物理攻击(+15%闪避) |
| 黄金 | 0.1% | 金色外观，掉落×10，必定掉落稀有装备 |

### 7.2 变异叠加规则

- 同一怪物可拥有多个变异（各独立概率）
- 体型变异互斥（不能同时巨型+微型）
- 元素变异互斥（不能同时腐化+圣化）
- 外观变异可与其他任意变异叠加
- 理论最大：1体型 + 1元素 + 1行为 + 1外观 = 4个变异叠加

## 8. 融合系统（Fusion）

> 参考：Persona 系列的合体、怪物圣所（Monster Sanctuary）的双怪物协作

融合是两种不同类型怪物在生成时"合并"为一只新怪物的机制。融合怪物拥有双方的特征，产生1+1>2的战斗体验。

### 8.1 融合规则

- 生成时有10%概率触发融合（可配置）
- 从当前区域的怪物池中随机选2种不同类型
- 融合怪属性 = 两类型倍率的平均值 × 1.15（融合加成）
- 融合怪拥有双方的技能池
- 融合怪外观 = 主体A的体型 + B的颜色/特效
- 掉落 = 双方掉落表的并集

### 8.2 融合示例

| 融合组合 | 名称 | 特征 | 战斗体验 |
|---------|------|------|---------|
| 战士+法师 | **魔剑士** | STR×0.85, INT×1.05 — 近战带魔法伤害，会横扫+火球 | 中距离混合伤害，不能单一防御 |
| 刺客+弓箭手 | **狙击者** | AGI×1.3 — 超远射程+高暴击，近身会暗影突袭脱离 | 需要近身但不能被风筝 |
| 肉盾+治疗 | **圣骑士** | CON×1.2, INT×0.8 — 高血量+自疗+光环 | 极其耐打，拖久了回满血 |
| 狂战士+法师 | **混沌骑士** | STR×0.95, INT×0.9 — 随机物理/魔法伤害，旋风斩带元素 | 无法针对性防御 |
| 召唤师+肉盾 | **虫巢领主** | CON×1.2, INT×0.8 — 召唤肉盾小怪，自身缓慢回血 | 小怪打不死，Boss慢慢磨 |

### 8.3 融合怪命名规则

```
[前缀-来自副类型] + [主体类型名]

前缀表：
  战士+法师 → 魔剑
  刺客+弓箭手 → 狙击
  肉盾+法师 → 圣光
  狂战士+刺客 → 血影
  ...（可扩展）
```

## 9. 行为机制设计

> 参考：黑暗之魂的敌人AI、怪物猎人的怪物状态机、Slay the Spire的意图系统

### 9.1 阶段转换（Phase Shift）

首领级怪物在HP达到阈值时转换行为模式：

| 阶段 | HP阈值 | 行为变化 |
|------|--------|---------|
| P1 | 100%-60% | 正常模式，使用基础技能 |
| P2 | 60%-25% | 新增1-2个技能，攻击频率+30%，可能改变移动模式 |
| P3 | <25% | 狂暴：攻击+30%，攻速+50%，但护甲-30%（或相反：极度防御+召唤） |

### 9.2 愤怒计时（Enrage Timer）

部分怪物（尤其是首领）内置隐藏计时器。战斗时间过长时逐渐增强：
- 每30秒：伤害+5%，攻速+3%（可叠加）
- 视觉提示：怪物越来越红，体型微微膨胀
- 设计意图：防"刮痧流"无脑磨死Boss，鼓励提升装备后回来碾压

### 9.3 队伍协作

怪物群中的不同类型的协作行为：

| 组合 | 协作行为 |
|------|---------|
| 肉盾 + 法师/弓箭手 | 肉盾在前排吸引，远程在后排输出 |
| 战士 + 刺客 | 战士正面牵制，刺客绕侧/背袭 |
| 召唤师 + 任意 | 召唤师在后排不断补充小怪 |
| 双刺客 | 轮流进场，一只打完脱离另一只进场 |

### 9.4 意图提示（可选，建议后期加）

类似 Slay the Spire，怪物在做出大动作前显示意图图标：
- ⚔️ 表示下回合使用高伤害技能
- 🛡️ 表示下回合进入防御/格挡状态
- ✨ 表示下回合使用特殊技能（召唤/治疗/AOE）

给予玩家0.5-1.0秒的反应窗口，将战斗从"拼数值"提升为"拼反应与策略"。

## 10. 攻击/防御特殊机制

### 10.1 方向性防御（盾牌怪物）

特定怪物（如持盾战士、肉盾）拥有**正面伤害减免**：
- 攻击来自正面（±60°）：伤害减免50%
- 攻击来自侧面：正常伤害
- 攻击来自背后：伤害+25%

这鼓励玩家走位绕背，而非站桩输出。

### 10.2 弱点系统

部分大型怪物/Boss拥有可破坏的部位或特定弱点：

| 弱点类型 | 效果 | 实现方式 |
|---------|------|---------|
| 头部弱点 | 受到伤害×1.5 | 独立的伤害判定区域 |
| 腿部弱点 | 受到足够伤害后怪物倒地(3s) | 累积伤害阈值触发 |
| 元素弱点 | 特定元素伤害+50% | 负元素抗性值 |
| 暴击弱点 | 对此部位必定暴击 | 暴击率强制100% |

### 10.3 护盾机制

| 护盾类型 | 机制 | 应对方式 |
|---------|------|---------|
| 白色护盾 | 额外HP条，必须先打掉才能伤血 | 正常输出 |
| 蓝色护盾 | 免疫物理伤害 | 切换魔法伤害 |
| 红色护盾 | 免疫魔法伤害 | 切换物理伤害 |
| 元素护盾 | 免疫除特定元素外所有伤害 | 使用对应元素 |
| 再生护盾 | 停止受伤5s后开始再生 | 持续施加压力 |

### 10.4 充能/蓄力打断

怪物使用强力技能前有 **0.6-1.2秒的蓄力/前摇**，此时：
- 怪物身上出现明显视觉提示（闪烁、蓄力特效）
- 若在此期间受到超过怪物最大HP 8%的伤害，技能被打断
- 若打断成功，怪物进入2秒硬直（受伤+25%）

此机制奖励反应快、输出高的玩家，同时让坦克构建也能通过"精准打断"获得战术优势。

## 12. 实施建议

### 12.1 阶段规划

#### P0 — 核心数值框架（1-2天）

1. 创建 `MonsterTypeProfile` Resource（7种类型倍率）
2. 创建 `MonsterRarity` 枚举和倍率常量
3. 在 `MonsterSpawnRule` 中接入等级→属性计算
4. 让 `EnemyBase` 或其子类接收计算后的属性并应用到 `CombatantComponent`
5. 调整怪物HP/MP公式截距（50和20）

#### P1 — 词缀系统（2-3天）

6. 创建 `MonsterAffix` Resource（效果定义 + StatModifier生成）
7. 在生成时根据稀有度随机选取词缀
8. 视觉反馈：词缀对应的光晕/粒子/颜色
9. 先实现5个核心词缀（火焰/冰霜/吸血鬼/石肤/光环），后续扩展

#### P2 — 变异系统（1-2天）

10. 创建 `MutationDef` Resource（变异定义）
11. 生成时概率投骰，叠加变异效果
12. 视觉反馈：体型缩放、颜色调整、shader叠加
13. 先实现3个变异（巨型化/微型化/狂化），验证机制可行性

#### P3 — 融合与行为机制（3-5天）

14. 融合生成逻辑（两类型平均+额外倍率）
15. 融合怪物命名和外观混合
16. 阶段转换（Phase Shift）状态机
17. 队伍协作AI（肉盾挡前、远程后排）
18. 愤怒计时器

#### P4 — 深度机制（可选）

19. 弱点系统（可破坏部位/元素弱点）
20. 护盾机制（白/蓝/红/元素/再生）
21. 意图提示UI（蓄力标识）
22. 充能打断机制

### 12.2 关键技术映射

| 设计项 | 现有基础设施 | 需新增 |
|--------|------------|--------|
| 怪物属性 | `CharacterAttributes` + `CombatantComponent` | `MonsterStatProfile` Resource |
| 属性修正 | `StatModifier` + `ModifierContainer` | 怪物侧自动生成 modifier |
| 怪物生成 | `MonsterSpawner` + `MonsterSpawnRule` | 等级→属性映射、变异概率判断 |
| 怪物行为 | `ChaseController` + `ChaseBehaviorResource` | 新行为类型（保持距离、绕后、逃跑） |
| 怪物AI | `_ai_process()` 虚函数 | 类型特定AI子类 |
| 词缀/Buff | `BuffDef` + `BuffRuntime` | 词缀用 Buff 或 StatModifier 实现 |
| 视觉 | `AnimatedSprite2D` + shader | 光晕shader、变色shader、缩放 |
| 伤害类型 | `DamageTypes.Type` 枚举 | 已完整，可直接使用 |

### 12.3 数据流示例（生成一只"火焰附魔·巨型·精英战士"）

```
1. MonsterSpawner 决定生成: type=WARRIOR, rarity=ELITE, level=30
2. 查参考玩家 Lv30: STR=AGI=INT=CON=LUK=56
3. × Warrior profile: STR×1.3, AGI×0.8, INT×0.6, CON×1.1, LUK×0.8
   → {STR=72.8, AGI=44.8, INT=33.6, CON=61.6, LUK=44.8}
4. × Elite rarity(×1.2):
   → {STR=87.4, AGI=53.8, INT=40.3, CON=73.9, LUK=53.8}
5. 变异判定: 巨型化(3%) = 命中!
   × 体型变异: STR×1.5, CON×1.5, AGI×0.7
   → {STR=131.1, AGI=37.7, INT=40.3, CON=110.9, LUK=53.8}
6. CharacterAttributes 计算派生:
   → HP=50+110.9×15+131.1×3=2107, 物攻=131.1×1.5+37.7×0.3=208
7. 词缀判定(精英必1-2个): 火焰附魔 = 命中!
   → 添加 StatModifier: 攻击属性转为FIRE, 命中生成火焰地面
8. 生成完成: "巨型火焰精英战士"
   HP=2107, 物攻=208(火), 体型×2, 带火焰地面
```

### 12.4 平衡调优守则

1. **先跑基准线**: 用均衡玩家 + 普通战士 @Lv30 的 1v1 作为基准战斗，调优所有参数
2. **派生为主，主属性为辅**: 优先调整派生公式系数，不要直接改主属性（会级联影响所有派生）
3. **稀有度间隔保持**: 普通→精英(2倍强)、精英→Boss(2倍强)、Boss→世界Boss(1.6倍强)
4. **玻璃大炮测试**: 用纯INT构建玩家挑战Boss法师，确保"可被杀但不是必死"
5. **坦克持久测试**: 用纯CON构建玩家挑战Boss肉盾，确保"打得慢但打得过"
