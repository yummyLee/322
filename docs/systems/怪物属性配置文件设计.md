# 怪物属性配置文件设计

> **项目**：openworldtest  
> **引擎**：Godot 4.x  
> **设计日期**：2026-05-05  
> **目标**：同一怪物原型可通过配置文件在不同场景/区域拥有不同的等级与数值，避免为每个等级创建独立 .tscn 场景

---

## 1. 核心思路

**分离"行为模板"（.tscn）与"数值模板"（Resource）。**

- 怪物 `.tscn` 场景 = 动画、AI、碰撞、武器行为（与等级无关）
- `MonsterStatProfile` Resource = 五维属性的等级成长曲线（纯数据）
- `MonsterSpawnRule` 指定"刷什么怪物 + 刷几级"

```
MonsterSpawnRule
  ├── MonsterSpawnEntry[]   → 指向 .tscn 场景
  ├── spawn_level: int      → 该批次怪物的等级
  └── stat_profile_override → 可选，覆盖场景默认的 profile

场景加载时：
  .tscn（行为） + MonsterStatProfile（数值） × Level → 最终怪物
```

## 2. MonsterStatProfile Resource

### 2.1 字段设计

| 字段 | 类型 | 说明 |
|------|------|------|
| `archetype_name` | String | 原型名称，如 "森林怪物" |
| `level_1_str` | float | 1级时的力量基准 |
| `level_1_agi` | float | 1级时的敏捷基准 |
| `level_1_int` | float | 1级时的智力基准 |
| `level_1_con` | float | 1级时的体质基准 |
| `level_1_luk` | float | 1级时的幸运基准 |
| `str_per_level` | float | 每级力量成长 |
| `agi_per_level` | float | 每级敏捷成长 |
| `int_per_level` | float | 每级智力成长 |
| `con_per_level` | float | 每级体质成长 |
| `luk_per_level` | float | 每级幸运成长 |
| `move_speed` | float | 基础移动速度（可选，直接写死最终值） |

### 2.2 计算公式

```
怪物N级主属性 = level_1_XXX + XXX_per_level × (N - 1)
```

例：森林怪物 `level_1_str = 8`, `str_per_level = 1.5`
- Lv1: STR = 8
- Lv5: STR = 8 + 1.5 × 4 = 14
- Lv20: STR = 8 + 1.5 × 19 = 36.5

### 2.3 代码骨架

```gdscript
# scripts/enemies/monster_stat_profile.gd
class_name MonsterStatProfile
extends Resource

@export var archetype_name: String = ""

@export_group("Lv1 基准")
@export var level_1_str: float = 8.0
@export var level_1_agi: float = 8.0
@export var level_1_int: float = 8.0
@export var level_1_con: float = 8.0
@export var level_1_luk: float = 8.0

@export_group("每级成长")
@export var str_per_level: float = 1.0
@export var agi_per_level: float = 1.0
@export var int_per_level: float = 1.0
@export var con_per_level: float = 1.0
@export var luk_per_level: float = 1.0

@export_group("固定值")
@export var move_speed: float = 80.0


func get_primary_at_level(stat: StringName, level: int) -> float:
	match stat:
		&"str": return level_1_str + str_per_level * (level - 1)
		&"agi": return level_1_agi + agi_per_level * (level - 1)
		&"int": return level_1_int + int_per_level * (level - 1)
		&"con": return level_1_con + con_per_level * (level - 1)
		&"luk": return level_1_luk + luk_per_level * (level - 1)
	return 0.0


func apply_to_combatant(combatant: CombatantComponent, level: int) -> void:
	var attrs := combatant.attributes
	attrs.set_base(AttributeIds.STR, get_primary_at_level(&"str", level))
	attrs.set_base(AttributeIds.AGI, get_primary_at_level(&"agi", level))
	attrs.set_base(AttributeIds.INT, get_primary_at_level(&"int", level))
	attrs.set_base(AttributeIds.CON, get_primary_at_level(&"con", level))
	attrs.set_base(AttributeIds.LUK, get_primary_at_level(&"luk", level))
	attrs.set_base(AttributeIds.CHARACTER_LEVEL, float(level))
	attrs.set_base(AttributeIds.MOVE_SPEED, move_speed)

	# 刷新 HP/MP 为满值（派生属性已自动重算）
	combatant.current_hp = combatant.get_max_hp()
	combatant.current_mp = combatant.get_max_mp()
```

### 2.4 文件组织

```
resources/monsters/
  profiles/
    forest_monster_profile.tres       # 森林怪物
    archer_monster_profile.tres       # 弓箭怪物
    warrior_monster_profile.tres      # 战士怪物（未来）
    rogue_monster_profile.tres        # 刺客怪物（未来）
    ...
```

### 2.5 与玩家属性对标

参考玩家 "自由点均分" 构建（见 `../narrative/角色属性v3.md`，旧《等级属性系统设计》已删除）：

| 等级 | 玩家固定基础 | 均分自由点 | 单属性总合 |
|------|-------------|-----------|-----------|
| 1 | 10 | 0 | 10 |
| 10 | 19 | 18 | 37 |
| 20 | 29 | 30 | 59 |
| 30 | 39 | 42 | 81 |

设计怪物 profile 时，普通怪的 `level_1_XXX` 应略低于玩家 Lv1（如 8），`XXX_per_level` 应接近玩家固定成长 + 均分成长（约 1.0~1.5），这样同等级普通怪属性约为玩家的 70%~85%。

## 3. EnemyBase 集成

### 3.1 属性初始化入口

在 `EnemyBase`（或子类 `_ready()`）中调用：

```gdscript
## 由 spawner 在生成后调用，或子类在 _ready 中自行调用
func init_stats(profile: MonsterStatProfile, level: int) -> void:
	if combatant:
		profile.apply_to_combatant(combatant, level)
```

如果怪物场景自带默认 profile 和默认等级，可在子类 `_ready()` 中直接写：

```gdscript
# ForestMonster._ready()
func _ready() -> void:
	super._ready()
	if combatant and combatant.attributes:
		var default_profile := load("res://resources/monsters/profiles/forest_monster_profile.tres")
		init_stats(default_profile, 5)  # 编辑器单独测试时的默认等级
```

生成器会覆盖这个默认值。

## 4. MonsterSpawner 集成

### 4.1 MonsterSpawnRule 新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `spawn_level` | int | 该批次怪物的等级 |
| `level_variance` | int | 等级随机浮动 ±N（可选，默认 0） |

### 4.2 生成流程

```
MonsterSpawner.generate(enemy_scene, level)
  ├── instance = enemy_scene.instantiate()
  ├── if instance.has_method("init_stats"):
  │       profile = instance.get_default_profile()  # 或从 spawn_entry 取覆盖
  │       actual_level = level + randi_range(-variance, +variance)
  │       instance.init_stats(profile, actual_level)
  ├── add_child(instance)
  └── 放置位置...
```

## 5. 使用示例

### 场景 A：新手森林（Lv3~5 森林怪）

```gdscript
# MonsterSpawnRule.tres
spawn_entries = [森林怪物场景]
spawn_level = 4
level_variance = 1   # 实际等级 3~5
```

### 场景 B：后期深渊（Lv22~28 同种森林怪）

```gdscript
spawn_entries = [森林怪物场景]  # 同一份 .tscn
spawn_level = 25
level_variance = 3   # 实际等级 22~28
```

无需创建新场景，只改两个数字。

## 6. 扩展点

### 6.1 稀有度覆盖

配合《怪物系统设计》中的稀有度倍率（普通 0.6x、精英 1.2x、Boss 2.5x），在 `apply_to_combatant` 之后叠加一个 StatModifier 即可：

```gdscript
func apply_rarity(combatant: CombatantComponent, rarity_mult: float) -> void:
    for stat in [&"str", &"agi", &"int", &"con", &"luk"]:
        var val := combatant.attributes.get_base(stat)
        combatant.attributes.set_base(stat, val * rarity_mult)
```

### 6.2 词缀 Modifier

配合词缀系统（火焰附魔、吸血等），在 `init_stats` 之后通过 `attributes.add_modifier()` 注入，与装备/buff 走同一套 modifier 管道。

### 6.3 区域等级曲线

如果希望区域等级不是手动指定而是自动计算（如"越远离城镇等级越高"），可在 spawner 中添加一个 `level_curve: Curve` 资源，按距离采样等级。
