# 武器系统设计文档

> 设计目标：**可组合、可扩展、与角色解耦**。融合《暖雪》的流派爆发力与《Brotato》的词条多样性。

## 一、设计原则

1. **武器与角色松耦合** —— `WeaponBase` 通过可选的 `wielder_combatant` 接入角色属性（装备时由 Player 注入），未注入时退化为纯 base_damage
2. **数据驱动** —— 武器数值全部存在 `WeaponData`（Resource），编辑器中创建 `.tres` 即可配置新武器，无需改代码
3. **行为可替换** —— 攻击方式是独立的子节点（Strategy 模式），运行时 `remove_child / add_child` 即可热换
4. **三层职责分离**：
   - `WeaponData` —— 是什么（数值/类型）
   - `WeaponBase` —— 能做什么（冷却、信号）
   - `AttackBehaviorBase` —— 怎么打（命中检测逻辑）

---

## 二、架构总览

```
WeaponData (Resource)           ← 纯数据，编辑器配置
        ↓ @export
WeaponBase (Node2D)             ← 武器实体，管理冷却与信号
        └── AttackBehaviorBase (Node2D)   ← 攻击行为接口
                ├── MeleeAttackBehaviorBase     ← 近战公共基类（Area2D）
                │       ├── SlashBehavior       ← 剑：宽矩形挥砍
                │       └── ThrustBehavior      ← 枪：窄矩形突刺
                └── ProjectileBehavior          ← 弓：生成弹丸实例
                        └── ProjectileBase (CharacterBody2D)  ← 飞行弹丸
```

### 信号流向

```
角色/AI 调用 weapon.try_attack(direction)
        ↓
AttackBehaviorBase.execute()
        ↓ 检测到命中
hit_detected(hit_info)
        ↓ WeaponBase 转发
weapon_hit(hit_info)            ← 外部伤害系统在这里订阅
```

## 四、核心类说明

### 4.1 WeaponData（Resource）

武器的所有数值配置，在编辑器中右键 → `New WeaponData` 创建 `.tres` 文件。

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `weapon_id` | String | 唯一标识（如 `"iron_sword"`） |
| `display_name` | String | 显示名称 |
| `weapon_type` | WeaponType | SWORD / SPEAR / BOW |
| `base_damage` | float | 武器基础伤害（叠加到攻击力上） |
| `attack_cooldown` | float | 两次攻击的冷却时间（秒） |
| `attack_duration` | float | 近战命中框激活时长（秒） |
| `attack_range` | float | 攻击范围（像素） |
| `attack_angle` | float | 挥砍弧度宽（度，仅 SlashBehavior 使用） |
| `projectile_speed` | float | 弹丸飞行速度（像素/秒，仅弓使用） |

### 4.2 WeaponBase（Node2D）

武器的"骨架"节点，挂载到场景后通过 `@export var weapon_data` 绑定数据。

**核心接口：**

```gdscript
# 发动攻击。冷却中或正在攻击时返回 false。
func try_attack(direction: Vector2) -> bool

# 命中任何目标时发出（伤害系统在此订阅）
signal weapon_hit(hit_info: WeaponHitInfo)

# 状态查询
func is_on_cooldown() -> bool
func is_attacking() -> bool
```

### 4.3 AttackBehaviorBase（Node2D）

攻击行为的抽象接口。作为 `WeaponBase` 的子节点存在，`WeaponBase` 会自动查找第一个继承它的子节点。

```gdscript
# 子类必须重写，实现具体的命中检测逻辑
func execute(data: WeaponData, direction: Vector2) -> void

signal hit_detected(hit_info: WeaponHitInfo)  # 检测到命中时发出
signal attack_finished                          # 攻击动作结束时发出
```

### 4.4 MeleeAttackBehaviorBase（Node2D）

近战攻击的公共基类，封装命中框管理、物理查询、防重复命中逻辑。

**场景结构约定（子类场景必须遵守）：**

```
MeleeAttackBehaviorBase
└── HitArea (Area2D)   collision_layer=0  collision_mask=2
    └── HitShape (CollisionShape2D)        ← shape 不要设 disabled
```

**碰撞层要点：**
- `HitArea.collision_layer = 0`：不被任何体/区域检测到
- `HitArea.collision_mask = 2`：只查询第 2 层（敌人/假人），不误伤玩家或地形

> 碰撞层总表以 `./战斗与属性统一体系.md` §玩家碰撞与分层 为准：**玩家 CharacterBody2D 的 `collision_layer = 8`（`Player Body`）**，地形为 `1`，敌人/假人为 `2`，投射物为 `4`。本文 §8.4 表格的「默认 1」是 Godot 节点的默认值提示，**实际 Player 场景里已改为 8**。

**命中检测机制 — `_query_hits()`：**

近战命中**不依赖** `Area2D.body_entered` 信号，而是在 `_physics_process` 里每帧主动调用 `_query_hits()`：

```gdscript
func _query_hits() -> void:
    var q := PhysicsShapeQueryParameters2D.new()
    q.shape     = _hit_shape.shape
    q.transform = _hit_area.global_transform   # hitbox 当前世界变换
    q.collision_mask = _hit_area.collision_mask
    for result in get_world_2d().direct_space_state.intersect_shape(q, 8):
        if result.collider is Node:
            _on_body_entered(result.collider as Node)
```

> **为什么不用 body_entered 信号？**
> Godot 4 的 `body_entered` 设计为"物体移入静止 Area2D"时触发。当我们用 Tween 脚本移动 Area2D（非物理驱动）时，对 `StaticBody2D` 等静止物体，信号不可靠或根本不触发。`intersect_shape` 是直接对物理空间的快照查询，在 `_physics_process` 中每帧结果准确。

**防重复命中 — `_hit_nodes`：**

```gdscript
func _on_body_entered(body: Node) -> void:
    if body in _hit_nodes:   # 本次攻击已命中过，跳过
        return
    _hit_nodes.append(body)
    hit_detected.emit(...)
    if body.has_method("on_hit"):
        # 通过 WeaponBase.compute_hit_damage 计算出手伤害（含 STR/暴击/全伤害加成）
        var weapon := get_parent() as WeaponBase
        if weapon:
            var result := weapon.compute_hit_damage(base_damage, mult)
            body.on_hit(result["damage"])
        else:
            body.on_hit(base_damage * mult)
```

- 同一次攻击中同一个目标只触发一次伤害
- 攻击结束（`_end_attack`）时清空 `_hit_nodes`，下次攻击重新计算

#### 剑 — SlashBehavior

命中框为**细矩形（刀刃形）**，用 Tween 驱动旋转，贴合剑身挥砍轨迹。

| 参数 | 默认值 | 说明 |
|:---|:---:|:---|
| `width_ratio` | 0.8 | 决定扫角：半角 = `atan(0.8)` ≈ 39° |
| `hitbox_width` | 8px | 矩形短边（对应刀刃宽度） |
| `swing_duration` | 0.15s | 旋转动画时长，需与 SwordVisual 对齐 |

**execute() 流程：**
1. 设置矩形尺寸 `attack_range × hitbox_width`，放置到起始角度
2. 开启 `monitoring = true`，同时启动旋转 Tween
3. Tween 将命中框从 `direction - 39°` 扫到 `direction + 39°`（0.15s）
4. Tween 结束后关闭 monitoring，等待 `attack_duration - swing_duration` 后发出 `attack_finished`
5. `_physics_process` 在 monitoring 期间每帧调用 `_query_hits()`

```
   起始角 ──────────► 终止角
     \   [—刀刃—]   /
      \             /
       ● 玩家位置
```

#### 枪 — ThrustBehavior

命中框为**细长矩形（矛身形）**，覆盖矛头到矛尖完整长度，随视觉突刺动画平移。

| 参数 | 默认值 | 说明 |
|:---|:---:|:---|
| `width_ratio` | 0.2 | 矩形短边 = `attack_range × 0.2` |
| `tip_length` | 14px | 矛尖额外长度，与 `SpearVisual._TIP_LEN` 对齐 |
| `lunge_distance` | 30px | 突刺位移，需与 `SpearVisual` 的 lunge 对齐 |

**execute() 流程：**
1. 设置矩形尺寸 `(attack_range + tip_length) × width`，对齐攻击方向
2. 中心放置于 `direction × (total_length / 2)`（矛的视觉起点）
3. 开启 monitoring，启动突刺 Tween：
   - 0 → 70% 时长：中心向前平移 30px（EASE_OUT）
   - 70% → 100% 时长：弹回原位（EASE_IN）
4. Tween 结束后关闭 monitoring，发出 `attack_finished`
5. `_physics_process` 在 monitoring 期间每帧调用 `_query_hits()`

```
玩家 ──►  [——————矛身——————][矛尖]  →  [突刺 +30px]
           ↑ attack_range          ↑ tip_length
```

### 4.5 ProjectileBehavior（Node2D）

远程攻击行为。调用 `execute()` 后立即实例化弹丸、设置位置和速度，攻击动作随即结束（冷却控制射速）。

**@export 字段：**
- `projectile_scene: PackedScene` — 要生成的弹丸场景（bow.tscn 中已预绑定 arrow.tscn）
- `spawn_offset: float` — 生成位置沿攻击方向的偏移（像素）

### 4.6 ProjectileBase（CharacterBody2D）

弹丸基类，使用 `move_and_collide` 实现直线飞行（可碰墙壁 StaticBody2D）。

| 字段/方法 | 说明 |
|:---|:---|
| `max_range` | 最大飞行距离，超出后自动销毁 |
| `launch(data, direction)` | 由 ProjectileBehavior 调用，设置速度和旋转 |
| `_on_collide(collider)` | 子类重写此方法添加命中特效/AOE |
| `signal projectile_hit` | 命中时发出，携带 WeaponHitInfo |

**命中判定流程：**

```gdscript
func _physics_process(delta):
    var collision := move_and_collide(velocity * delta)
    if collision:
        _on_collide(collision.get_collider())

func _on_collide(collider):
    _has_hit = true
    if collider.has_method("on_hit"):
        collider.on_hit(_weapon_data.base_damage)   # 直接调用目标受击
    projectile_hit.emit(WeaponHitInfo.new(...))      # 通知武器系统
    queue_free()
```

- `_has_hit` 标志确保同一弹丸只命中一次（`move_and_collide` 每帧返回第一个碰撞）
- 弹丸添加到场景根节点（`get_tree().current_scene`），生命周期与武器节点无关

## 五、伤害判定完整流程

### 5.1 近战（剑 / 枪）

```
玩家鼠标左键
    ↓
Player._unhandled_input() → _try_weapon_attack()
    ↓
WeaponBase.try_attack(direction)
    ├─ 检查：不在攻击中 AND 不在冷却
    ├─ 设 _is_attacking = true，启动冷却计时
    ├─ AttackBehaviorBase.execute(data, direction)
    │       ├─ 设置 HitArea 形状尺寸和初始位置
    │       ├─ 开启 _hit_area.monitoring = true
    │       └─ 启动 Tween（剑：旋转扫角 / 枪：平移突刺）
    └─ WeaponVisual.play_attack(direction)（播放视觉动画）

每物理帧（_physics_process）：
    SlashBehavior / ThrustBehavior._physics_process()
        └─ monitoring 为 true 时调用 _query_hits()
                └─ intersect_shape() 查询物理空间
                        └─ 有结果 → _on_body_entered(body)
                                ├─ 检查 _hit_nodes 防重复
                                ├─ body.on_hit(damage)          → [假人] 受到伤害日志
                                └─ hit_detected.emit(hit_info)
                                        ↓ WeaponBase 转发
                                   weapon_hit(hit_info)          → [武器调试] 命中日志

Tween 结束：
    monitoring = false → _end_attack() → _hit_nodes.clear()
    attack_finished.emit() → WeaponBase._on_attack_finished() → _is_attacking = false
```

### 5.2 远程（弓箭）

```
玩家鼠标左键
    ↓
WeaponBase.try_attack(direction)
    ├─ ProjectileBehavior.execute(data, direction)
    │       ├─ 实例化 arrow.tscn（CharacterBody2D）
    │       ├─ 连接 projectile_hit → hit_detected
    │       ├─ 添加到场景根（独立生命周期）
    │       ├─ 设置 global_position 和 velocity
    │       └─ 立即 attack_finished.emit()（冷却控制射速）
    └─ WeaponVisual.play_attack(direction)

弹丸每物理帧（Arrow._physics_process）：
    move_and_collide(velocity * delta)
        └─ 碰撞 → _on_collide(collider)
                ├─ collider.on_hit(damage)              → [假人] 受到伤害日志
                ├─ projectile_hit.emit(hit_info)
                │       ↓ ProjectileBehavior 转发
                │  hit_detected.emit(hit_info)
                │       ↓ WeaponBase 转发
                │  weapon_hit(hit_info)                  → [武器调试] 命中日志
                └─ queue_free()
```

### 5.3 两种机制对比

| 维度 | 近战（Area2D + 物理查询） | 远程（move_and_collide） |
|:---|:---|:---|
| 检测方式 | `intersect_shape()` 每帧主动查询 | `move_and_collide()` 物理驱动碰撞 |
| 命中时机 | hitbox 覆盖目标的任意物理帧 | 弹丸物理步进首次碰撞 |
| 为什么不用 body_entered | 脚本移动 Area2D 时信号对静止体不可靠 | 不适用（弹丸自己是物理体） |
| 防重复 | `_hit_nodes` 数组，攻击结束清空 | `_has_hit` 标志，弹丸销毁时失效 |
| on_hit 调用位置 | `_on_body_entered()` | `_on_collide()` |

### 4.7 WeaponHitInfo（RefCounted）

命中事件的信息载体，通过 `weapon_hit` 信号传递。

| 字段 | 类型 | 说明 |
|:---|:---|:---|
| `weapon_data` | WeaponData | 武器数据快照（含 base_damage） |
| `hit_position` | Vector2 | 命中世界坐标 |
| `hit_target` | Node | 被命中节点（可能为 null） |
| `attack_direction` | Vector2 | 归一化攻击方向 |

## 七、使用示例

### 实例化并使用武器

```gdscript
# 实例化（与角色解耦，可独立测试）
var sword = preload("res://scenes/weapons/sword.tscn").instantiate()
sword.weapon_data = preload("res://data/weapons/iron_sword.tres")
add_child(sword)

# 订阅命中事件（伤害结算在此处理）
sword.weapon_hit.connect(func(info: WeaponHitInfo) -> void:
    var damage = info.weapon_data.base_damage
    print("命中 %s，基础伤害 %d" % [info.hit_target.name, damage])
)

# 发动攻击（朝右）
sword.try_attack(Vector2.RIGHT)
```

### 创建 WeaponData（编辑器操作）

1. 在 `res://data/weapons/` 目录右键 → `New Resource`
2. 选择 `WeaponData`，保存为 `iron_sword.tres`
3. 在 Inspector 填写各字段，拖拽赋值到武器场景的 `weapon_data` 属性

## 八、扩展指南

### 新增武器种类（如斧头）

1. 创建 `WeaponData` Resource `axe.tres`，设置 `weapon_type = SWORD`（或添加新枚举值）
2. 使用 `SlashBehavior`，将 `attack_angle` 调大，`attack_duration` 调长
3. 实例化 sword.tscn，运行时替换 `weapon_data` 即可，无需新场景

### 新增攻击方式（如旋风斩 360°）

```gdscript
# scripts/weapons/behaviors/spin_behavior.gd
class_name SpinBehavior
extends AttackBehaviorBase

func execute(data: WeaponData, _direction: Vector2) -> void:
    # 创建全圆 Area2D 或手动检测周围所有体
    # 完成后调用 attack_finished.emit()
    pass
```

### 新增投射物（如爆炸火球）

```gdscript
# scripts/weapons/projectile/fireball.gd
class_name Fireball
extends ProjectileBase

func _on_collide(collider: Object) -> void:
    # 触发 AOE 爆炸，命中附近所有敌人
    super(collider)   # 发出 projectile_hit 信号并 queue_free
```

## 九、Player 集成（武器装备与鼠标攻击）

### 8.1 Player 新增接口

```gdscript
# 信号：装备的武器命中目标时发出（从 WeaponBase.weapon_hit 转发）
signal weapon_hit(hit_info: WeaponHitInfo)

# 装备武器。weapon_scene 为对应 .tscn；data 可选，不传则用场景内默认值。
func equip_weapon(weapon_scene: PackedScene, data: WeaponData = null) -> void

# 鼠标左键单击自动触发（_unhandled_input），朝鼠标方向攻击
func _try_weapon_attack() -> void
```

- 装备时自动卸下旧武器（`queue_free`）并将新武器添加为 Player 子节点

- 头顶显示累计伤害数值

**碰撞层设置**

| 节点 | collision_layer | collision_mask |
|:---|:---:|:---:|
| Player（CharacterBody2D） | **8** | 1 |
| Player Hurtbox（Area2D） | **16** | — |
| 地板 / 墙体（StaticBody2D） | **1** | 1 |
| 武器 HitArea（Area2D） | 0 | **2** |
| 弓箭（CharacterBody2D） | **4** | **2** |
| TestDummy / 敌人（StaticBody2D / CharacterBody2D） | **2** | 1 |

HitArea / 箭矢只检测第 2 层，不会误命中地板或玩家自身。玩家冲刺撞敌详见 `./玩家冲刺与撞敌.md`。

## 十、武器视觉系统

### 9.1 架构

```
WeaponVisualBase (Node2D)         ← 皮肤系统 + 鼠标跟踪旋转
    ├── SwordVisual               ← 剑外观 + 旋转挥砍动画
    ├── SpearVisual               ← 枪外观 + 突刺位移动画
    └── BowVisual                 ← 弓外观 + 拉弦动画
```

每种武器场景（sword/spear/bow.tscn）各含一个对应的 Visual 子节点。

### 9.2 WeaponVisualBase

**@export 字段：**
- `skin_texture: Texture2D` — 皮肤贴图（设置后用 Sprite2D 渲染；设为 null 回退到程序化绘制）
- `hold_offset: Vector2` — 持握点相对角色中心的偏移（默认 `Vector2(8, 0)`）

**行为：**
- 每帧自动朝向鼠标（`_process`，攻击动画期间暂停）
- `play_attack(direction)` 由 WeaponBase 在攻击成功时调用，触发子类动画

### 9.3 换皮肤

```gdscript
# 运行时换皮肤（有贴图时用 Sprite2D，无贴图时自动回退代码绘制）
$Sword/SwordVisual.skin_texture = preload("res://assets/weapons/sword_fire.png")

# 取消皮肤，恢复代码绘制
$Sword/SwordVisual.skin_texture = null
```

### 9.4 动画效果

| 武器 | 动画 | 时长 |
|:---|:---|:---|
| 剑（横劈） | 旋转 `−atan(0.8)` → `+atan(0.8)`（约 ±39°，EASE_OUT），半角与 `SlashBehavior.width_ratio` 保持一致 | 0.15s |
| 剑（竖劈） | 以 `direction + 90°` 为中轴，`±atan(0.6)`（约 ±31°）扫弧（EASE_OUT） | 0.18s |
| 剑（旋转斩） | 旋转 `spin_turns`（默认 1）圈（EASE_IN_OUT） | `spin_duration` 秒（默认 0.4s） |
| 长枪 | `position` 冲出 `direction * 30px` → 弹回到 `hold_offset` | `attack_duration * 0.7` + `attack_duration * 0.3`（默认总 0.2s） |
| 弓 | `draw_amount` 0→1→0（弓弦拉紧/释放） | 0.10s + 0.15s |

> 注：`SpearVisual._TIP_LEN = 14px` 是矛**三角头部的长度**（只影响绘制），与突刺位移无关；实际突刺位移固定 30px。

### 9.5 箭矢外观

`ProjectileBase._draw()` 在每个弹丸上绘制：
- 轴杆（褐色）+ 箭头（钢蓝色）+ 尾羽（红色）
- 朝向由 `launch()` 中的 `rotation = direction.angle()` 决定

## 十二、v2.0 新增功能说明

### 12.1 武器作为物品（WeaponData 继承 ItemData）

`WeaponData` 现在继承自 `ItemData`，武器是物品的子类型：

```gdscript
class_name WeaponData
extends ItemData
```

- 原 `weapon_id` 字段 → 使用父类 `id`
- 原 `display_name` 字段 → 使用父类 `item_name`
- `item_type` 应设为 `ItemData.ItemType.WEAPON`
- `max_stack` 应设为 `1`（武器不叠加）
- 武器可以直接放入背包 `Inventory`，无需额外转换

**迁移提示：** 创建 `WeaponData.tres` 时，填写 `id`（原 `weapon_id`）和 `item_name`（原 `display_name`）。

---

### 12.2 武器属性词条系统

`WeaponData` 新增 7 个属性词条字段，装备武器时自动注入角色属性系统：

| 字段 | 类型 | 注入属性 | 说明 |
|:---|:---|:---|:---|
| `bonus_attack_power` | float | `ATTACK_POWER_PHYS`（FLAT） | 物理攻击力加成 |
| `bonus_crit_rate` | float | `CRIT_RATE`（PERCENT_ADD） | 暴击率加成（小数，0.05=5%） |
| `bonus_crit_damage` | float | `CRIT_DAMAGE`（PERCENT_ADD） | 暴击伤害加成（小数，0.2=20%） |
| `bonus_attack_speed` | float | `ATTACK_SPEED`（PERCENT_ADD） | 攻击速度倍率加成 |
| `bonus_attack_range` | float | `ATTACK_RANGE`（FLAT） | 攻击范围词条加成 |
| `bonus_penetration` | float | `PENETRATION`（FLAT） | 物理穿透加成 |
| `bonus_damage_all` | float | `DAMAGE_BONUS_ALL`（PERCENT_MULT） | 全伤害独立乘算加成 |

**使用示例：**

```gdscript
var sword := WeaponData.new()
sword.id = "fire_sword"
sword.item_name = "火焰剑"
sword.base_damage = 25.0
sword.bonus_attack_power = 10.0   # +10 物理攻击力
sword.bonus_crit_rate = 0.08      # +8% 暴击率
sword.bonus_crit_damage = 0.30    # +30% 暴击伤害

# 查看会生成哪些 modifier（无需手动调用，equip_weapon 自动处理）
var mods := sword.build_modifiers()
```

**Modifier source_tag 格式：** `"weapon:<id>"`，例如 `"weapon:fire_sword"`。卸下武器时按此 tag 批量清除。

### 12.3 AttackPattern 攻击方式配置

`AttackPattern`（`scripts/core/weapons/attack_pattern.gd`）是一个 Resource，描述一次攻击的"怎么打"：

```
AttackPattern (Resource)
├── behavior_type: BehaviorType  ← 决定底层行为（横劈/竖劈/旋转/突刺/弹丸）
├── damage_multiplier: float     ← 伤害倍率（默认 1.0）
├── override_duration / override_range   ← 覆盖武器默认参数
└── 各行为专属参数（width_ratio, spin_turns, lunge_distance…）
```

#### BehaviorType 枚举

| 值 | 说明 | 对应行为脚本 |
|:---|:---|:---|
| `HORIZONTAL_SLASH` | 横劈（以攻击方向为中心水平扫弧） | `slash_behavior.gd` |
| `VERTICAL_SLASH` | 竖劈（以攻击方向垂直上下扫弧） | `vertical_slash_behavior.gd` |
| `SPIN_SLASH` | 旋转斩（360° 全圆旋转） | `spin_behavior.gd` |
| `THRUST` | 突刺（直线刺出并弹回） | `thrust_behavior.gd` |
| `PROJECTILE` | 发射弹丸 | `projectile_behavior.gd` |
| `CUSTOM` | 自定义（由场景内置行为处理） | 场景中第一个 AttackBehaviorBase 子节点 |

#### 在 WeaponData 中配置攻击方式

```gdscript
# 武器数据中直接配置普攻方式
@export var primary_pattern: AttackPattern = null
@export var combo_patterns: Array[AttackPattern] = []
```

**配置示例（编辑器中创建 .tres）：**

```
horizontal_slash.tres
├── behavior_type = HORIZONTAL_SLASH
├── damage_multiplier = 1.0
└── width_ratio = 0.8

vertical_slash.tres
├── behavior_type = VERTICAL_SLASH
├── damage_multiplier = 1.2       ← 竖劈伤害更高
└── width_ratio = 0.5

spin_slash.tres
├── behavior_type = SPIN_SLASH
├── damage_multiplier = 0.8       ← 旋转斩AOE伤害略低
├── spin_turns = 1.0
└── spin_duration = 0.4
```

#### 连击链配置

```gdscript
# 3段连击：横劈 → 竖劈 → 旋转斩
sword.combo_patterns = [horizontal_slash_pattern, vertical_slash_pattern, spin_pattern]
```

连击超过 `_COMBO_RESET_TIME`（1.5秒）无攻击会自动重置到第一段。

### 12.4 新增攻击行为

#### VerticalSlashBehavior（竖劈）

文件：`scripts/weapons/behaviors/vertical_slash_behavior.gd`

- 命中框以攻击方向旋转 **+90°** 为起点，自上而下垂直扫弧
- 与横劈共用相同参数结构，但弧度偏移 90°
- 调试可视化：蓝紫色矩形
- 适合：重斩、下劈等动作

#### SpinBehavior（旋转斩）

文件：`scripts/weapons/behaviors/spin_behavior.gd`

- 命中框从当前朝向出发旋转 360°（`spin_turns` 圈）
- 全方位 AOE，不依赖攻击方向（但仍接受 direction 参数作为起始角）
- `spin_turns = 1.0` 为完整旋转，可设 `0.5` 等分数圈
- 调试可视化：青绿色矩形
- 适合：旋风斩、陀螺式冲锋

```gdscript
# 添加旋转斩行为到剑场景（编辑器操作）
Sword (WeaponBase)
├── SlashBehavior          ← HORIZONTAL_SLASH 时使用
├── VerticalSlashBehavior  ← VERTICAL_SLASH 时使用
├── SpinBehavior           ← SPIN_SLASH 时使用（需有 HitArea/HitShape 子节点）
└── SwordVisual
```

### 12.5 武器与角色属性解耦接口

#### WeaponBase 开放接口

```gdscript
# 获取武器的所有 StatModifier（供装备系统调用）
func get_weapon_modifiers() -> Array[StatModifier]

# 获取当前连击段数（0-based，供 UI/动画查询）
func get_combo_index() -> int
```

#### Player 接口扩展

```gdscript
# 赋值角色属性（null = 不注入 modifier，保持解耦）
var character_attributes: CharacterAttributes = null

# equip_weapon() 内部自动处理 modifier 注入/移除
func equip_weapon(weapon_scene: PackedScene, data: WeaponData = null) -> void
```

**使用方式：**

```gdscript
# 外部系统（如角色管理器）赋值属性
player.character_attributes = CharacterAttributes.new()
player.character_attributes.set_base(AttributeIds.STR, 10.0)
player.character_attributes.set_base(AttributeIds.AGI, 8.0)

# 装备武器时自动注入武器词条 modifier
player.equip_weapon(preload("res://scenes/weapons/sword.tscn"), sword_data)
# 卸下旧武器时自动按 source_tag "weapon:xxx" 批量清除 modifier

# 若 character_attributes 为 null，equip_weapon 仍正常工作（只是不注入属性）
```

**解耦保证：** Player 不 `import` 也不硬依赖 `CharacterAttributes`；`character_attributes` 为 null 时所有属性相关操作静默跳过，武器功能不受影响。

### 12.6 execute_with_pattern 扩展接口

所有 `AttackBehaviorBase` 子类现在都可选实现 `execute_with_pattern()`：

```gdscript
## 默认实现（基类）：忽略 pattern，直接调用 execute()
func execute_with_pattern(data: WeaponData, direction: Vector2, pattern: AttackPattern) -> void:
    execute(data, direction)

## 子类重写示例（SlashBehavior）：
func execute_with_pattern(data: WeaponData, direction: Vector2, pattern: AttackPattern) -> void:
    var wr = pattern.width_ratio if pattern.width_ratio > 0.0 else width_ratio
    # ... 使用 pattern 参数
```

这让同一个场景内的 `SlashBehavior` 节点可以被多个不同的 `AttackPattern`（横劈/连击1/连击2）共用，只需在 pattern 里配置不同参数，无需创建多个行为节点。
