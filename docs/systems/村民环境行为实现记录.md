# 村民环境行为实现记录

> 首版落地：窑村 `yaocun_v1_map.tscn` + 6 个预设角色。

## 要解决什么

让非战斗村民在固定范围内**静止或走动**，行为可数据配置；视觉复用预设角色场景。

## 架构

```
CharacterBody2D（预设角色 .tscn）
├── AnimatedSprite2D          ← idle / walk_*
├── CollisionShape2D
└── NpcAmbientBehavior        ← 读 NpcBehaviorConfig，写 velocity + 切动画
```

| 文件 | 职责 |
|------|------|
| `scripts/npc/npc_behavior_config.gd` | Resource：`IDLE` / `WANDER` / `PATROL` + 速度、半径、停顿、路径 |
| `scripts/components/npc_ambient_behavior.gd` | 组件：按配置驱动父 `CharacterBody2D` |
| `resources/npc/behaviors/*.tres` | 各角色默认配置 |

**不**挂 `preset_character_controller`（键盘预览用）；**不**走敌人 `PatrolComponent` + 追逐栈。

## 模式

| Mode | 行为 |
|------|------|
| `IDLE` | 原地静止，播 idle |
| `WANDER` | 在出生点 `wander_radius` 内随机取点 → 走向 → 停顿 |
| `PATROL` | 沿 `patrol_offsets`（相对出生点）ping-pong |

被墙/建筑挡住时：位移明显小于预期会累计卡住时间，约 `stuck_give_up_time`（默认 0.4s）后停步并换目标，避免对着障碍一直播 walk。

无 `config` 时组件内建默认：`WANDER`，半径 80，速度 40。

## 窑村布点（v1 建筑附近）

| 角色 | 配置 | 世界坐标 |
|------|------|----------|
| 周伯 | `zhoubo_idle.tres` | `(68, -320)` 周伯屋前 |
| 哑姑 | `yagu_idle.tres` | `(820, 180)` 绣坊东侧空地（避开双生家屋顶） |
| 辫哥 | `biange_wander.tres` | `(670, 380)` 双生家 |
| 髻弟 | `jidi_wander.tres` | `(730, 380)` 双生家 |
| 三娃 | `sanwa_wander.tres` | `(560, 90)` 窑坊 |
| 石锁 | `shisuo_wander.tres` | `(640, 90)` 窑坊 |

场景节点：`Entities/NPCs/*`；运行时由 `yaocun_v1_map.gd` 展平到 `Entities` 以参与 y_sort。

预设角色与玩家场景统一烘焙 `PresetCharacterGenerator.DEFAULT_WORLD_SCALE = 0.4`（128×256 → 约 102px 高）。`player.tscn` 已直接使用 mainplayer 精灵表，不再依赖运行时换装才显示正确形象；`collision_layer = 8`。

## 如何换行为

1. 改对应 `.tres`，或
2. 在地图实例上覆盖 `NpcAmbientBehavior.config`

新增村民：复用预设场景 → 挂 `NpcAmbientBehavior` → 指定/新建 `.tres` → 放进 `Entities/NPCs`。
