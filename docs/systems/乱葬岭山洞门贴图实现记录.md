## 一、做了什么

原贴图石门框内是**红棕砖封死**，不能读作「可进山洞」。在**同一张 RGBA 贴图**上，用程序绘制的暗色木门替换砖墙区域，环境树、根、石阶与透明底不变。

**说明**：这是**美术贴图层**改动，不是 `MapBuilding` / `SceneDoorTrigger` 进门逻辑。进门切场景仍按窑村建筑门体系另配。

## 三、门洞定位

俯视角等距贴图中，真正的门洞在石框**偏右**（左半多为树根阴影，勿当成砖墙）。

门洞矩形（原图像素，含两端）：

| | 值 |
|--|--|
| 左 `L` | 835 |
| 上 `T` | 352 |
| 右 `R` | 906 |
| 下 `B` | 480 |
| 约宽×高 | 72×129 |

校准依据：

1. 在 y≈380～440 扫描**中性灰石柱**簇，左簇约 x∈[813,830]，右簇约 x∈[909,937]，开洞取柱内侧。
2. 暖棕「砖」像素集中在 x≈839～901，与柱内侧开洞重合。
3. `T` 压在石楣下沿之下，`B` 停在最上阶之上，避免盖住楣/台阶。

## 四、绘制与合成

### 门样式（对齐同目录 `石祠小庙.png` 的木门语汇）

- 4 竖木板 + 板缝深线 + 弱木纹
- 两道横档 + 铆钉
- 右侧铁环把手；左侧合页块
- 左上略亮、右下略暗；顶缘加楣投影
- 整体降亮度/饱和，贴近乱葬岭阴冷色

### 合成规则

1. 从备份图复制全图。
2. 仅在门洞矩形内写入木门像素。
3. **不覆盖**：很暗前景根须、绿叶、灰石框像素。
4. 遮罩边缘约 2px 羽化，顶缝再压暗，贴合石楣。

### 未采用方案（踩坑）

| 方案 | 问题 |
|------|------|
| 整图 AI 重绘再缩放 | 尺寸/比例变了，白底丢 Alpha，拉伸糊掉原画 |
| 用「暖色砖」全图搜 mask | 易把树根、右侧亮面石误收进 mask；或把门贴到开洞**左侧**根影区 |
| 从 AI 裁门再贴 | 扩张裁剪常带进深色树影，门面呈破洞/有机条 |

最终以**坐标锁定门洞 + 程序绘门 + 条件合成**为准。

## 五、回滚与重做

```text
# 回滚到无门
复制 乱葬岭左1山洞_无门备份.png → 乱葬岭左1山洞.png
```

重做时：以备份为底，改 `L/T/R/B` 或绘门参数后再合成。需更强笔触感时，可只重绘门洞局部，仍按第三节矩形对齐，勿整图替换。

## 六、场景进门（已落地）

与石祠小庙等乱葬岭建筑同一套链路：

| 项 | 值 |
|----|-----|
| 室外建筑 | `yaocun_v1_map.tscn` → `Entities/乱葬岭/乱葬岭左1山洞` |
| 室外门 | 子节点 `HouseDoor`（`MapBuildingDoor`） |
| `target_scene` | `res://scenes/chapter1/burial_left_cave_room.tscn` |
| `spawn_id`（进门） | `world_to_room` |
| `door_link_id` | `burial_left_cave_door` |
| 出室落点 | `HouseDoor/ExitSpawn` → `burial_left_cave_room_exit`（门南侧 `(0, 36)`） |
| 室内脚本 | `burial_building_room.gd`（与其它乱葬岭室内共用） |
| 室内出门 | `Doors/ExitToWorld` → `yaocun_v1_map.tscn`，`cross_mode = EXIT_TO_SOUTH` |

门槛位置按贴图木门底缘估算（Sprite 居中）：建筑局部约 `(120.5, 115)`；`trigger_size ≈ (56, 12)`（未开 `sync_width_from_foot_gap`，因脚底为多边形）。若进门手感偏了，在编辑器里微调 `HouseDoor` 相对建筑坐标即可。

室内现为深色石室占位几何；**洞内分区、路径与探索点**见 [乱葬岭左山洞场景描述](../scenes/乱葬岭左山洞场景描述.md)（地牢 J · **J0～J13** · 底图 **5600×3600**）。替换正式美术／重建占位时按该文十四区铺开，门 ID / spawn 约定保持不变。

进门总览见：[窑村地图建筑进门与图层实现记录](./窑村地图建筑进门与图层实现记录.md)、[室内室外门切换设计](./室内室外门切换设计.md)。
