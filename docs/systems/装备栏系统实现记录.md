# 装备栏系统实现记录

## 文档目的
- 记录玩家装备栏的当前落地实现：数据层 `Equipment`、UI 层 `EquipmentSlotUI`，以及与 `Inventory / Player / WeaponBase` 之间的耦合方式。
- 与 [物品与背包系统设计说明](./物品与背包系统设计说明.md)、[武器系统](./武器系统.md) 配合阅读。

---

## 1. 功能范围（当前已实现）
- 玩家拥有 **5 个装备槽位**，竖向显示在「角色属性」面板（`P` 打开）的右侧栏。
- 槽位类型固定且有序：`武器 / 头部 / 胸甲 / 腿部 / 饰品`，**目前只有「武器」槽启用**，其余为占位（不可放入物品）。
- 主属性 / 派生属性两个 Tab 按钮已压缩字号与最小尺寸，不再撑满整行，给右侧装备列留出空间。
- 拖拽规则：
  - 背包 → 武器槽：把 `item_type=WEAPON` 的物品拖入即可。物品会从背包移走，不再占用物品栏；玩家持有的运行时武器会**切换为该装备**。
  - 武器槽原本有装备时，旧装备会**自动放回拖拽起点的同一个背包格**（一次操作即视为交换）。
  - 武器槽 → 背包：拖回任意背包格。空格直接落入；同槽位允许放入的装备类型且数量为 1 时与其交换；其他情况拒绝。
- 装备槽悬停弹出物品 Tooltip（名称 / 稀有度色 / 类型 / 描述）；空槽显示槽位中文名作为占位文字。
- 装备状态在「本次运行内」持久；目前未落盘。

## 2. 架构与数据流

### 2.1 主要对象关系

```
Equipment (RefCounted)               ← 5 个槽位的纯数据容器，emit equipment_changed
    ↑ 持有
Player (CharacterBody2D)             ← 入口 API：equip_from_inventory / unequip_to_inventory
    ↑ 委托
EquipmentSlotUI (Control)            ← 单个槽位的绘制 + 拖拽交互
    ↑ 列表化挂在
PlayerStatsPanel (CanvasLayer)       ← P 键打开，右列即装备栏
```

```
InventorySlotUI (Control)            ← 背包格子，新增了对 "from_equipment_slot" 拖拽包的接受
```

### 2.2 装备的运行时同步链路

`Equipment` 只存 `ItemData` 引用，**不直接控制武器实例**。把"装备槽 ItemData"翻译成"运行时挂在 Player 节点下的 `WeaponBase`"由 `Player.apply_equipped_weapon_item(item)` 完成：

1. `EquipmentSlotUI._drop_data` 收到来自背包的 `{"from_slot": idx}`。
2. 调用 `Player.equip_from_inventory(idx, slot_type)`。
3. `Player` 修改 `inventory` 与 `equipment` 两个容器（先把旧装备塞回起点格子，再把背包里的物品搬进装备槽）。
4. 若槽位是 `WEAPON`，调用 `apply_equipped_weapon_item(item)`：
   - 通过 `_WEAPON_SCENE_BY_ID`（`sword/spear/bow → res://scenes/weapons/*.tscn`）加载武器场景。
   - 若 `item is WeaponData` 直接复用，否则用 `_build_weapon_data_for_item(item)` 构造默认 `WeaponData`（与 `DebugWeaponMenu` 中的硬编码同源）。
   - 调用既有 `equip_weapon(scene, data)` 完成挂载、modifier 注入、信号转发。
5. `equipment_changed` 触发后，`EquipmentSlotUI.refresh()` 重绘；`inventory_changed` 让背包格子刷新。

> 与 `DebugWeaponMenu` 共存：`I` 键的调试菜单**直接调用 `Player.equip_weapon`**，绕过 `equipment` 数据层，因此调试菜单装备的武器**不会显示在装备槽里**，下次拖拽换装会被覆盖。这是当前的已知不一致点，留待后续合并到统一 API。

### 2.3 拖拽流程总览

| 拖拽方向 | drag data | 目标判定 | 入口方法 |
|---|---|---|---|
| 背包 → 武器槽 | `{"from_slot": int}` | `Equipment.is_slot_enabled(slot)` 且 `Equipment.can_equip(slot, item)` | `Player.equip_from_inventory(inv_idx, slot)` |
| 武器槽 → 背包 | `{"from_equipment_slot": int}` | 目标格为空 / 同类装备且 qty==1 | `Player.unequip_to_inventory(slot, inv_idx)` |
| 装备槽 ↔ 装备槽 | — | 暂不支持，`_can_drop_data` 直接 `false` | — |

## 3. 关键文件清单

### 数据层
- `scripts/core/items/equipment.gd`
  - `class_name Equipment`，`Slot` 枚举 `WEAPON / HEAD / BODY / LEGS / ACCESSORY`。
  - 静态规则：`can_equip(slot, item)`、`is_slot_enabled(slot)`、`slot_display_name(slot)`。
  - 信号：`equipment_changed(slot_type: int)`。
- `scripts/core/items/inventory.gd`
  - 新增 `set_slot_direct(index, item, quantity)`：跳过堆叠合并/查空格，直接覆写槽位。装备搬运专用。

### 逻辑层
- `scripts/player/player.gd`
  - 新增 `equipment: Equipment` 实例。
  - 新增常量 `_WEAPON_SCENE_BY_ID = { sword/spear/bow: 场景路径 }`。
  - 新增方法：
    - `apply_equipped_weapon_item(item)` —— 同步运行时武器实例。
    - `equip_from_inventory(inv_idx, slot)` —— 拖入装备槽的总入口。
    - `unequip_to_inventory(slot, inv_idx)` —— 拖回背包的总入口。
    - `unequip_weapon()` —— 卸下当前武器实例并移除 modifier（从 `equip_weapon` 拆出来复用）。
    - `_build_weapon_data_for_item(item)` —— 从普通 `ItemData` 构造默认 `WeaponData`（与调试菜单的数值一致）。

### UI 层
- `scripts/ui/equipment_slot_ui.gd`
  - `class_name EquipmentSlotUI extends Control`，固定 `48 × 48`。
  - 绘制：背景（启用 / 禁用 / 悬停 / 空 / 有物）、稀有度色边框、占位中文名 Label。
  - 拖拽：`_get_drag_data` 返回 `{"from_equipment_slot": slot_type}`；`_can_drop_data` 接受来自背包的拖拽并按 `Equipment.can_equip` 校验。
  - 监听 `equipment.equipment_changed` 自动刷新。
- `scripts/ui/inventory_slot_ui.gd`
  - `init(index, inv, player)` 增加可选 `Player` 参数，用于支持装备槽 → 背包的反向拖拽。
  - `_can_drop_data / _drop_data` 接受 `from_equipment_slot` 拖拽包，调用 `Player.unequip_to_inventory`。
- `scripts/ui/inventory_ui.gd`
  - 创建格子时把 `_player` 传入 `InventorySlotUI.init`。
- `scripts/ui/player_stats_panel.gd`
  - 主体改为 `HBoxContainer`：左列保留等级 / 经验 / 属性页签 / 滚动列表；右列为装备栏（`EquipmentSlotUI × 5`）。
  - 主属性 / 派生属性按钮：`font_size: 12`、`custom_minimum_size: Vector2(72, 22)`、`SIZE_SHRINK_BEGIN`，不再撑满整行。
  - 面板宽度从 `520` → `620`，给右侧装备列留位置。
  - 复制了一份装备槽专用的 Tooltip（与背包 Tooltip 同样式）。

### 场景与工程配置
- 没有新增 `.tscn`。`PlayerStatsPanel` 与 `InventoryUI` 仍然以全代码构建 UI，无需改场景文件。
- `project.godot` 未变。

## 4. 数据结构约定

### 4.1 `Equipment.Slot`
```text
WEAPON     = 0   # 当前唯一启用
HEAD       = 1   # 占位
BODY       = 2   # 占位
LEGS       = 3   # 占位
ACCESSORY  = 4   # 占位
```
顺序由 `SLOT_ORDER` 数组固定，UI 渲染顺序与之一致。

### 4.2 装备槽内存
- `Equipment._items: Dictionary { slot_type: ItemData | null }`
- 单个槽位**最多放一件**装备，`max_stack = 1` 由武器物品本身保证。

### 4.3 `_WEAPON_SCENE_BY_ID`
- 把背包物品 `id` 映射到 `res://scenes/weapons/*.tscn` 路径，目前覆盖 `sword / spear / bow`。
- 新增武器物品时**必须**在此注册场景路径，否则 `apply_equipped_weapon_item` 会 `push_warning` 并装备失败。

## 5. 交互规则（重要）

### 5.1 校验链
- 装备槽接受拖入：`Equipment.is_slot_enabled(slot) && Equipment.can_equip(slot, item)`。
- 背包格接受装备拖回：
  - 目标格为空 → 接受。
  - 目标格非空 → 必须是 `qty == 1` 且 `Equipment.can_equip(同槽, 该物品)`。

### 5.2 swap 顺序（防丢失）
`Player.equip_from_inventory` 内部固定按"先把旧装备塞回起点格、再把背包物品搬进装备槽"的顺序更新 `inventory`，最后才调 `apply_equipped_weapon_item`。这样即使中途任何一步失败，背包/装备的总持有件数都不会减少。

### 5.3 与运行时武器的关系
- **`equipment` 是真相**：`Player._equipped_weapon` 必须由 `apply_equipped_weapon_item(item)` 间接产生。
- 所以**清空武器槽 = 卸下运行时武器**，不需要额外调用 `unequip_weapon()`。

## 6. 常见改动入口（给后续开发）

### 启用其他装备槽
1. 在 `Equipment.can_equip()` 里为对应 slot 增加判定（例如 `HEAD` 接受 `item_type == ARMOR_HEAD`，需要先扩展 `ItemData.ItemType` 枚举）。
2. 在 `Equipment.is_slot_enabled()` 中把该 slot 加入启用列表。
3. 若有 gameplay 影响（属性 modifier），仿照 `apply_equipped_weapon_item` 在 `Player` 上加 `apply_equipped_<xxx>_item(item)`，并在 `equip_from_inventory / unequip_to_inventory` 的 slot 分支里调用。

### 新增可装备的武器物品
1. 在 `resources/items/item_catalog.json` 加 `item_type: "WEAPON"` 物品。
2. 在 `scenes/weapons/` 新建对应武器场景。
3. 在 `Player._WEAPON_SCENE_BY_ID` 映射 `item_id → 场景路径`。
4. 在 `Player._build_weapon_data_for_item(item)` 的 `match item.id` 中追加默认 `WeaponData` 配置（或让目录条目本身就是 `WeaponData` 资源，跳过这步）。

### 调整装备栏布局
- 槽位尺寸：`EquipmentSlotUI.SLOT_SIZE`。
- 列宽 / 间距：`PlayerStatsPanel._build_equipment_column()` 中的 `VBoxContainer`。
- 整体面板宽度：`PlayerStatsPanel._build_ui()` 里的 `_panel.custom_minimum_size` 与 `offset_*`。

## 7. 已知限制与注意事项

- **`DebugWeaponMenu` 与装备槽不同步**：`I` 键调试菜单仍直接调用 `Player.equip_weapon`，不写入 `equipment`。装备槽 UI 不会反映调试装备，且下一次正常拖拽会覆盖。
- **占位槽不可用**：头/胸/腿/饰品槽目前只能渲染，不能被拖入，且 `Equipment.set_item` 没有任何业务约束（仅 UI 层 `_can_drop_data` 拒绝）；后续若想热改 `is_slot_enabled` 直接生效，需要再加 UI 刷新订阅。
- **装备没有 modifier 词条来源声明**：当前 modifier 只来自 `WeaponData.build_modifiers()`，由 `equip_weapon` 注入；其他装备类型若也想注入需要单独设计（沿用 `source_tag = "equip:<slot>:<id>"` 之类的命名）。
- **没有"丢弃 / 直接销毁装备"流程**：装备只能在背包 ↔ 装备槽之间移动。
- **没有"穿戴提示"**：玩家把武器拖入装备槽时没有音效 / 屏幕提示，需要后续统一接入 UI 反馈层。
- **存档**：`equipment._items` 当前未参与持久化；落盘时应序列化为 `slot_type → item_id`。

## 9. 快速自测清单

- 按 `B` 打开背包，再按 `P` 打开角色属性面板：装备列出现在面板右侧，5 个槽位竖排，仅顶部"武器"槽看起来可交互。
- 把背包里的"剑"拖入武器槽：剑从背包消失，槽内出现剑色图标；左键点击攻击使用剑。
- 把背包里的"弓"拖入已经装着剑的武器槽：弓从背包消失出现在槽内，剑回到原本弓所在的背包格；左键攻击切换为弓。
- 把武器槽里的武器拖到任意空背包格：背包里出现该武器，槽位变空，左键攻击不再触发。
- 把武器槽里的武器拖到含有另一把武器（数量 1）的背包格：两者交换。
- 把武器槽里的武器拖到含有非武器物品（如石头）的背包格：被拒绝，状态不变。
- 把背包里的"石头"拖到头/胸/腿/饰品槽：被拒绝，状态不变。
- 主属性 / 派生属性两个 Tab 按钮明显比之前小，不再左右撑满。
