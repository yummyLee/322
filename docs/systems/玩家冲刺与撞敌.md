# 玩家冲刺与撞敌

## 概述

冲刺由两个**可独立开关**的节点能力组成，挂在 `Player` 场景下：

| 节点 | 脚本 | 作用 |
|------|------|------|
| `DashAbility` | `PlayerDashAbility` | 空格 + 方向键冲刺位移、冷却 |
| `DashHitAbility` | `PlayerDashHitAbility` | 冲刺期间对敌人造成伤害 |

在检查器中关闭对应节点的 **`enabled`** 即可禁用该能力，无需改 `Player` 脚本。

---

## 冲刺与怪物的「无碰撞但仍伤害」

### 需求

- 冲刺时**不要**与怪物发生 **`move_and_slide` 的实体碰撞**（可穿过怪）。
- 穿过时**仍要**对怪造成伤害（调用 `on_hit(damage)`，与武器、假人约定一致）。
- **保留与地形**的物理碰撞。

### 实现思路

1. **`PlayerDashAbility`**  
   - 冲刺**开始**：保存玩家当前 `collision_mask`，改为 **`dash_physics_collision_mask`**（默认 **`1`**，仅地形层）。  
   - 冲刺**结束**或能力被关闭：恢复保存的 mask。

2. **`PlayerDashHitAbility`**  
   - **不用** `get_slide_collision` 判怪（冲刺时 mask 已不含怪层，滑移碰撞里本来也不会有怪）。  
   - 每帧用 **`PhysicsDirectSpaceState2D.intersect_shape`**：以玩家 **`CollisionShape2D` 的 shape + global_transform** 做形状查询。  
   - 查询使用单独的 **`enemy_damage_collision_mask`**（默认 **`2`**，与假人/怪所在层一致），与当前 `move_and_slide` 的 mask **无关**。  
   - 同一次冲刺内，对每个目标实例**只结算一次**伤害（按 `instance_id` 去重）。

---

## 碰撞层约定（当前工程）

- 玩家本体：`collision_layer = 8`，平时 `collision_mask = 1` → **只与层 1（地形）做 `move_and_slide` 碰撞**，**不与敌人层推挤**。  
- 冲刺中：`dash_physics_collision_mask = 1` → 与平时相同（仍为仅地形）；穿过怪物依赖上述分层，撞敌仍由 `DashHitAbility` 单独查询。  
- 假人 `TestDummy`：`collision_layer = 2`。  
- 伤害查询：`enemy_damage_collision_mask = 2`。

若地形占**多个层**，将 `dash_physics_collision_mask` 设为这些层的**按位或**（例如层 1 与层 16：`1 | 16 = 17`）。

## 可配置项

### `DashAbility`（`PlayerDashAbility`）

| 属性 | 说明 |
|------|------|
| `enabled` | 是否启用冲刺 |
| `dash_distance` | 约移动路程（像素） |
| `dash_duration` | 冲刺持续时间（秒） |
| `dash_cooldown` | 冷却（秒） |
| `dash_physics_collision_mask` | 冲刺中 **`move_and_slide` 使用的 mask**（默认仅地形 `1`） |

### `DashHitAbility`（`PlayerDashHitAbility`）

| 属性 | 说明 |
|------|------|
| `enabled` | 是否启用冲刺撞伤 |
| `damage` | 每次冲刺对每个目标造成的伤害 |
| `dash_ability_path` | 指向 `DashAbility` 节点（默认同场景内 `../DashAbility`） |
| `enemy_damage_collision_mask` | **形状重叠查询**使用的层掩码（默认 `2`） |
| `collision_shape_path` | 相对 `Player` 的 `CollisionShape2D` 路径（默认 `CollisionShape2D`） |
| `overlap_query_max_results` | `intersect_shape` 最大返回数（默认 `32`） |

## 敌人接口

可受伤目标需实现：

```gdscript
func on_hit(damage: float) -> void
```

与近战武器、`TestDummy` 一致。

---

## 扩展说明

- 若敌人根节点是 **Area2D** 而非 `CharacterBody2D` / `StaticBody2D`，需在 `PlayerDashHitAbility` 中把 **`collide_with_areas`** 设为 `true`（当前脚本为 `false`，仅查 `RigidBody2D` / `CharacterBody2D` / `StaticBody2D` 等 body）。可按项目需要改为导出变量。

- 完全移除冲刺：可删除 `DashAbility` 节点；`Player` 已对缺失节点做判断。  
- 仅保留位移、不要撞伤：关闭 **`DashHitAbility.enabled`**。
