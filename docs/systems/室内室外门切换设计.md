# 室内室外门切换设计

> 实现：`SceneDoorTransition`（切场景状态 + 淡入淡出）+ `SceneDoorTrigger`（`DIRECTIONAL_CROSS` 模式）  
> 首版落地：沈寂屋 ↔ `phase1_room` / `chapter1_world`；窑村 **House2** ↔ `house2_room` / `yaocun_v1_map`  
> **实现总览**（进门与 MapBuilding 门洞/图层联动）：[窑村地图建筑进门与图层实现记录](./窑村地图建筑进门与图层实现记录.md)

---

## 一、问题

旧方案用 `Area2D` + `AUTO_ENTER`（进入即切场景），在俯视角上下移动时容易误触：

| 场景 | 误触情况 |
|------|----------|
| 出房间后往南走 | 落点靠近门槛，立刻再次进门 |
| 大世界在门口徘徊 | 擦过触发区即切场景，与移动意图无关 |
| 切场景后 | 落点在触发区内，首帧即二次切换 |

需要：**只有玩家「有意穿过门槛」时才切换**，并做落点防呆。

---

## 二、设计原则

1. **单向穿越**：进门、出门各配置允许的**移动方向**（室外→室内 = 向北，室内→室外 = 向南）。
2. **薄门槛**：触发区是门洞宽 × 约 12px 的窄条，贴在建筑南墙门线，不用大块 Area。
3. **落点防呆**：切场景后落点放在门槛**外侧一步**（室外出门落在门槛南侧；室内进门落在门槛北侧），避免首帧二次切换。
4. **淡入淡出**与穿越判定解耦，统一走 `SceneDoorTransition`。
5. **冲刺进门**：`cross_detect_margin_y` 扩大纵向监测；冲刺时用 `DashAbility` 动画位移向量判方向，并支持**跨帧穿越门槛线**检测。

---

## 三、坐标与穿越方向

俯视角 **Y 轴向南**（向下为正）：

```
        北（院内 / 室内）
            ↑
    ────[ 门洞门槛 ]────  ← 薄触发区（中心在门线）
            ↓
        南（院外 / 室外）
```

| 穿越模式 | 玩家相对门槛位置 | 速度要求 |
|----------|------------------|----------|
| `ENTER_FROM_SOUTH` | 在门槛**南侧**（`rel.y > 边距`） | `velocity.y < -min_cross_speed`（向北） |
| `EXIT_TO_SOUTH` | 在门槛**北侧**（`rel.y < -边距`） | `velocity.y > min_cross_speed`（向南） |

静止或横向擦过门槛 → **不切换**。

### 穿越检测（`DIRECTIONAL_CROSS`）

除「在触发区内 + 速度方向正确」外，`_physics_process` 还记录玩家上一帧位置；当玩家在门洞 x 范围内**跨帧穿过门槛线**（`prev_y` 在门槛一侧、`pos.y` 到另一侧）时也触发切换，避免冲刺一帧穿过薄 `Area2D` 漏检。

| 参数 | 默认 | 说明 |
|------|------|------|
| `cross_detect_margin_y` | `72` | 门槛线上下纵向监测半宽（px） |
| `min_cross_speed` | `20` | 非冲刺时要求的最小纵向速度 |
| `side_margin` | `6` | 相对门槛中心的纵向站位边距 |

---

## 四、落点防呆

切场景后，新场景把玩家放到**远离门槛、符合移动意图**的落点，而不是门槛正中央：

| 方向 | 落点原则 |
|------|----------|
| 室外 → 室内 | 落在门槛**北侧**（院内 / 门内一步） |
| 室内 → 室外 | 落在门槛**南侧**（院外 / 门前一步） |

同一对门洞使用相同 `door_link_id`（便于成对维护；当前实现**不依赖**宽限期 API，靠落点偏移 + 方向穿越即可防二次切换）。

### 沈寂屋

| 落点 spawn_id | 落点位置 | 说明 |
|---------------|----------|------|
| `shenji_room_exit` | 门槛**北侧**院内 `(120, 158)` | 出院后落在门内；再向南可出门 |
| `world_to_room` | 室内门槛北侧 `(0, 168)` | 进门后靠近南门内侧 |

### 窑村 House2

| 落点 spawn_id | 场景节点 | 说明 |
|---------------|----------|------|
| `world_to_room` | `house2_room.tscn` → `Markers/SpawnWorldToRoom` `(0, 140)` | 从室外进门后落在室内门槛北侧 |
| `house2_room_exit` | `yaocun_v1_map.tscn` → `Markers/SpawnHouse2RoomExit` | 运行时由 `yaocun_v1_map.gd` 设为门槛南侧 `+36px` |

`SpawnHouse2RoomExit` 在 `.tscn` 里仅为占位坐标；`_sync_door_layout()` 在 `_ready` 时根据 House2 脚底碰撞重算门线与落点。

## 七、API 摘要

### `SceneDoorTransition`

| 方法 | 用途 |
|------|------|
| `set_pending_spawn(spawn_id, fade_in)` | 切场景前写入落点与淡入时长 |
| `take_pending_spawn_id()` | 新场景 `_ready` 读取落点 |
| `fade_in_from_scene_load(tree)` | 场景加载后淡入（黑幕存在时必淡出） |
| `fade_out_and_change(tree, path, dur)` | 黑幕淡出并 `change_scene_to_file` |

### `SceneDoorTrigger`

- `INTERACT`：按交互键（其他建筑门预留）
- `DIRECTIONAL_CROSS`：方向穿越 + 跨帧门槛线检测（室内室外门）
- `AUTO_ENTER`：保留，非室内门不使用

## 八、窑村 House2 落地（`yaocun_v1_map`）

### 场景关系

```text
yaocun_v1_map.tscn（室外）
  Doors/House2Door  ──向北穿越──►  house2_room.tscn（室内）
  Markers/SpawnHouse2RoomExit  ◄──向南穿越──  Doors/ExitToWorld
```

### 门线 / 门宽：从 MapBuilding 脚底自动推算

`scripts/chapter1/yaocun_v1_map.gd` 在 `_sync_door_layout()` 中读取 `Entities/House2`（`MapBuilding`）的 `FootCollision`：

1. 取**最南一排**脚底块（`MapBuilding.get_door_gaps_local()`：矩形或多边形南缘聚类）；
2. 按 x 排序后取相邻空隙作为门洞（宽度 / 中心）；
3. 将挂在建筑下的 `MapBuildingDoor`（若 `sync_width_from_foot_gap`）的 `trigger_size.x` 同步为门洞宽度 × `building.scale.x`（最小 24px）。

**配置要求**：南墙门洞 = 左右墙基 footprint 留空，或整块多边形南侧凹口 ≥8px。侧墙 / 内墙不在最南一排则不参与门洞推断。

### 室外门 `Doors/House2Door`

| 属性 | 值 |
|------|-----|
| `target_scene` | `res://scenes/chapter1/house2_room.tscn` |
| `spawn_id` | `world_to_room` |
| `door_link_id` | `house2_door` |
| `trigger_mode` | `DIRECTIONAL_CROSS`（枚举值 2） |
| `cross_mode` | `ENTER_FROM_SOUTH`（默认） |
| `trigger_size` | 运行时覆盖 x；默认 `Vector2(80, 12)` |

### 室内门 `house2_room.tscn` → `Doors/ExitToWorld`

| 属性 | 值 |
|------|-----|
| `target_scene` | `res://scenes/chapter1/yaocun_v1_map.tscn` |
| `spawn_id` | `house2_room_exit` |
| `door_link_id` | `house2_door` |
| `trigger_mode` | `DIRECTIONAL_CROSS` |
| `cross_mode` | `EXIT_TO_SOUTH`（枚举值 1） |
| `trigger_size` | `Vector2(68, 12)` |

### 场景脚本职责

| 脚本 | 职责 |
|------|------|
| `yaocun_v1_map.gd` | 同步 House2 门线/门宽/出门落点；`take_pending_spawn_id()` 放置玩家；`fade_in_from_scene_load` |
| `house2_room.gd` | 室内落点；淡入；室内清屏色 |

### 淡入淡出注意点

`SceneDoorTransition.fade_in_from_scene_load()`：**黑幕 alpha 仍 > 0 时一律淡出**，避免切场景后卡在黑屏（此前「无 pending 则不淡入」会导致进门黑屏）。

## 九、扩展

周伯屋等后续室内场景复用同一套：`door_link_id` + `DIRECTIONAL_CROSS` + `SceneSpawnMarker`。

与 MapBuilding 的配合：门洞由脚底最南一排墙基间隙推断；门前图层与穿越判定解耦，详见 [窑村地图建筑进门与图层实现记录](./窑村地图建筑进门与图层实现记录.md) 第六节。
