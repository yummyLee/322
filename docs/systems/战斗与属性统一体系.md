# 战斗与属性统一体系

## 概述

玩家和怪物共用同一套属性系统（`CharacterAttributes`），通过 **`CombatantComponent`** 组件挂载。各系统之间通过接口通信，互不直接引用。

---

## 架构图

```
武器系统                        角色（Player / EnemyBase / 训练假人）
───────────                     ─────────────────────────────────────
WeaponBase.try_attack(dir)
  │
  ├─ wielder_combatant ──────▶ CombatantComponent（持有者，装备时注入）
  │   compute_hit_damage()        compute_outgoing_physical()
  │   (ATK + base_dmg) × crit     → 出手伤害（含 STR/暴击/全伤害加成）
  │
  ├─ AttackBehaviorBase
  │   _on_body_entered()
  │   body.on_hit(computed_damage) ─────▶ 目标.on_hit(damage)
  │                                           │
  └─ weapon_hit(WeaponHitInfo) → 信号       CombatantComponent（目标）
     （UI/调试用）                            ┌──────────────────────────┐
                                             │ CharacterAttributes       │
                                             │   五维主属性 → 派生属性    │
                                             │ current_hp / current_mp   │
                                             │ on_hit() / receive_hit()  │
                                             └────────┬─────────────────┘
                                                      │
                                             DamageCalculator（纯静态）
                                             ┌──────────────────────────┐
                                             │ 防御侧：闪避→护甲/魔抗→抗性│
                                             │ 攻击侧：攻击力+暴击+全伤害 │
                                             └──────────────────────────┘
```

## 解耦关系

| A 系统 | B 系统 | 交互方式 |
|--------|--------|----------|
| 武器系统 | 角色属性 | 装备时注入 `wielder_combatant`；未注入退化为纯 base_damage |
| 武器系统 | 目标 | `body.on_hit(damage)` 鸭子类型调用 |
| 角色 | 属性管理 | 通过 `CombatantComponent` 子节点，删节点即脱离 |
| 属性管理 | 伤害计算 | `DamageCalculator` 纯静态方法，接收属性返回数值 |
| 冲刺撞伤 | 目标 | `node.call("on_hit", damage)` 同一约定 |

**属性系统不引用** 武器、伤害计算。
**伤害计算不引用** 任何节点，只接收 `CharacterAttributes` + 数值。

## CombatantComponent 配置项

在编辑器检查器中直接设置：

| 属性 | 说明 |
|------|------|
| `base_str` | 力量（→ 物攻、生命） |
| `base_agi` | 敏捷（→ 攻速、闪避、移速加成） |
| `base_int` | 智力（→ 法攻、法力、法力回复、CDR） |
| `base_con` | 体力（→ 护甲、魔抗、生命回复） |
| `base_luk` | 幸运（→ 暴击率、暴击伤害、收获加成） |
| `auto_tick` | 自动每帧 tick modifier 到期 + HP/MP 回复（默认 true） |
| `use_default_formulas` | 使用默认派生公式（默认 true） |

> "不死"语义已迁移到 Buff 系统：通过 `ImmortalBuff.apply(combatant)` 施加 `&"immortal"` Buff，
> 受击时 `CombatantComponent.is_immortal()` 返回 true，HP 会被钳在 1，不触发 `died`。
> 训练假人通过场景中的 `ImmortalApplier` 组件实现，不再需要专用字段。

## 完整伤害流程

### 攻击侧（WeaponBase → 目标）

```
Player 按下鼠标左键
  → _try_weapon_attack()
  → WeaponBase.try_attack(direction)
  → AttackBehaviorBase.execute(data, direction)
  → 命中检测（Area2D 或 PhysicsShapeQuery）
  → _on_body_entered(body)
    → weapon.compute_hit_damage(base_damage, damage_multiplier)
      → wielder_combatant.compute_outgoing_physical(raw)
        → DamageCalculator.compute_outgoing_physical(attrs, raw)
          → outgoing = (ATK_POWER + raw) × (1 + DAMAGE_BONUS_ALL)
          → 暴击判定: randf() < CRIT_RATE ? outgoing *= CRIT_DAMAGE
      → 返回 { "damage": computed, "is_crit": bool }
    → body.on_hit(computed_damage)

弹丸特殊：发射前预计算 → projectile.launch(data, dir, hit_damage)
```

### 防御侧（CombatantComponent 内部）

```
Player / EnemyBase.on_hit(damage)
  → CombatantComponent.on_hit(damage)
    → 构造 HitContext { raw_damage=damage, type=PHYSICAL }
    → DamageCalculator.apply_defense(raw, type, defender_attrs, penetration)
      → 闪避判定：rand() < evasion ? 伤害=0
      → 护甲减免：有效护甲 / (有效护甲 + 100)
    → current_hp -= final_damage
    → 发出信号 damage_received / health_changed / died
```

### 无属性退化

若 `wielder_combatant` 为 null（如未装备到角色的武器），伤害退化为 `base_damage * multiplier`，不经过属性加成。防御侧同理，若 `defender_attrs` 为 null，不进行减免。

## 属性计算公式（v3，详见 [`../narrative/角色属性v3.md`](../narrative/角色属性v3.md)）

### 等级倍率

```
Atk(L) = 1.0 + (L - 1) × 0.012   # 攻击维度
Vit(L) = 1.0 + (L - 1) × 0.007   # 生存维度
```

99 级：Atk(99) ≈ 2.176，Vit(99) ≈ 1.686。

### 主属性 → 派生属性

| 派生属性 | 公式 | 上限 | 驱动 |
|----------|------|:----:|:----:|
| 物理攻击力 | STR × 1.5 × Atk(L) | — | STR |
| 生命上限 | 60 + STR × 12 × Vit(L) | — | STR |
| 攻击速度 | 1.0 + AGI × 0.008 | 250% | AGI |
| 闪避 | AGI × 0.003 | 60% | AGI |
| 移速加成 | AGI × 0.001 | 30% | AGI |
| 魔法攻击力 | INT × 1.8 × Atk(L) | — | INT |
| 最大法力 | 30 + INT × 10 | — | INT |
| 法力回复 | INT × 0.2 /s | — | INT |
| 冷却缩减 | INT × 0.003 | 40% | INT |
| 护甲 | CON × 1.2 × Vit(L) | — | CON |
| 魔法抗性 | CON × 0.8 × Vit(L) | — | CON |
| 生命回复 | CON × 0.4 /s | — | CON |
| 暴击率 | 5% + LUK × 0.4% | 75% | LUK |
| 暴击伤害 | 150% + LUK × 1.2% | 500% | LUK |
| 收获加成 | LUK × 0.5% | — | LUK |

**v3 关键变化**：

- 每个派生只由 1 个主属性驱动（取消了 v2 的"主+次"交叉）
- 进攻 / 生存维度引入等级倍率，缓解高等级"加点没感觉"
- 利用率类派生（攻速 / 闪避 / 暴击 / CDR）强制硬上限，不引入等级倍率
- 加点曲线：1 级各维 8，每级 5 自由点，**取消每级 5 维各 +1 的固定成长**

### Modifier 三层公式

```
final = (base + Σflat) × (1 + Σpercent_add) × Π(1 + percent_mult_i)
```

### 词条属性（无基础值，纯 modifier 驱动）

`DAMAGE_BONUS_ALL`、`PENETRATION`、`ATTACK_RANGE`、`LIFESTEAL`、
`DMG_FIRE/ICE/LIGHTNING/POISON`、`RES_FIRE/ICE/LIGHTNING/POISON`、
`STATUS_CHANCE`、`MOVE_SPEED`、`PICKUP_RANGE`

> 重要：词条属性没有 base 值，通过 `ModifierContainer.get_all_stat_ids()` 确保 `_recalculate()` 能正确遍历到它们。

### 防御公式

```
物理减伤率 = 有效护甲 / (有效护甲 + 100)
  有效护甲 = max(0, 护甲 - 穿透)

魔法减伤率 = 有效魔抗 / (有效魔抗 + 100)

元素伤害 = 原始伤害 × (1 - 魔法减伤率) × (1 - 元素抗性)

真实伤害 → 无视一切防御
```

## 如何创建一个怪物

1. 新建场景，根节点 `CharacterBody2D`，挂 `EnemyBase` 脚本
2. 添加子节点 `Node`，挂 `CombatantComponent`，命名为 **`CombatantComponent`**
3. 检查器里设五维属性（如 STR=3, CON=8）
4. 添加 `CollisionShape2D`，设 `collision_layer = 2`
5. 放到关卡场景中即可

子类可重写：
- `_on_died()` → 死亡动画 / 掉落
- `_on_damage_received(final_damage, context)` → 受击特效 / 飘字
- `_draw()` → 自定义外观

## Player 的接入

- `player.tscn` 中 `CombatantComponent` 子节点（STR=10, AGI=8, INT=5, CON=12, LUK=6）
- `player.gd._ready()` 自动从组件获取 `character_attributes`
- `equip_weapon()` 自动将 `_combatant` 注入武器的 `wielder_combatant`
- 装备/卸下武器自动注入/移除 modifier
- `on_hit()` / `receive_hit()` 委托给 `CombatantComponent`

## 信号列表（CombatantComponent）

| 信号 | 参数 | 触发时机 |
|------|------|----------|
| `health_changed` | `current_hp, max_hp` | HP 变化（受伤 / 治疗 / 回复） |
| `mana_changed` | `current_mp, max_mp` | MP 变化（回复） |
| `damage_received` | `final_damage, HitContext` | 受到伤害后（含最终伤害和上下文） |
| `died` | 无 | HP 降为 0 |

## 碰撞层约定

| 层 | 用途 | 备注 |
|----|------|------|
| 1 | 地形 / 墙壁 | |
| 2 | 敌人（怪物、假人） | |
| 4 | 弹丸 | |
| 8 | 玩家 `CharacterBody2D` | 与地形、敌人分层，移动时不与怪互相挤压 |
| 16 | 玩家 `CombatHurtbox`（`Area2D`） | 仅承接敌方攻击形状查询；伤害转发给父节点 `on_hit` |

玩家 `collision_layer = 8`，`collision_mask = 1`（仅地形）。
受击框 `CombatHurtbox`：`collision_layer = 16`，不参与移动推挤。
冲刺中 `dash_physics_collision_mask = 1`（仍仅地形；与平时一致，撞敌靠 `DashHitAbility` 形状查询）。
