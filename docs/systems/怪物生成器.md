# 怪物生成器（MonsterSpawner）与规则编排

## 概念

- **`MonsterSpawnRule`（资源）**：描述**一条**生成逻辑（区域、成团数量、距玩家距离、怪物池等）。
- **`MonsterSpawner`（节点）**：放在房间里，提供**坐标变换**（`to_global`）与父节点、玩家解析；负责**执行**一条规则：`spawn_wave(rule)`。
- **`MonsterSpawnRuleRunner`（节点）**：挂多条规则，按模式**依次**执行，并支持**步间延迟**与**循环整组规则**。

## MonsterSpawnRule

- 脚本：`scripts/enemies/monster_spawn_rule.gd`（`class_name MonsterSpawnRule`）
- 可在检查器中 **New Resource** 保存为 `.tres`，或在 `MonsterSpawnRuleRunner.rules` 数组里内联编辑。
- **`spawn_area_mode`**：
  - `RECT_LOCAL`：在 `spawn_area_local` 矩形内随机锚点（可与 `min_distance_from_player` 组合过滤）。
  - `RING_AROUND_PLAYER`：以**玩家**为圆心，在 `[ring_min_radius, ring_max_radius]` **圆环**上随机取点（世界坐标）；**必须能解析到玩家**（Spawner 的 `player_node` / `player_group`）。
- **`ring_independent_positions`**（仅环模式）：`true` 时每只怪各自随机环上一点；`false` 时每团一个锚点再用 `pack_spread_radius` 散开。
- 主要字段：
  - `display_name`：备注用
  - `spawn_area_local`：`RECT_LOCAL` 用
  - `ring_min_radius` / `ring_max_radius`：`RING_AROUND_PLAYER` 用（`max < min` 时退化为 `min`）
  - `pack_count` / `pack_size_min` / `pack_size_max` / `pack_spread_radius`
  - `min_distance_from_player` / `max_anchor_attempts`（矩形模式过滤锚点）
  - `spawn_entries`：`MonsterSpawnEntry` 加权列表
  - `fallback_monster_scene`：条目为空时的默认场景

### 示例：每 2 秒在玩家环外随机刷 1～3 只森林怪、循环

1. `MonsterSpawner`：`spawn_on_ready = false`，挂好 `fallback` 或仅用规则里的场景。
2. 一条 `MonsterSpawnRule`：`spawn_area_mode = RING_AROUND_PLAYER`，`pack_count = 1`，`pack_size_min = 1`，`pack_size_max = 3`，`ring_independent_positions = true`，`fallback_monster_scene = forest_monster.tscn`。
3. `MonsterSpawnRuleRunner`：`rules = [该规则]`，`run_mode = SEQUENCE_LOOP`，`sequence_repeat_limit = 0`，`delay_before_first_sec = 2`，`delay_between_rules_sec = 2`，`start_on_ready = true`。

参考场景：`scenes/test/grassland_test.tscn`。

## MonsterSpawner

- 脚本：`scripts/enemies/monster_spawner.gd`
- **默认行为**：节点上仍有一组导出字段；**无参** `spawn_wave()` 会按这些字段生成一份临时规则并执行（兼容旧场景）。
- **传参**：`spawn_wave(rule: MonsterSpawnRule)` 只执行该规则（区域等以规则为准，父节点与玩家仍用 Spawner 上的路径/组）。
- 信号：`wave_finished(spawned_count)`
- 编辑器内可绘制 `spawn_area_local`（默认规则区域预览）。

## MonsterSpawnRuleRunner

- 脚本：`scripts/enemies/monster_spawn_rule_runner.gd`
- `spawner_path`：指向场景中的 `MonsterSpawner`（默认 `../MonsterSpawner`）。
- `rules`：`MonsterSpawnRule` 数组，按**下标顺序**执行。
- **`run_mode`**：
  - `SEQUENCE_ONCE`：每条规则执行**一次**后结束。
  - `SEQUENCE_LOOP`：从第一条到最后一条算**一轮**，反复执行；`sequence_repeat_limit`：**0 = 无限**，**N = 执行 N 轮后停**。
- `delay_before_first_sec`：第一次执行前等待。
- `delay_between_rules_sec`：每条规则执行完后的间隔（下一轮第一条也会经过该间隔）。
- `start_on_ready`：进入场景自动 `start_runner()`。
- API：`start_runner()` / `stop_runner()`
- 信号：`started`、`rule_step_started`、`rule_step_finished`、`runner_finished(reason)`

### `runner_finished` 的 reason（StringName）

- `sequence_once_done`：顺序一轮结束
- `loop_limit_reached`：循环达到 `sequence_repeat_limit`
- `no_spawner` / `no_rules`：配置错误
- `stopped`：调用 `stop_runner()`

## 示例工作流

1. 场景中放置 `MonsterSpawner`，对齐房间（可选保留默认导出用于单次测试）。
2. 新建若干 `MonsterSpawnRule`（例如「近战团」「远程团」不同 `spawn_area_local` / `pack_count` / 怪物池）。
3. 添加 `MonsterSpawnRuleRunner`，`rules` 里按顺序拖入规则，`run_mode` 选 `SEQUENCE_ONCE` 或 `SEQUENCE_LOOP`。
4. 需要由剧情/按钮触发时：关 `start_on_ready`，脚本里调用 `start_runner()`。

## 与草地测试场景

`scenes/test/grassland_test.tscn` 仍可直接使用 **仅 MonsterSpawner + 默认导出**；若要演示多规则，在同一父节点下增加 `MonsterSpawnRuleRunner` 并配置 `rules` 即可。
