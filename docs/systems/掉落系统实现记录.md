# 掉落系统实现记录

怪物击杀后在死亡位置散落金币与物品；掉落规则由 **Resource 掉落表** 驱动，与 [`核心循环补全详细设计.md`](../核心循环补全详细设计.md) §1 对齐。

| 角色 | 路径 |

## 接入方式

1. **生成器路径（推荐）**：在 `MonsterStatProfile` 上指定 `loot_table`。`MonsterSpawner` → `MonsterStatApplier.apply()` 会自动 `LootDropperComponent.ensure_on(enemy)` 并 `configure(profile.loot_table)`。
2. **手动挂载**：在任意 `EnemyBase` 下添加 `LootDropper` 子节点，导出 `loot_table`；或调用 `LootDropperComponent.ensure_on(enemy)`。
3. **摘下组件 = 不掉落**（组件即功能），与 `KillXpGranter` 并列、互不依赖。

## 掉落表字段说明

### LootTable

| 字段 | 说明 |
|------|------|
| `enabled` | 表总开关；`false` 时整表不 roll |
| `table_chance` | 表级触发概率（0~1），如 0.3 表示 30% 怪才进入后续掉落 |
| `gold_min` / `gold_max` | 金币数量区间（生成 `WorldGoldPickup`） |
| `gold_chance` | 金币独立命中概率 |
| `guaranteed` | 独立掉落池：每条按自身 `chance` 单独判定 |
| `weighted` | 加权池：先 `roll_count_min~max` 次，每次按 `weight` 抽 1 条 |
| `roll_count_min` / `roll_count_max` | 加权抽取次数区间 |

### LootEntry

| 字段 | 说明 |
|------|------|
| `enabled` | 单条开关 |
| `item_id` | 对齐 `ItemDatabase` / `item_catalog.json` |
| `chance` | **guaranteed 池**：独立命中概率（1 = 必出） |
| `weight` | **weighted 池**：相对权重 |
| `min_count` / `max_count` | 掉落数量区间 |

## 运行时流程

1. 玩家击杀 → `CombatantComponent.died(last_hit)`。
2. `LootDropperComponent` 检查 `last_hit.attacker_node is Player`。
3. 若配置了 `unique_enemy_id`，查 `SaveManager.is_unique_enemy_defeated()`；已击败则跳过；首次击杀写入 `register_unique_enemy_defeated()`。
4. `LootRoller.roll(table, rng)` → `LootRoller.spawn_drops()` 在死亡点附近散落。
5. `WorldItem.spawn_at` / `WorldGoldPickup.spawn_at` 生成拾取物并播放落地弹跳。

## 落地弹跳动画

由 `WorldPickupMotion.play_land_bounce()` 统一实现：

- 自落点上方 `BOUNCE_DROP_HEIGHT`（24px）处以小缩放出现；
- `position:y` 使用 `TRANS_BOUNCE` 落至目标高度；
- `scale` 使用 `TRANS_BACK` 过冲回 1.0；
- 动画结束后进入 idle 上下漂浮（`WorldItem` / `WorldGoldPickup` 均有）。

**场景内静态放置**的 `WorldItem`（非 `spawn_at` 动态生成）不播放弹跳，直接 idle 漂浮。

## 草原测试配置

`grassland_forest_profile.tres` 与 `grassland_archer_profile.tres` 均已引用 `grassland_common.tres`。

**默认掉落（`grassland_common.tres`）**：

| 类型 | 内容 |
|------|------|
| 金币 | 5~15，100% |
| guaranteed | 风绒草 55%×(1~2)、赤根草 45%×(1~2)、韧皮纤维 35%×(1~3) |
| weighted 0~1 次 | 铜矿石 / 石头 / 木头（权重 5:3:2） |

**测试步骤**：运行 `scenes/test/grassland_test.tscn` → 等刷怪 → 击杀 → 观察散落物弹跳与拾取。

## 存档策略

- 已掉落、未拾取的战利品 **不持久化**（重进场景刷新，常规 ARPG 行为）。
- 唯一怪一次性掉落：复用 `SaveManager._world_state.defeated_unique_enemies`。
- 场景内带 `persist_id` 的静态 `WorldItem` 仍走原有 `picked_up_items` 逻辑，与击杀掉落无关。
