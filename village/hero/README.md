# 可编辑 3D 主角

当前角色已暂时从窑村移出，F5 为场景调试：方向键平移镜头。模型与动画文件均保留。后续将 `hero.tscn` 实例化到 `yao_village.tscn` 根节点并命名为 `Hero`，即可重新接入控制和跟随；原出生位置为 (-4, 0.1, 5)，角色模式镜头 size 可设为 12。

- F5 运行 `village/main.tscn`：方向键按屏幕方向行走，按住 Shift 跑步；滚轮缩放，R 重置镜头，Esc 设置。
- `hero.tscn` 为独立可复用角色。角色朝向本地 +Z，直立于 Y 轴；无需倾斜模型来适配画面。
- `Visual/Hips` 下保存身体、头发、服装、手臂和腿的实际网格节点。关节为分层 Node3D，可直接选择、移动、旋转；这是分部件低多边形模型，没有蒙皮骨骼。
- 选中 AnimationPlayer，在动画面板修改 `idle`、`walk`、`run` 的关键帧。待机轻微起伏，行走交替摆臂摆腿，跑步增加前倾、屈膝和摆臂。
- 根节点 Inspector 可调 walk_speed、run_speed、acceleration、turn_speed；BodyCollision 可改胶囊碰撞。
- `yao_village.tscn` 内的 Hero 实例决定出生点；RenderRig/VillageCamera 保存约 35° 俯角、正交投影和默认 size=12。运行时保留相机基准角度，跟随角色并按当前像素尺寸吸附。旋转和动画仍可能产生像素跳动。
- `world_collisions.tscn` 保存地面、建筑主体、树干和地图边界碰撞，可独立编辑。装饰物尚未全部配置碰撞；屋顶、树冠尚未实现遮挡淡出。
- 模型依据参考图重新制作，保留主要配色和服饰特征，不是逐像素还原。动画为手工关键帧近似，不是从图片恢复的动作捕捉。
- 第二版将躯干、脸部、四肢和鞋改为多圈截面网格，添加圆肩、肘部衔接、脸颊和分层发束；保留原节点层级与动画路径。`hero_before_refinement.tscn` 是修改前的备份。
- 动画以 +Z 为前方：躯干 X 正旋转前倾，肘部 X 负旋转向前屈臂，膝盖 X 正旋转向后收腿。
- 稳定像素显示：物理插值 + 同步物理动画 + 相机读取插值位置；默认 1920×1080 窗口实际渲染 640×360，最近邻放大 3 倍。窗口改变时按整数像素倍数计算渲染尺寸，描边不再二次抽样。
- 相机在低分辨率网格上吸附，最终画面补偿为显示屏像素位移。它减轻移动错拍和全画面跳动，但不会消除关节旋转、阴影、描边产生的所有像素变化。增大像素颗粒会让这些变化更明显。
- tools 下制作脚本仅用于一次性制作，不在运行时调用。请直接编辑已保存场景；不要重新生成覆盖手工修改。
