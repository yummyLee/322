# 乱葬岭左山洞 v4 区块设计

这张参考图不是一块连续地面，而是黑色落差中的多个洞室、竖井和窄通路。v4 先按场景描述中的 J0～J13 拆分，再把区块接成三条可读回路和两条捷径。世界坐标以图像下方为南、`Y=0` 为主要行走基准；水阶、深井和桥栏单独保留高度。

## v4 通路关系

- 天光主廊：J0 → J1 → J8，使用一条连续 S 形地面带，南门不会落空。
- 东侧高环：J8 → J2 → J4 → J11 → J5，再沿深层路回到 J8。
- 西侧湿环：J8 → J3 → J9 → J6，末端从陷坑豁口望向 J5。
- 深层环：J5 → J10 → J12 → J13；J10 西侧的 J7 是封缝死路。
- 两条捷径：J4 → J0 的落台、J12 → J8 的采石捷径，均使用连续窄带和独立碰撞。

墙面使用每个洞室轮廓的连续三段式洞壁带，通路入口使用低矮石柱分隔；平台只作为洞室地面，不能代替洞壁。石柱使用四环变半径构件，J9 另放置 22 根错落石柱和 8 根倒挂钟乳石，避免圆柱或方块重复堆叠。所有落差外缘只有贴着崖口的碎石唇，没有悬空的底部方块。
