# 乱葬岭左山洞区块设计

这张参考图不是一块连续地面，而是黑色落差中的多个洞室、竖井和窄通路。建模先按空间功能拆分，再把各区块接成可探索的回路。

## 区块

| 区块 | 画面位置 | 空间特征 | 建模重点 |
| --- | --- | --- | --- |
| J0 入口喉道 | 下方偏中 | 狭窄、向内收口 | 不规则拱口、两侧岩壁、入口暗面 |
| J1 中央骨场 | 中央 | 主分流大厅 | 骨堆、浅土台、三条窄路分叉 |
| J2 骨骸陈列台 | 上方中部 | 较高的干燥平台 | 骨架陈列架、后墙洞门、墙面岩肋 |
| J3 湿滑喉道 | 左上 | 阶梯落差和水流 | 多层石灰岩台阶、水面薄片、垂直水帘 |
| J4 上层裂隙廊 | 左侧上方 | 贴墙的窄边路 | 连续洞壁带、低矮钟乳石、转折口 |
| J5 大型分拣厅 | 上方右中 | 宽厅和矿架 | 木架、矿车、碎石堆、洞顶暗面 |
| J6 竖井/陷坑 | 中右 | 断裂地面 | 断桥、深色井口、两侧岩唇 |
| J7 封闭裂隙 | 右中 | 不可直穿的黑缝 | 岩柱夹缝、短墙和回头路 |
| J8 老矿车场 | 中央偏右 | 多路汇合的枢纽 | 车辙、转向路、矿车和支架 |
| J9 石柱林 | 左下 | 水中密集石柱 | 多环石柱、大小错落、窄水道 |
| J10 灰瀑阶池 | 左上至左下 | 连续高差水系 | 不规则池缘、石灰岩边脊、冷色水光 |
| J11 悬骨桥 | 中右 | 跨过黑色落差 | 窄桥面、护栏、桥下深井 |
| J12 塌方采石廊 | 右上 | 矿洞和堆石 | 连续侧墙、木架、工具和崩落石 |
| J13 记名壁室 | 右下 | 独立小室 | 入口拱门、石碑、刻名牌和墓台 |

## 通路关系

- 主回路：J0 → J1 → J8 → J6 → J11 → J5 → J2 → J1。
- 水路回路：J1 → J3 → J10 → J9 → J0，沿水池边缘折返。
- 上层回路：J1 → J4 → J9 → J6，经过石柱林和竖井边缘。
- 两条捷径：J8↔J2 的上层窄口、J6↔J13 的采石廊侧门。

墙面使用连续的不规则洞壁带，通路入口使用石柱拱口；平台只作为洞室地面，不能代替洞壁。石柱使用多环、偏心和变半径网格，避免圆柱或方块重复堆叠。
